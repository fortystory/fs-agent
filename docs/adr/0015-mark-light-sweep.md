# 标记上那束只在运行中扫过的反光

给左栏那块小篆「衡」加上一束从右下扫到左上的反光之后，这一篇记下三条**难回头**的决定：
**标记重新开始动**（票 08 曾把它定成静止，并写着「别把它想回来」）、**这束光只在一次运行
进行中出现**（于是它是「还在跑」的另一条通道，不是装饰），以及**峰值是白**（品牌色在这一
格上让位给物理感）。

规格在 [`.scratch/mark-sweep/spec.md`](../../.scratch/mark-sweep/spec.md)。

## 决定

- **标记重新会动，但只在一次运行进行中。** 空闲时整块逐格不变 —— 字形、颜色都不动。
- **光是一束从右下走到左上的斜带。** 每一格投影到那条轴上（`s = (最右列 − 列) + (最下行 −
  行)`，右下角是 0），光带就是 `s` 上的一段区间，核心 5 格、连两侧过渡一共 13 格，头每帧
  走 3 格，1.8 秒一轮、运行期间一直扫。
- **峰值是白**（`palette::MARK_LIGHT`），过渡回到字形本来就有的亮品红。
- **帧来自既有的脉冲**，不为它另起一个时钟：`RunState` 的两个边沿都把计数器归零，所以一次
  运行总从光带在右下角进场那一刻开始扫。

## 为什么

1. **静止是当时的结论，不是一条永久禁令。** 票 08 关掉的是「下落短横」那种**装饰性**动画
   —— 它没有在说什么，只是在动，而那时的理由（`CONTEXT.md` 的**下落短横**词条）是「真机上
   看下来不好看」。这次要的东西不同：一束扫过去的光**说明界面的状态**，用户点名的也是它。
2. **只在运行中，是因为空闲时的动必须有话说。** 空闲的会话已经在动两处（提示符停在静止色、
   状态行的月相慢下来），再加一束跟状态无关的光，左栏就变成一块没人读得懂的走马灯。
3. **洋红族里没有更亮的档了。** 字形是 `LightMagenta`、拼音是 `Magenta`，一道反光要在它们
   身上读出来，只能**过曝**成白 —— 这也是真机上看过的：白的那几格读起来像镜面，换成品红只会
   像换了个色调。
4. **几何是一条纯函数，不是逐帧画上去的。** `mark_sweep(column, row, columns, rows, frame)`
   决定每一格的颜色，测试直接量它的方向与档位，屏幕那一份只是把它画出来。

## 代价

1. **`the_mark_does_not_move_while_a_run_is_in_flight` 这条断言被推翻。** 它从「运行中也不
   动」改成「**没有运行在跑**时不动」，另加两条新的（方向、只在运行中出现）。
2. **一次运行里左栏多了一处每帧要算的东西。** 每帧为标记的 23 行各拆一次 span —— 行数固定、
   计算是整数加减，但它是空闲之外**唯一**为标记花的钱。
3. **`paint_mark` 从「一行一个颜色」变成「一行若干段」。** 一帧里同一行会出现三种颜色，段落
   数随之变化；留白格刻意**不吃**扫光，否则每帧都会多出一段没人看得见的颜色变化。
4. **四分之一块之上又加了一个字体要求。** 峰值是白，但过渡带用的是已有的 `LightMagenta` ——
   这一条没有引入新的码位。

## 被否决的替代方案

- **常驻循环（空闲也扫）**。**否决**：空闲时的动会被读成状态，而它那时什么都没说。
- **只在运行中扫，但用品牌色做峰值**。**否决**：与字形的亮品红拉不开距离，扫过去像换色调。
- **一条硬边细线**（不加过渡）。**否决**：60 ms 一帧下会闪，且不像反光。
