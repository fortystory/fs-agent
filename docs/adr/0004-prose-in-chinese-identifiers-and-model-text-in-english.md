# 散文用中文；只有标识符与「进 `messages` / 进流」的文本留英文

**决定**：这个仓库的**散文**一律用中文 —— 代码注释（`//` / `///` / `//!`）、`docs/` 下的逐面设计文档与 `docs/agents/`、测试的断言消息、以及只在启动时打印给人的错误文本（`ConfigError`、harness 的 `Error`、provider 的告警）。**英文只留给三类东西**：① 代码标识符（类型、函数、字段、文件名、CLI 旗标、事件 schema 的名字）；② **模型可见**的文本（工具声明与描述、工具结果、`AgentError.message`）；③ **进事件流、要永久回放**的文本（`PermissionDecided.reason`、`SessionError.detail`、`HistorySuperseded.summary`、协议标记 `CONCLUSION:`、投影前缀）。`docs/research/` 下的原始笔记是**一手来源的引文**，一个字不改。

这条**修订 ADR 0001 的两半**：它那条「人类可见文本用中文」现在覆盖全仓散文（不再只是前端文案），而它那条「模型可见文本冻结」被**原样保留并加强** —— 从「约定」变成 `scripts/check-language.py` 里可执行的检查。ADR 0001 里「写成英文」的那半句（以及 README 约定一节里「`docs/` 与 `docs/agents/` 写英文」那一行）由本文取代。

## 为什么

- **读者是人。** 注释与设计文档的服务对象是我自己（和读它的 agent）：解释为什么这样定、哪一处是刻意的、哪一处是踩过的坑。模型两种语言都读得懂，所以这一侧的收益全在「人读代码时」。
- **两半的代价不对称。** 散文改动是纯文本，编译器不管、也不进任何持久化产物，改错了最多是一句注释更差；而模型可见/durable 那一侧动一次要付**两笔**：前缀缓存整体作废一次，以及老流里的文本永远是旧语言（`--continue` 重放时会中英混排）。收益又几乎没有 —— 那一侧的读者是模型。
- **约定要能检查，否则会漂。** 之前只有 ADR 0001 的一句散文，实际状态是 `src/` 里已经有 195 行中文注释、`wording.rs` 是中文、其余 `src/` 与全部 `docs/*.md` 是英文，而模型可见的英文串就混在同一批文件里。翻译一遍正好是把这条线**画死**的时机：`scripts/check-language.py` 三条检查（冻结面无 CJK、`docs/*.md` 中文占比下限、`src/` 注释中文行的棘轮）。

## 代价（如实写）

- **一次性搬迁 ≈ 92 万字符**：`src/` + `tests/` 的英文注释 9,211 行（≈59 万字符）、`docs/*.md` 英文正文 ≈10 万字符、`tests/` 的英文断言消息 1,082 条（≈4.9 万字符）、以及给人看的错误文本 ≈2 万字符。翻译是**判断活**：注释里写着「这是刻意的，不是 bug」「这一条与 §12 的那条不变量是同一条」，批量机翻会把它们压成正确的废话，所以按模块小批翻、逐条判断。
- **搬迁窗口期两种语言并存**，`git log` 上会有一串「只动注释」的提交（每次的验收都是：diff 里没有非注释行、`cargo test` 条数不变、clippy 干净）。
- **老流与新流在语言上仍然是混的**：`reason` / `detail` 这批 durable 文本永不翻译，所以升级前的会话重放出来是英文的，升级后的是……还是英文的（这一侧没动）。这不是缺陷，是 ADR 0001 的冻结面。
- **中文注释更长**：同一段意思通常比英文长 10–20%，`//` 注释的换行位置会重排（行数会变，语义不能变）。

## 被否决的替代方案

- **只定增量约定、不翻历史**（新注释写中文，旧注释改到哪翻到哪）：省下 10–20 个 session，但代码库长期双语言，而且「哪一半是英文」不再有规律可循。用户选的是全量。
- **把模型可见的那一侧也中文化**：收益可疑（模型两种语言都懂），代价明确（缓存整体作废 + 老流永久混排），并且会破坏 ADR 0001 里那条真正重要的不变量（缓存前缀只增不改）。不做。
- **只翻 `docs/`，注释不翻**：`docs/` 只有 ≈10 万字符，是收益/成本最好的一块，但注释才是体量的主体（≈59 万字符、占全部散文的 85%），只翻文档等于把「读代码时读中文」的需求留在了原地。
- **翻译 `docs/research/`**：那 75 万字符是上游文档的引文（Gemini CLI、opencode、DSH、Cline 的正文摘录），翻译即失真，它存在的意义就是可核对的一手来源。
