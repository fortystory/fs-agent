# 问卷的键位按区域分派，单选与多选共用一个答案形状

给问卷加上 `j`/`k` 与区域之后，这一篇记的是那两条**难回头**的决定：**键位的判据是区域**
（`Zone { Options, Input }`，替换原来那个只被空格那一支读过的布尔），以及**答案只有一个形状**
（`selected` 与 `custom` 并存，单选不再是「文本覆盖选择」）。后者推翻的是一条**模型侧可观察**、
已经写进 [`.scratch/fs-agent-v1/spec.md` §7](../../.scratch/fs-agent-v1/spec.md) 的编码约定。

规格在 [`.scratch/questionnaire-keys/spec.md`](../../.scratch/questionnaire-keys/spec.md)，
意向的两次记录在 [`seed.md`](../../.scratch/questionnaire-keys/seed.md)。

## 决定

> 问卷里**键盘在哪一区**是显式状态（`Zone`），整套键位按它分派；而一道题的答案只有一个形状：
> **`selected` 与 `custom` 可以同时成立**。

具体地：

- **区域**是**问卷级**的状态（每题共用，翻页回到选项区），任一时刻只有一个。
- `j`/`k`/`Ctrl-N`/`Ctrl-P`/`↑`/`↓` 在选项区共一条分派、两端环绕、越过边界就是进输入区；
  进了输入区，`j`/`k` 就是文本。
- **选项区吞掉可打印字符与 `Backspace`**：键盘只在光标落到输入区时才让给文本。
- **答案形状统一**：单选与多选都是 `selected` + `custom` 并存；单选按键语义成 toggle
  （集合至多一个：未选中项 = 替换，已选中项 = 取消）。
- **问卷里的 `Esc` 只管「退出这次询问」**（双击、drop 掉 sender、模型继续跑），
  「取消这次运行」归 `Ctrl-C`；两把手势互斥。

## 为什么

1. **「一个布尔 + 散落的分派」已经在同一处漏过两次。** 票 33（空格在自定义文本里被当成确认）
   与票 34（`↑`/`↓` 挪高亮却不把焦点收回选项区）是同一类缺陷的两个实例：判据 `custom_focused`
   只被分派里的一支读过，别的支各自假设键盘在哪。区域把它变成一处显式状态之后，「这一支要不要
   看区域」不再是每个分支自己记的事。
2. **两个答案形状要模型自己解释「哪边优先」。** 单选覆盖、多选补充的差别是键盘侧的实现选择，
   却被写成了模型读的契约；并存之后模型只需知道「两个字段可以同时有值」这一条。
3. **`Esc` 在问卷里没有「这道题不答了」的出口，而那条语义其实已经存在。** 问卷立着而回合不忙时
   `Esc` 走的就是 `decline(pending)`。这次只是把它提升成问卷里 `Esc` 的唯一意思，
   并把「这次运行不要了」明确交给本来就承担它的 `Ctrl-C`。

## 代价

1. **模型侧契约变更。** §7 那条编码约定与 `ask_user_question` 的工具描述都要回改，老会话与新
   会话的答案形状不同；这是这次最贵的一笔。
2. **「问卷打开直接打字」不再有效。** 得先按一下 `↓`/`j` 让高亮落到输入区。这是真机手感上的
   显著改变，也是「按区域分派」的直接代价。
3. **同一个键在三个地方三种含义。** `Ctrl-N`/`Ctrl-P` 在编辑器里是历史上下条、在选项区是移动
   高亮、在输入区什么都不做——它们必须进词表，否则下一轮读代码的人会以为漏了绑定。
4. **`Esc` 在问卷里不再取消运行。** 想快速中止的人得改用 `Ctrl-C`（它本来就管这事，
   这次顺手把它的举手回执在问卷页脚里显示出来）。
5. **两把手势并存。** 「退出询问」与「退出运行」后果完全不同（一个让模型继续、一个中止回合），
   却共用一行提示的位置，所以要用一把共享槽位 + 一个「这是哪把」的标签保证互斥。

## 被否决的替代方案

- **留着 `custom_focused` 布尔，只在需要的地方多判断几次。** 最省事，但判据继续散在分派里，
  票 33/34 那类缺口会再来一次。**否决。**
- **单选保留「文本覆盖选择」，另加一个「清空已选」的键。** 它多一个键，而且模型那一侧仍然
  是两个形状。**否决。**
- **把「退出这次询问」做成给模型的一条合成「用户跳过」。** 模型会以为用户看过这道题并放弃了，
  而 §7 已经定了「`answers` 里没有该 `id` = 没走到那题」——退出询问与没走到是同一件事的两面。
  **否决。**
- **问卷里的 `Esc` 继续取消运行，另派一个键给「退出询问」。** 与区域模型正面冲突（`Esc` 在输入区
  已经是「回选项区」），而 `Ctrl-*` 那一层已被编辑器语义占着。**否决。**
- **把输入区做成真正的编辑器**（行内光标、历史、`Ctrl-U`/`Ctrl-W`）。它会让 `j`/`k` 的分派重新
  变模糊（编辑器的 `Ctrl-N`/`Ctrl-P` 与选项区的移动同键不同义已经够绕），而且是另一条意向。
  **否决。**
