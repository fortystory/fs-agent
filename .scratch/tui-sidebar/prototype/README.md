## 产物怎么读

- `frames/*.txt`：每张开头 3 行是这一档的 metadata（左栏档位 / 状态行档位 / 转录行列数 /
  回合条格数 / 提示行条目 / 分隔线列），然后是按 ratatui 真实输出的整屏。
- `geometry-table.md`：A 尺寸矩阵 / B 草稿档 / C 争议宽度档 / D 宽度扫描 / E 高度扫描 /
  F 状态行阶梯 / G 回合条状态 / H 提示行宽度账。数字都由画帧的同一套 `plan()` 打印。
- `SNAPSHOTS.md`：一张表回答「哪一张在回答什么」。

## 探针里编码的 spec 规则

- 一圈外框 + 1 条竖分隔线（`┬`/`┴`/`├`/`┤`/`│` 字形表）+ 主列 3 条横分隔线 → **固定 chrome 7 行**，`转录行 = h − 7 − 输入行数`。
- 左栏档位（spec §2）：`w ≥ 120` → 40（mark）；`100 ≤ w < 120` → 34；`80 ≤ w < 100` → 28；`w < 80` → 隐藏。去留只由宽度决定，内容由高度决定（先丢 mark → 身份行 → 字段尾部）。
- 状态行：三段 → 丢模型 → 只剩 `上下文 n%`（**第 4 档「整行消失」几何上不可达**，见 `geometry-table.md` §F）。
- 提示行宽度 = **主列内容宽**（不是终端宽）。
- 回合条：1 列、贴底、焦点格 `┃`、普通格 `┊`、溢出 `⋮`；两个状态各一张帧，外加一张**反例**（视口停在很旧的单位上 → 按 spec 原写法整条没有亮格），这张反例是 spec §4 的洞。

## 已知简化（不要当成产品结论）

- 没有滚动状态机（假数据直接给视口位置）；没有光标定位（dump 里看不到光标）；没有鼠标命中测试。
- 回合条的「窗口跟着焦点走」这一修法**没有实现**（它是票 01 之后才定的，见 spec §4）：帧里画的是原写法，反例那一张就是它的失效证据。
- 权限询问 / 详情覆盖层 / 问卷不在探针范围。
- 主题未定：边框与标签按 dim 画，焦点格两种配色各出一张只作对比。
