# 09: repo map

**What to build:** 模型能按需取一份仓库符号地图帮忙定位——成本可预期（固定预算）、结果可解释（朴素排序），且**不注入**（所以不会把历史反复挤出缓存前缀）。

Blocked by: 07

Status: ready-for-agent

**参考:** spec §9（skills 与 repo map）

- [ ] 内建**只读**工具 `repo_map(focus?)`，与 `skill(name)` 同形：产物是工具结果、`effect()` = `ReadOnly`、落进同一套截断与丢弃；**不注入**
- [ ] **固定预算 1k、可配上限 4k**；**不接受**模型传 `tokens`
- [ ] 抽取 = tree-sitter + 官方 `tags.scm`（**只有名字**，v1 不做签名渲染；增量解析后置）
- [ ] 排序 = **朴素可解释的纯函数**（会话相关度为主 + 结构信号为辅），**不做**整图 PageRank；`rank()` 是可替换的纯函数接缝
- [ ] 大仓库下取一次 map 的耗时与产物体量在预算内（记下实测数字，作为回归基线）
