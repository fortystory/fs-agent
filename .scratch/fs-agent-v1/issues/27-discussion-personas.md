# 27: 讨论者池与「人物」（推翻票 25/26 的自动 `#2` 命名）

**What to build:** 票 25 让同模型的第二个人自动叫 `<模型>#2`。用户试过之后的要求是：**池子里放几个「人物」**（名字写在预设里），`/discuss` 可以指定用哪两个，不指定就**随机抽两个**。这一票把 roster 从「一对」变成「名字 + 模型的池子」，并删掉自动后缀。

Blocked by: 25（同厂商/同模型允许）、26（`/discuss` 在活会话上）

Status: done

**参考:** spec §5（发言归属与投影）、§15（讨论协议）、票 25/26、`docs/discussion.md`

- [x] **`[discussion] debaters` 是池子**：≥2 个成员，简写 `["kimi-k3", …]`（名字 = 模型 id）或 `[[discussion.debaters]] name/model` 表；多于两个时一次讨论只用两个
- [x] **人物 = 名字 + 模型**：名字就是它在流上的身份（转录标签、私有身份、模型看到的 `[轮 N · 名字]` 前缀），因此校验「非空、不断开的单个词、≤32 字符、池内唯一」
- [x] **删掉自动后缀**：同一个模型的两位**必须**各起名字；错误信息给出 `{ name = "甲", model = "…" }` 的写法，不再猜一个 `#2`
- [x] **抽签**：`discussion::pick_pair(len, seed)` 纯函数（池内序、两个必不相同）；运行时种子取自时钟（`discussion_seed`），测试给常数
- [x] **指定**：`--debaters 保守,激进`（子命令与 `/discuss` 都支持；`/discuss` 的旗标只认行首，之后整行都是题目）；名字不在池子里时列出可用名字
- [x] **人名可以中文**：投影把**名字原文**写进 body 前缀（两侧必须可分辨），只对 `name` *字段*做 `[A-Za-z0-9_-]` 消毒（§5 的保守面）；`speaker_name` / `wire_name` 分开，executor 仍是 `executor-<id>`
- [x] **异质性判定改成「对这一对」**：`Config::debaters_share_a_vendor(a, b)`（池子可以混厂商，抽到的才决定提示），前台每次讨论说一遍
- [x] **文档/词表**：README 配置示例、`docs/discussion.md`、`CONTEXT.md`「讨论者」词条（人物 persona）、`discuss --help`
- [x] **测试**：池解析（简写/具名/多条）、四种拒绝（少于两个/未配置/重名/坏名字）、`pick_pair`（含池 3 能出全三对）、投影「前缀原文 + 字段消毒」、CLI 选择与旗标解析
- [x] **端到端**：池里三个人，分别验证「指定」与「随机」两种抽法都能跑完两轮讨论

## Comments

**2026-09-22（实现）** 三条取舍：

1. **名字是身份，不是标签。** 投影、转录、私有身份、模型的 `[轮 N · 名字]` 前缀全都用同一个字符串，所以「重名」只能靠配置期拒绝（而不是运行时去重）——这也正是自动 `#2` 该消失的原因：一个模型 id 不可能是两个身份，与其猜，不如让配置说清楚。
2. **名字允许中文，但 `name` 字段保持消毒。** 前缀是归因的真正保证（`name` 只是增强，§5 已有此论），所以人看/模型读的前缀用原文，字段走老规矩。
3. **判定异质性从「池子」下沉到「抽到的那一对」。** 池子可以混厂商，只有抽出来的两位才决定是否有「两个独立判断」。

**2026-09-22（后续）** 票 28 给人设加了可选的 `soul`（性格描述）：它以 `ContextInjected { source: Persona(名字) }` 进流、署名那位讨论者、只发给它自己。
