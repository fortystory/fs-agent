# 界面收一收：维护者点名的五处

Status: 5/5 done（2026-10-08 维护者一次提五条，当场问出四个选择：选择回显做成一条**用户发言**、技能名**连发给模型的文本一起**保留、废弃动画**只清与 `❱` 绑定的那一套**、工作中的状态字形**照旧走月相**；同日全部落地。当天稍后维护者看过回显的第一版，要求**把题面与选项也摆出来**——第一版只有一行 `题面：答案`，第二版改成一道题一段：完整题面加整张选项表，见票 01 的评论）

一轮真机使用之后维护者提的五条，彼此独立，一次收掉。

## 问题陈述

1. **模型问完的问卷，答案在对话里看不见。** `ask_user_question` 的结果是那段 JSON，躺在工具
   行点开的详情里；转录里既没有「我问了什么」的答案，也读不出「我选了什么」。回看一场会话时，
   正是这一处最需要一眼看到。
2. **技能调用把技能名从文本里删掉。** `submission()` 解析出 `/<skill>` 之后，送给模型的任务是
   记号**两侧**的字拼起来的（`task_around`），技能名本身被丢掉 —— 于是 `/research 帮我查 X`
   在对话里长成 `帮我查 X`，而「这一句是怎么发出去的」不再可读，追问时也无法照原样重发。
3. **就绪时状态行那个字形还在转。** 月相循环是「还在跑」的一条信息通道，而空闲时它照样一格一
   格地走：一个什么都没做的界面在微微地动，而「就绪」两个字已经说完了状态。
4. **输入框那个 `❱` 不再需要。** 它的来由是「编辑器待在那里时，画家给这个字形的颜色绕着色相
   轮走」（`tui-input-pulse` §2b）—— 而那条色相通道是给**运行中**用的。维护者点掉了这个字形。
5. **与 `❱` 绑定的那套色相/呼吸随它一起废弃。** `palette::prompt_colour` 与四个 `PROMPT_*`
   常量、`hsv_to_rgb`、画家那一处 `prompt_style`，都只为这一个字形存在。死代码收口
   （`tui-visual-language` §34）已经清过一次同类残留，这次轮到这一套。

## 方案

五条各自独立，四张票落在前端与措辞层，一张落在提交解析：

| # | 改什么 | 关键文件 |
| --- | --- | --- |
| 01 | 问卷答完，往转录推一条**用户发言**（完整题面 + 整张选项表 + 自定义文本） | `render/transcript.rs`、`render/wording.rs`、`render/tui.rs`、`render/plain.rs` |
| 02 | `/<skill> 任务` 的整条原文发给模型，技能名不再被删 | `cli.rs` 的 `submission` |
| 03 | 就绪时状态字形固定在 `🌕`，运行中照旧走月相 | `render/wording.rs` |
| 04 | 删掉 `❱` 提示符：`wording::PROMPT` 与 `prompt_columns` 整套离场 | `render/wording.rs`、`render/editor.rs`、`render/layout.rs` |
| 05 | 随 `❱` 一起删掉色相/呼吸那套（04 的推论） | `render/palette.rs`、`render/tui.rs` |

### 定下来的四条（2026-10-08 一次四问）

- **回显做成一条用户发言**，不是静音回执：与你打的字同一档（TUI 里是那块气泡），于是「我选了
  什么」和「我说了什么」在转录里是同一个位置上的东西。它摆出**完整的题面与整张选项表**
  （包括没选中的那些），所以回看时读得出「当时还有哪些没选」。它由**流上的那次工具调用**推出来
  （`Transcript` 从结果里认 `ask_user_question`），所以 `--continue` 重放同样重现，两个前端
  也自动一致。
- **技能名连发给模型的文本一起保留**：`/research 帮我查 X` 整条原文既显示、也作为 user 消息
  发出去，技能正文照旧加载。裸的 `/<skill>`（整条只有那一个记号）仍走「正文就是指令」，多出
  的那条 user 消息不会出现。
- **废弃动画只清与 `❱` 绑定的那一套**：左栏标记忙时那束扫光（ADR 0015）与光标闪烁都留着。
- **工作中的状态字形照旧走月相**：静止只发生在就绪那一半。

## 不做什么

- 不动 `task_around` 给内建命令（`/discuss`、`/goal-new`、`/loop`、`/model`、`/effort`）的语义：
  那些命令的参数是记号**旁边**的字，技能是唯一一个「名字本身就是这句话的一部分」的记号。
- 不给问卷答案回显补一条进模型上下文的 user 消息：它是给人看的转录行，进上下文的是那次工具
  调用与它的结果。
- 不回滚左栏扫光、不动 `PULSE_FRAME` 那个时钟：它就绪时也照着光标闪烁。
