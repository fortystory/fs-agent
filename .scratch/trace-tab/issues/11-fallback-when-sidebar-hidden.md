# 11 — 降级：左栏不可见时对话视图退回全量

Type: implement
Status: ready-for-agent
Part of: ../map.md
Blocked by: 10

> 规格：[`../spec.md`](../spec.md) §6（降级）。

## 目标

左栏**不可见**时（`w < 80`，或用户 `Ctrl-O` 收起），进轨迹的那些块**回到对话视图** —— 过程行永远有地方显示。用户看得见：窄终端与收起态下，「注入了什么、调了什么工具、为什么报错」不会凭空消失。

## 现状（改前先复核）

- 左栏的去留 = 用户意愿 × 宽度档；不可见时页矩形为 `None`。
- 上一张票之后，过程行只进轨迹视图 —— 于是左栏不在时它们**没有任何去处**，而今天（改动前）它们在转录里任何宽度都看得到。

## 落点

`src/render/tui.rs`（分工函数的输入多一个「左栏在不在」）。

## 具体行为

1. 判据 = **页矩形为 `None`**（宽度不够或意愿为假都走同一支）。
2. 该帧的分工返回「所有块都进对话视图」。
3. 这是**视图选择**，不是第二条渲染路径：块的产生、详情入口、markdown 排版都不变。
4. 左栏回来时恢复分工（含用户重新叫回的那一帧）。

## 验证

1. 帧断言：120×24 下收起左栏 → 过程行出现在主列；叫回 → 主列又只剩对话。
2. 80 列以下（左栏本就不存在）同一断言。
3. 收起/叫回不改变滚动位置与「N 条新行」计数（两个视图各自的意图保留着）。

## 不做什么

- 不改左栏的档位门槛与 `Ctrl-O` 的语义。
- 不给窄终端另做一套排版。
