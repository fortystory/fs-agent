# 账本的两级结构与每行信息

Type: grilling
Status: resolved
Part of: ../map.md
Blocked by: 03

## 问题

[账本骨架的几帧](03-prototype-ledger-skeleton.md) 给出了候选形态，这一票把它**拍定**。要拍的
（每条都要落成一个能在 spec 里执行的句子）：

1. **分组几级、判据是什么**。DSH 是 turn → `Message` / `Step N` 两级。衡的流里有两个候选的
   「单位」：**回合 / 轮次**（`TurnStarted` → `TurnEnded`，讨论里是 `RoundStarted` → `RoundEnded`，
   今天画成一条虚线）与**迭代**（`TurnStarted.iteration`，一次模型调用）。
   定：轨迹页分几级；每一级的**名称**（要进 `CONTEXT.md`，`/domain-modeling`）；一个单位从哪块
   开始、到哪块结束；讨论会话里「轮次」与「回合」怎么并。
2. **组头写什么**。候选：序号 / 起止时刻 / 墙钟跨度 / 工具直方图（`bash×6`）/ 块数。定下选哪些、
   什么顺序、超宽怎么截；以及**它是不是可点的**（点了折起来？跳过去？）。
3. **行首那 9 列**。今天固定是 `HH:MM:SS `。序号 `#N` 要不要？要的话与时间戳并排还是分档
   （窄终端给哪个）？这一格的宽度是**常数**（`layout::STAMP_COLUMNS`），改了它牵动轨迹内容的
   排版宽度 —— 定下最终值。
4. **每行耗时**。工具块手里有 `duration_ms`（今天没上屏）、模型调用可从 `at` 推。定：谁带耗时、
   挂在行尾还是行首、格式（`1.5 s` / `1500 ms` / `0.3 s`）、以及**拿不到就不画**（不许编）。
5. **失败与错误码**。今天末尾一个红色 `失败`，错误正文在详情里。定：行上要不要带错误码
   （DSH 带 code、详情里给 `name: code`）；`ToolOutcome.error` 与 `ok = false` 但无 error 文时
   各读成什么。
6. **结果摘要**。DSH 的工具行是 `name · args → 结果`。衡今天只有调用摘要、结果在详情里。定：
   行上要不要给一小段结果（首行？字节数？行数？），空输出读成什么（DSH 给一句灰话）。
7. **无主段落**。会话开头那一段（`SessionStarted` / 各类注入）、`compaction`（`History`）、
   `/clear` 之后 —— 给不给小标题（DSH 有 `Between turns`），还是继续当普通块。
8. **消息行**。今天 `首行 + …`。分组之后它要不要变（缩进？还是照旧）—— 「点开看全文」这条
   （`DetailKind::Message`）不动。
9. **`parity.md` A 节的收口**：把那一节每一条的最终判定写回去（`已对齐 / 补齐 / 变形做 / 不做`）。

**冻结项不许重开**：[图](../map.md) 的四条（可寻址的账本、范围五块全进、用量两处都要、
不许押 TTFT）。

## 作答

2026-10-09，与维护者三轮 grilling（分组 / 行内宽度与数字 / 组头的时刻与交互，共十问）。三条
冻结项未动：判据仍以 DSH 为基线、模型可见文本零变化、不押 TTFT。

### 0. 新核的两条事实（本票的推荐都建立在它们之上）

- **边界可靠**：逐文件数过 8 个真实会话，`TurnEnded` 的条数与 `TurnStarted(iteration == 1)` 的
  条数**相等**（每回合一 条边界）。所以「回合」是一个可靠的切分，不必自造判据。
- **回合很长**：一个回合里的迭代数从 **1 到 557**，多数几十上百；而一次会话只有 **1–13 个回合**。
  所以「迭代」那一级不是可选项 —— 一个 200 次迭代的回合平铺开来没法读。
- 反面代价同样实测过（帧 1d）：两级缩进把工具行压到 **36 列**，而 120×24 下轨迹页只有 15 行
  可视高度 —— 缩进把「宽」与「高」两样最稀缺的资源一起吃。

### 1. 分组：两级，成员不缩进

- 轨迹页分**两级**。一级是**单位**：交互会话数**回合**（`TurnStarted(iteration == 1)` 起、
  `TurnEnded` 止），讨论会话数**轮次**（`RoundStarted` / `RoundEnded`）。二级是**迭代**
  （`TurnStarted.iteration`，一次模型调用）。
- **成员不缩进**：一级成员与二级成员一律从第 9 列（内容起点）起排，工具行保住 70 列。层级由
  **头行**承载，不吃内容宽度（形状见 §10）。
- 讨论会话**不额外给「发言」一级**：二级头写 `[minimax-cn] 第 3 次迭代 · 18 s`，发言者身份沿用
  既有的 `[名字]` 前缀语法（`research/02`：执行者 / 讨论者就靠它区分）。
- 可执行的边界判据：`TurnStarted` 且 `iteration == 1` → 开新的一级组；`TurnStarted` 且
  `iteration > 1` → 开新的二级组；`TurnEnded`（讨论里 `RoundEnded`）→ 收当前一级组。组头长在
  一级组的最前面。
- 理由：帧 1d 的缩进换来的清晰度不值那 34 列；不缩进后 `parity.md` A 节那条两级分组仍是**变形做**
  （结构照 DSH，形状不照）。

### 2. 组头：并进虚线那一行

- 组头**并进单位之间那条虚线**，占一行，横跨整条正文（时间戳那几列也在内，跨度与今天的
  `trace_rule` 一致）。零额外行数。
- 字段与顺序：**起时刻 · 序号 · 墙钟跨度 · 工具直方图**。一级头像：
  `09:12:04 ┄ 回合 1 · 49 s · bash×2 read×2 edit×1 ┄┄┄┄…`；讨论里 `轮次 2`。二级头不带虚线：
  `第 3 次迭代 · 18 s`。
- 起时刻 = 一级组第一条 `TurnStarted.at`；跨度 = 起时刻到 `TurnEnded.at`；直方图按
  `ToolCallStarted.tool_name` 计数、同类归并成 `bash×6`；拿不到的字段整个不画（不编数字）。
- 超宽**从右往左丢**：先丢直方图尾部（`· edit×1`），再丢整段直方图；序号、跨度、起时刻最后才丢。
- **摘要在单位开头就画、随单位推进而增长**：直方图每来一条长一格、跨度跟着长，`TurnEnded` 那刻
  定稿。这要求 `pane` 能**按行键替换任意一行**（今天只有思考行用的 `replace_last`）—— 它与
  `research/02` §2 那条「块 → 源行」记账是同一层，见 §11。
- 理由：轨迹页是实时流，读者最想看的是「正在跑的这个回合在干什么」；而帧 1a 那种「头自己一行」
  在 15 行可视高度上要吃掉三分之一屏。

### 3. 行首那 9 列：不动

- `layout::STAMP_COLUMNS` **仍是 9**，只放 `HH:MM:SS` + 一个空格。行上**不给序号**：一级序号在
  组头（`回合 1` / `轮次 2`），二级序号在二级头（`第 N 次迭代`）。
- 组头那一行也在这 9 列里放它的起时刻 ⇒ 所有行的时刻列竖向对齐不变。
- 由此 DSH 的「每行 `#N` 请求编号」判为**变形做**：它的用途（知道这是第几个请求）由两级组头
  兑现，行上不重复。代价是牵动的排版宽度为零。

### 4. 每行耗时

- **工具行**：行尾、用量之前，形如 `· 1.5 s`（`  in=… out=…` 保持 ADR 0016 的形状）。
  格式：秒为单位、一位小数，≥ 10 s 不带小数（`0.2 s` / `1.5 s` / `49 s`）。
- **迭代**：耗时挂它**自己的二级头**（`第 3 次迭代 · 18 s`）—— 一次迭代没有自己的行，二级头
  就是它的行，所以模型调用的耗时一分行内宽度都不占。
- **拿不到就不画**：被取消的、还在跑的、宽度放不下的都空着，不编数字（帧 3e）。
- **行尾溢出顺序**：先丢耗时、保用量。ADR 0016 已把行尾定成用量的家，耗时是后来者。
- 口径写清（供 spec 直接抄）：工具耗时取 `ToolCallCompleted.duration_ms`（调用墙钟，含钩子与
  排队）；迭代耗时取 `TurnStarted(iteration = k).at` 到下一个同 speaker 的 `TurnStarted` 或该回合
  `TurnEnded` 的 `.at`（`research/01` §3）。

### 5. 失败

- 行上仍是末尾一个红 `失败`（这一半今天已对齐）。
- **错误正文首行多画一行**：从第 9 列（内容起点）起、弱色。`error: Some(text)` 时画 `text` 的
  首行；`ok == false` 而 `error == None` 时只留那个红 `失败`，第二行不画。
- **不加行首 `✗`**：那要把行首那格加宽 2 列，全体行的内容宽一起降，而红色落在内容位已经读得出来。
- **错误 code 不做**（`events::ToolCallCompleted` 只有 `error: Option<String>`，要 code 得动流；
  `parity.md` A 节那一半维持「不做」）。失败行不多，多一行不心疼。

### 6. 结果摘要：只在异常时给一句

- 常规成功行**一个字也不加**（调用摘要照旧是今天那一半，结果进详情）。
- 三种异常才在行上补一句：空输出 → `· 无输出`；被截断过 → `· 188 行（省掉 412 行）`；失败 →
  按 §5 走。`ok == true` 且 `output` 为 `None` 或空串就是「空输出」。
- 「行数」与「省掉多少」的口径归 spec 核：今天至少两路截断（上下文组装期的
  `context::TRUNCATED_MARKER`、工具输出自己的 head/tail），spec 要写清**行上读的是哪一路**，
  别混成一个数。

### 7. 无主段落：都给小标题

- 三类各一行的标题，形状与组头同族（不缩进、弱色、**不带虚线、不是把手**）：
  - `▸ 开场 · 4 条注入`（`SessionStarted` / 各类注入 / 技能注入）
  - `▸ 压缩 · 上下文过半，前面 42 轮压成摘要`（`Block::History`）
  - `▸ 新会话段（上一段留在磁盘上）`（`/clear` 之后）
- 理由：DSH 的 `Between turns` 就是这个用途 —— 让「不属于任何回合」在账本上看得见。
- 开场那一串注入能不能折成一行（帧 6d 的 `▸ 开场 · 4 条注入 · …`）归 [搜索与折叠的形态](09-grilling-search-and-folding.md)。

### 8. 消息行：照旧

- `首行 + …` 不变，`DetailKind::Message` 与「点开看全文」不动。成员不缩进之后它本来不需要改。

### 9. `parity.md` A 节的收口

| DSH 的轨迹 | 最终判定 | 落成什么 |
| --- | --- | --- |
| 回合之间分隔线 + `#N` 角标（当前回合高亮） | 变形做 | 分隔线并进组头，序号在组头里（`回合 N` / `轮次 N`）；「当前回合高亮」的着色归 spec |
| turn → `Message` / `Step N` 两级分组 | 变形做 | 两级照 DSH，**成员不缩进**（§1） |
| 组头摘要（墙钟跨度 + 工具直方图） | 变形做 | 起时刻 · 序号 · 跨度 · 直方图，并进虚线，随回合增长，超宽从右丢（§2） |
| 每行 `#N` 请求编号 | 变形做 | 行上不给号，用途由两级组头兑现（§3） |
| 失败：行上给错误 code | 不做（code）/ 变形做（其余） | 红 `失败` + 错误首行多画一行；code 要动流，不做（§5） |
| 工具行 `name · args` → `结果` | 变形做 | 调用摘要照旧；结果只在空输出 / 被截断时给一句（§6） |
| 子调用（PTC）缩进成 subtool | 不做 | 范围之外，维持 |
| `Between turns` 区段 | 补齐 | 开场 / 压缩 / 新会话段三种小标题（§7） |
| 工具变更提示折成一行 | 不做 | 范围之外，维持 |

### 10. 形状与措辞（归 spec 与 `docs/render.md`，不是本票的决策）

- 一级头占满一整行虚线（框架位、与今天的 `trace_rule` 同字形），二级头是弱色单行、行首那格仍
  放它自己的起时刻。
- **展开态一律不用 `▸`**：`▸` 只表示「有折起来的内容」（`wording::FOLDABLE` 的定义）。组头是
  虚线行，二级头是弱色行，折叠态才轮到 `▸`（帧 6a）。二级头若不可折，就一个字形都不新增。
- 二级头前缀那个轻字形（候选 `┆`，与「框架」那套虚线同族）与组头的语义色归
  `.scratch/tui-visual-language/spec.md` 的符号表；**反显通道继续封着**（全屏唯一的反显是
  「键盘所在」，`research/02`）。
- 正在跑的那个一级组（还没收到 `TurnEnded`）的组头要不要着色区分，归 spec —— 措辞沿用现有的
  **焦点回合**语言，别造新词。

### 11. 三个张力的结论

1. **行尾挤不下耗时** → 工具耗时挂行尾但**先丢耗时、保用量**；迭代耗时挂二级头，不占行内宽度。
2. **`▸` 已被占用** → 展开态不用它：组头是虚线行、二级头是弱色行，`▸` 只留给折叠态。字形一个
   都不新增。
3. **两级分组吃宽度** → 成员不缩进（工具行保 70 列）；多花的那一行由「组头并进虚线」抵成零。

### 12. 术语变更点（供 `/domain-modeling` 落到 `CONTEXT.md`）

- **新词建议：单位（Unit）** —— 轨迹页与回合条上那一个分组：交互会话数回合、讨论会话数轮次。
  它不是流上的词（流上是 `TurnStarted` / `RoundStarted`），是视图层的统称；本图、`parity.md`
  与这张票已经在用它而没有词条。
- **`回合（Turn）`** 补一句：轨迹页的组头读作 `回合 N`；讨论会话里不数回合，数轮次（一次发言
  仍然是「一个 agent 的一次完整往返」，定义不动）。
- **`轮次（Round）`** 补一句：轨迹页讨论会话的组头读作 `轮次 N`；一个轮次里两个发言者**不单独
  成级**，靠 `[名字]` 前缀与二级迭代头读。
- **`迭代（Iteration）`** 词条不动（已写「屏幕上读作『第 N 次迭代』」）；补一条耗时口径：
  `TurnStarted(k).at` 到下一个同 speaker 的边界。
- **不立新词**：**发言** —— 它就是「回合」在讨论会话里的读法，立词条会暗示一个界面上不存在的层级。

### 13. 本票排掉的 fog，与新浮出来的一条

- 排掉：**「迭代这一级叫什么、立不立词条」**那条 fog（沿用**迭代**，二级头读 `第 N 次迭代`）—— 它从图的
  「尚未明确」里毕业出局。
- 浮出：**「按行键替换任意一行」这一层归哪张票** —— 组头的增量增长（§2）与稳定行键、
  「块 → 源行」记账是同一层前置，[搜索与折叠的形态](09-grilling-search-and-folding.md) 与
  [长历史与行选择](10-grilling-history-and-selection.md) 都有它。已记进图的「尚未明确」。
