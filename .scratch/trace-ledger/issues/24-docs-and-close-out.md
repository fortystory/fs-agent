## 目标

这一轮落地之后，**下一轮读代码的人**能从逐面文档与手工清单里知道现在有什么：账本结构、横带、
面、搜索折叠、选中这几件各自在屏幕上的样子；以及那三处纪律（`/` 两义、`Enter` 在搜索模式里
不提交草稿、搜到的命中不一定都在轴上）被写在明处。

## 现状（2026-10-09 核实，改前先复核）

- `CONTEXT.md` 里这一轮的词条**已经在票收尾时落下**（账本 / 选中 / 行身份 / 新内容指示器 /
  详情覆盖层 / 面 / 时间轴 / 首 token 时刻 / 命中 / 过滤 / 折叠 / 单位）—— 本票要补的是
  **实现之后与代码对不上的那几处口径**，不是重写决定。
- **轨迹视图**词条里「滚轮与三键都归当前显示的那一页」那句已被新的两层归属取代。
- `docs/render.md` 的相关小节：两个视图、时间戳、键盘、拖选与复制（加折叠与过滤）。
- `docs/tui-manual-checklist.md` 轨迹那一条今天只覆盖「主列的第二页、时间戳与轮次分隔线」。
- 逐面文档与手工清单都要过文档密度护栏的压表达规则。
- 启动检查脚本只要求身份在场与虚线的数量，**从不要求某一页上写着什么** —— 横带选了框架那套虚线
  之后它的计数会自然上升，而那是「至少三格」的降级护栏、不红。

## 具体行为

1. **`CONTEXT.md`**：补齐实现之后与代码对不上的口径；修**轨迹视图**词条里键盘归属那半句；
   **单位**词条补一句「它是视图层的统称，流上的事件仍叫那两对」。
2. **`docs/render.md`**：
   - **两个视图**：两级分组、组头并进虚线、组头字段与随推进改写、每行耗时、失败多一行、
     三类无主段落小标题。
   - 新增**时间轴**一节：三行横带、两泳道、TTFT 两段、视口区间底色、位置标记、降级阶梯、
     不可聚焦。
   - **键盘**一节：轨迹页新增那一层的判据与位置、`Esc` 四层顺序、交还与拿回、完整键位表。
   - **拖选与复制**（或相近那节）加折叠与过滤那一套。
   - 新增**检视器的面**一节：分派表、切面键、各面各记滚动、默认面。
   - 三处纪律写在明处：`/` 在轨迹页与记号菜单两义、`Enter` 在搜索模式里不提交草稿、
     **搜到的命中不一定都在轴上**（以及落轴的那条判据）。
3. **`docs/tui-manual-checklist.md`**：轨迹那一条从「主列的第二页、时间戳与轮次分隔线」扩成走查项 ——
   两级分组与组头字段、每行耗时、失败那一行、时间轴三行与两段切分、选中与折叠、搜索过滤的键盘流、
   交还与拿回。**真机要看的那一半**（真实字体下的密度、两档底色在不同主题上的可分辨性、
   长会话里折叠与过滤的手感）列在这里而不是单元测试里。
4. **收口**：本图的 `Status:` 按实现票的实际完成度改写；`.scratch/README.md` 那一行跟票走。
5. **明确不写进任何文档的**：这一轮「不做」的那一整串（分页、聚合条数、Web 无障碍那一套、
   像素手势、深链接、区间聚焦、原文面、模型面）—— 它们在 `parity.md` 与本图的「范围之外」里，
   **不要**在逐面文档里写成「暂不支持」。
