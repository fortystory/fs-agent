## 目标

一场会话几百上千块，找一句话不必靠眼睛扫：`/` 进搜索、查询串打在输入区，搜到的块在账本上
**真过滤**（未命中不占行），右下角那一行给 `n 个命中`，`n` / `N` 沿命中走一遍。

## 现状（2026-10-09 核实，改前先复核）

- 事件流是**只追加**的，所以块的身份（票 12）与块自己的那段文字都在手边 —— 索引不必读盘。
- 输入区有既有的编辑器（缓冲、光标、行内编辑与拖选），**草稿存取是现成的**；行内文本编辑只有
  输入区与问卷自由文本行两处先例 —— **状态行没有行内编辑**。
- 块的身份今天**没有被裁剪**（窗格裁的是折好的显示行），所以索引能覆盖整场会话而不是窗口内。
- 块定稿那一刻是可判的：还在流的增量块不建索引。
- 没有可复用的匹配件：既有的搜索工具是流式逐文件、大小写敏感的；路径那套匹配是分段前缀、
  只返回排序用的段号。
- 过滤要真过滤就得「不推那些源行」，而窗格**没有删一段的入口** —— 所以过滤走重放（与宽度重放
  同一条路）。

## 落点

渲染层的索引（一份「块身份 → 那段文字」）、重放那条路的输入（哪些块在）、输入区的一种模式、
键盘那一支（`/`、`n`、`N`）、右下角那个浮字位的文字来源。

## 具体行为

1. **`/` 进搜索**：轨迹页持有键盘时它归搜索，**必须排在记号菜单那一支之前**（否则 `/` 永远被
   菜单先抓住）。**同一个物理键两层换含义**写进逐面文档。
2. **查询串打在输入区**：进搜索时输入区切到搜索模式，**草稿原样存着、退出时原样还原**。
   搜索模式里：普通键改串、`Backspace` 删字、`Enter` 接受并离开（**不提交草稿**）、
   `Esc` 取消并还原草稿。改一个字符就**实时重算**（不设节流）。
3. **索引**：每块一条记录、字段是**块自己那段文字的全文**（工具摘要、消息正文、思考、注入正文、
   工具参数与输出）；不另立字段、不做分词预处理。
4. **建索引的时机 = 块定稿那一刻**，增量建、只建一次；**重放不重建**（重放换的是窗格的行）。
   **未定稿的增量块不进索引**；它定稿那一刻建索引并触发一次重放，于是它若命中就出现在过滤视图里。
5. **覆盖整场会话**，不受裁剪影响 —— 文档里要说成「搜的是整场会话」而不是「搜窗口内」。
   **不做截断**：截断就是拿一个静默的洞换内存。
6. **查询语义**：空格分词、大小写不敏感、各词 AND。没有引号短语、没有正则、没有模糊匹配。
7. **真过滤**：账本上只剩命中块（走重放：未命中的块一条源行都不推）。
   **组头保留且不因过滤改写**（它是该单位全体成员的直方图）。
   **过滤期间跟随暂停**，命中的新块照样进账。退出过滤回到原处（视口锚点兜住）。
8. **`n` / `N`**：下一个 / 上一个命中，**并把选中移到那个块**（票 18 给了那条移动路径）。
9. **读法**：命中数写在**内容区右下角那个浮字位**（与「新内容指示器」同一位、同一色）——
   `n 个命中`；自进入过滤以来有新命中块到达时加 `· 新增 M`（**M 是新到达的命中块数**）；
   **无匹配就写 `0 个命中`**；滚到底恢复跟随后「新增」清零。
   **过滤期间那个位置整句让给命中读法**，因此那一刻它不再是可点的手势位；回到最新由 `G` 承担。
   **状态行一个字都不动。**
10. **状态存在渲染器一侧、按块身份记**，不存窗格里 —— 于是宽度重放之后过滤集原样还在。
11. 搜索串**只活在进程内**，切会话 / 恢复会话不持久。

## 验收

- [ ] 轨迹页持有键盘时按 `/` 进搜索；打字时 `/` 仍然弹记号菜单（两层换含义）。
- [ ] 查询串打在输入区，进搜索前的草稿**原样存着**、退出后**原样还原**。
- [ ] 搜索模式里 `Enter` 离开搜索模式但**不提交草稿**；`Esc` 取消并还原。
- [ ] 改一个字符就实时重算，不按回车。
- [ ] 一块命中时它那几行一起出现在过滤视图里；未命中的块**一条源行都不占**。
- [ ] 索引覆盖整场会话：早就滚出屏（被裁掉）的那块仍能搜到。
- [ ] 还在流的增量块不进索引；它定稿后若命中就出现在过滤视图里。
- [ ] 组头在过滤视图里**保留且不改写**。
- [ ] 过滤期间新块进账而视口不动；`Esc` 清过滤后回到原位。
- [ ] `n` / `N` 跳命中并把选中移到那个块。
- [ ] 右下角那一行：`12 个命中` / `12 个命中 · 新增 2` / `0 个命中` 三种文案各自出现；
      滚到底后「新增」清零。
- [ ] 过滤期间那个位置**点它没有反应**（不再是手势位）；`G` 仍回到底部但**过滤不变**。
- [ ] **状态行逐字未变**。
- [ ] 改宽度（触发重放）之后过滤集原样还在。
- [ ] `cargo test` 全绿、`cargo clippy` 干净、`cargo fmt --check` 只留既有漂移。
