## 目标

每一块在渲染层有一个**从事件信封派生的身份**，活过窗格裁剪与宽度变化重放这两件今天会推翻位置下标
的事；并且窗格多一个「按行键替换任意一行」的入口，于是「正在跑的那个回合的组头就地改写」第一次
有可能实现。

**这一票屏上什么都不变** —— 它是让后面十张票变容易的那一步，验收全在测试层。

## 现状（2026-10-09 核实，改前先复核）

- `apply` 只取信封的 `at` 就把 `seq` 丢了；`Painted::Block` 与除 `Block::Tool` 外的所有 `Block`
  变体都**没有身份字段**。
- 一条事件可以产出**零个到多个块**，所以「一个 `seq` 对应一个块」今天不成立 —— 身份必须是
  `seq` **加块内序号**。
- `seq` 是 JSONL 的行号，落盘与读回**原样保留**；实时路径与会话恢复路径逐字相同
  （`read_events` → 重放 → `apply`），所以从那里取身份不需要第二套编码。
- `Pane` 的公开面只有 `push`（返回本次丢弃的源行数）/ `replace_last` / `append_to_last` /
  `clear` / `source_at` / `view` / `scroll_to_source` / `scroll` / `page` / `wheel` / `to_bottom` /
  `restore`，**字段全私有**，没有任何按索引插入 / 替换 / 删除。
- 裁剪让窗格内**一切**下标统一左移（`starts`、`top`、`total`、`seen`、视口锚点各减），返回值就是
  两张平行表跟着裁的**唯一权威**。

## 落点

`render::transcript`（`Painted` / `Block` 带身份）、`render::tui` 的 `apply` 与它的推送路径
（传 `seq`、记一份「块身份 → 源行」）、`render::pane`（新增一个入口）。
**事件 schema 一个字节不改** —— `seq` 本来就在信封里。

## 具体行为

1. **块身份 = `(seq, 块内序号)`**，挂在每一个块变体上（工具 / 消息 / 思考 / 注入 / 答案 / 命令 /
   todo 那一族）。`apply` 从信封取 `seq` 并往下传；同一个事件产出的多个块按产出顺序编号。
2. **增量块在流式期间取一次号，定稿不换身份** —— 身份是块的数据，不是它当前长什么样。
3. **身份 → 源行**那份账随行一起记，随窗格的丢弃数一起裁；它是「点开详情」「层级跳转」
   「命中导航」三处的共同落点（后三处分别归票 18 / 19 / 20）。
4. **`Pane` 新增按行键替换任意一行的入口**：键 = 源行下标（今天那套），替换的是那一行的**整行**。
   替换一条不存在的行是**空操作**；空窗格上安全；替换**不改动视口锚点**（读者的位置不跳）。
5. **重放时身份不变**：同一批事件重放两次得到同一套身份 —— 宽度变化重放是这一条的第一个消费者
   （归票 16），所以现在就要把「同序重建得到同号」这条纪律守住。

### 形状与票面不同的两处

1. **身份挂在 `Painted` 那三个变体上，而不是二十几个 `Block` 变体。** 票面写的是「挂在每一个块
   变体上」，那会把 `Block`（共享层，plain 与 TUI 共用）整个改一遍，而身份只服务 TUI 的寻址。
   `Painted` 正是「一块 + 它的时刻 + 它的尾巴」那条记录，`apply` 今天也正是从那里取 `at` ——
   身份与时刻放在同一个地方，是同一个道理（`.scratch/trace-ledger/spec.md` §1）。
2. **「行键」住在 `TuiState` 侧，窗格只加一个按来源行下标替换的最小入口。** `Pane` 是两个视图共用的
   通用件，而窗格内部的键就是源行下标；「行键 → 源行」这份映射住在 `trace_block_ids`
   （按来源行存），于是裁剪仍然是 `pop_front` 一次，O(1)。若把它塞进 `Pane`，那张表就要跟着每次
   裁剪重算。

### 实现撞出来的一个事实：`seq` 不可空

票面与 [ADR 0021] 都写「块身份从 `Event.seq` 派生」，而**渲染层自己造的记录没有信封**：推理增量
开出的思考行、诊断、通知、拼好的系统提示词 —— 增量绕过事件流，事后推不出来（`transcript.rs`
模块头第二条规矩）。所以 `BlockId.seq` 是 `Option<u64>`，`None` 的那几种由渲染层一条单调计数补
`index`：唯一，且**跨重放稳定**（重放走的是同一个事件序列）。这是 ADR 的实现细节，已在 ADR 里补一段。
`Block::Delta` 本身不留在 `painted` 里（它只变成思考行或者不留），所以受影响的只有思考行与那三类
自造记录。
