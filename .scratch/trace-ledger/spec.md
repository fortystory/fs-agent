# 轨迹页对齐 DSH 的轨迹：把轨迹升格成可寻址的账本

Status: 11 resolved + 12 done + 1 ready-for-walkthrough（2026-10-09 由 [`map.md`](map.md) 折成
—— 十一张决策票全部 `resolved`、十二张实现票 `done`，只剩票 24 等人真机走查；票号与阻塞边
见 map 的「实现票」一节，本文件是它们的构建计划）

轨迹页今天是一条**只能点开看**的流：想找一件事只能一路读，想看「时间花在哪」得自己心里算，
想收掉一段读不下去的没有折叠，想在里面找一句话只能靠眼睛扫。它把每一块都忠实地画出来了，
但**每一块之间没有关系** —— 没有分组、没有耗时、没有总览、不能选中、不能检索。

这份 spec 把它升格成**可寻址的账本**：DSH 的每一行都是能选中、能折叠、能被搜索与时间轴区间命中的
对象，而衡今天是一串只能点开的行。围着它有四件事 —— **可寻址**（行选择、折叠、搜索过滤）、**结构**
（回合 / 迭代的分组与组头摘要）、**数字**（每行耗时、检视器里的用量与计时拆分）、**另一种读法**
（时间轴总览）。

## 问题陈述

1. **没有分组。** 一个回合里 1 到 557 次迭代、几十上百次工具调用，全部平铺在 15 行可视高度里。
   「这一回合在干什么」这件事今天只能靠读，不能靠看 —— 而往返分隔线之间塞着的几十行里，
   没有人知道哪几次调用是同一轮思考。
2. **没有时间感。** 每块只带一个 `HH:MM:SS` 起始时刻，**每块多长**这件事今天只有一个地方有：
   工具结果的 `duration_ms`，而它没上屏。所以「这 49 秒花在哪」只能靠算，模型等了多久更是无从知道。
3. **不能选中。** 轨迹页今天在键盘阶梯里**没有归属**（只在「当前显示那一页」那一支拿到三键与滚轮），
   于是它没有「我在这里」这个概念。行身份还是**位置型下标**，而它恰好会被两件事推翻：`CAP` 裁剪
   让全体左移、宽度变化让整批重放。
4. **不能检索。** 一场会话几百上千块，想找一句话只能靠眼睛扫。没有索引、没有过滤、没有折叠。
5. **详情只有一个面。** 点开一条工具调用只有一份正文，看不到它的 schema、它属于哪次模型调用、
   它那 3 秒里等了多久审批 —— 而这些都在手边。
6. **页只有一部分。** `CAP = 20 000` 源行，超出就把最旧的丢掉，而「最旧」这件事用户从来看不见，
   直到某天发现翻到顶也看不到头。

## 方案

**给每一块一个身份，给每一行一个落点，然后把三件事接上去：账本结构、时间轴、检视器的面。**

```
 09:12:04 ┄ 回合 1 · 49 s · bash×2 read×2 edit×1 ┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄
 09:12:04 ┄┄┄┄┄┄┄ 09:12:49 ┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄
 09:12:05   第 3 次迭代 · 18 s
 09:12:06   [bash] ls -la src · 1.5 s  in=1.2k out=340
 09:12:09   [read] src/render/pane.rs · 0.2 s  in=3.1k out=4.4k
 09:12:10   [bash] cargo test · 3.0 s  in=… out=…
                      这条不行：Permission asked for 2.4s
 09:12:14   ▸ 回合 2 · 12 个步骤 · 9 个工具调用 · 2.1 s
 ┄┄ 09:12:14 ┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄ 09:12:52 ┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄
 09:12:14 ┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄
```

五条改动轴：

- **结构**：两级分组（**单位** / 迭代），组头**并进**单位之间那条虚线，零额外行数；行首 9 列
  仍是 `HH:MM:SS`；工具行挂耗时，迭代耗时挂二级头。
- **身份**：`Block` 带上从 `Event.seq` 派生的块身份（ADR 0021），窗格多一个「按行键替换任意一行」
  的入口 —— 于是选中、折叠、命中导航、层级跳转、详情跳转五件事都能活过裁剪与重放。
- **时间**：`MessageCompleted` 加一个可选 `first_token_ms`（ADR 0020），内容区顶上固定一条
  **三行横带**（刻度 + 模型泳道 + 工具泳道），横轴是整趟会话。
- **检索**：`/` 进搜索（查询串打在输入区），每块一条索引、块定稿时增量建；过滤与折叠都是
  **重放时推什么给窗格**，所以窗格一个字节不用改就得到真过滤与三档折叠。
- **检视器**：详情覆盖层分成**面**，顶部一条标签条切，**每面各记自己的滚动位置**。

## 用户故事

### A. 账本的结构

1. 作为用户，我想让回合与迭代分成两级组，以便一眼看出「这一回合里有几轮思考」。
2. 作为用户，我想让组头占满单位之间那条虚线而不额外占一行，以便 15 行可视高度一行都不白花。
3. 作为用户，我想让一级组头写出起时刻、序号、墙钟跨度与工具直方图，以便那一行本身就是这一回合的摘要。
4. 作为用户，我想让二级头写出「第 N 次迭代 · N s」，以便模型调用自己有一行。
5. 作为用户，我想让组头摘要**随回合推进而增长**（直方图每来一条长一格），以便正在跑的那个回合也读得出形状。
6. 作为用户，我想让超宽时组头**从右往左丢字段**（先丢直方图尾部，再丢整段直方图），以便序号与跨度最后才消失。
7. 作为用户，我想让工具行在行尾带上自己的耗时，以便不必点开就知道这一调多重。
8. 作为用户，我想让耗时挂在用量**之前**、放不下时**先丢耗时保用量**，以便 ADR 0016 那一行不被侵蚀。
9. 作为用户，我想让耗时格式是一位小数、10 秒以上不带小数，以便扫得出来又不占地方。
10. 作为用户，我想让**拿不到的耗时留空**，以便屏幕上没有一个编出来的数字。
11. 作为用户，我想让迭代耗时挂在二级头上而不是行尾，以便模型调用的耗时分文内宽度都不占。
12. 作为用户，我想让失败行末尾那个红 `失败` 留着，并在下一行多画一句错误正文的首行，以便失败的原因不必点开。
13. 作为用户，我想让 `ok = false` 而没有错误正文时只留那个红 `失败`，以便不出现空行。
14. 作为用户，我想让行首不加 `✗`，以便内容宽度一分不降。
15. 作为用户，我想让**常规成功行一个字也不加**，以便账本还是一份好扫的流。
16. 作为用户，我想让空输出 / 被截断 / 失败这三种异常各补一句结果摘要，以便异常在行上就认得出。
17. 作为用户，我想让开场、上下文压缩、`/clear` 之后这三类不属于任何回合的段落各有一行小标题，
    以便「不属于任何回合」在账本上看得见。
18. 作为用户，我想让消息行仍是「首行 + `…`」，以便这次改动不改它。
19. 作为用户，我想让行首那 9 列仍然是 `HH:MM:SS` 且竖向对齐，以便时刻列还能当一条竖线扫。
20. 作为用户，我想让行上**不给序号**（序号在组头里），以便内容宽度一列都不让给重复信息。

### B. 每块的时间：时间轴

21. 作为用户，我想让轨迹内容区顶上固定一条三行横带（刻度 / 模型泳道 / 工具泳道），以便「时间花在哪」一眼可读。
22. 作为用户，我想让横带**不随账本滚动**，以便它一直当标尺用。
23. 作为用户，我想让横轴覆盖**整趟会话**，以便它是一张全程图而不是一个滑动窗口。
24. 作为用户，我想让模型泳道画出每次模型调用占了哪些格子，以便我知道那一大段空白是不是在等模型。
25. 作为用户，我想让工具泳道画出每次工具调用占了哪些格子（含并发调用互相重叠），以便排队与串行分得开。
26. 作为用户，我想让模型泳道按**首 token 时刻**切成「等首 token」与「吐字」两段，以便那 7 秒里有多少是空白有答案。
27. 作为用户，我想让**不足一格的两段保底不画**，以便轴上不出现编出来的形状。
28. 作为用户，我想让回合边界在模型泳道里画一道竖线，以便回合之间在时间上也分得开。
29. 作为用户，我想让刻度行用区间底色标出**当前视口**，以便我知道眼前这一屏在全程的哪一段。
30. 作为用户，我想让正在进行中的那一段画到当前时刻、右端不收边、不给时长数字，以便流式时轴不说谎。
31. 作为用户，我想让老会话（没有首 token 时刻）时模型泳道**整段画**而不是插占位符，以便缺失不假装成零。
32. 作为用户，我想让宽度不够时横带退成稀疏刻度、再退成一行三态、最后整条不画，以便窄屏下账本优先。
33. 作为用户，我想让高度不够时**账本优先**、整条横带让位，以便可视高度先给内容。
34. 作为用户，我想让横带**不可聚焦、不响应鼠标**，以便它只是一块可读的图而不是另一个交互面。
35. 作为用户，我想让空档（两条泳道都没盖住的列）保持留白而不写解释文字，以便我不读到编出来的成因。
36. 作为用户，我想让「输入」泳道**不做**，以便我不拿注入时刻冒充请求组装的时间。

### C. 检视器：面

37. 作为用户，我想让详情覆盖层分成几个**面**（顶部一条标签条），以便一份详情能装下参数、输出、
    Schema、计时、来源与概述。
38. 作为用户，我想让每种记录的面集合由**一张表**定死，以便我能预知每种详情里有什么。
39. 作为用户，我想让工具详情有六个面（参数 / 输出 / Schema / 计时 / 来源 / 概述），以便它是面最多的那一种。
40. 作为用户，我想让消息与思考各有三个面（正文 / 用量 / 概述 / 思考），以便我能单独看这一条的用量。
41. 作为用户，我想让注入有两个面（注入 / 概述），以便它与消息的读法一致。
42. 作为用户，我想让文件、改动、待办**不分面**（它们本身就是一份完整的可滚动对象），以便不必多点一次。
43. 作为用户，我想让**默认面永远是今天打开就看到的那一面**（工具默认落在参数），以便行为不跳。
44. 作为用户，我想让 `Tab` / `Shift+Tab` 切面，以便覆盖层立着时那个空键终于有用。
45. 作为用户，我想让点标签也能切面，以便不用记键位。
46. 作为用户，我想让**每面各记自己的滚动位置**，以便切回去时还在原处。
47. 作为用户，我想让一个面内部有 ≥ 2 节时画出小节标题，以便滚到中段还认得出在哪一面。
48. 作为用户，我想让用量面分「本次」与「这一趟会话」两节，并写明 `输入 = 缓存读 + 未命中`、
    推理已含在输出里，以便我不把三个数加起来。
49. 作为用户，我想让「本次」的口径与行尾那个 `合计` 是同一个数，以便两处对不上时不担心是自己看错。
50. 作为用户，我想让供应商没报推理 token 时写 `—（供应商未报）` 且**不画条形**，以便没有分母的条不骗人。
51. 作为用户，我想让计时面给出精确数字（开始时刻 / 总时长 / 首 token / 生成 / 吞吐）并写清计时来源，
    以便我知道每个数是哪两个时刻相减。
52. 作为用户，我想让「等审批」这个切分**只在计时面出现**并写清两个口径不可相加，以便我不会把两段读成可加的。
53. 作为用户，我想让老会话上那三个数字写 `不可用` 而不是 0 或占位符，以便缺失不假装成零。
54. 作为用户，我想让「来源」面给出只读的祖先链三环（本行 → 那一迭代 → 那一回合 → 上面那条用户消息），
    以便我知道这一行是被什么带出来的。
55. 作为用户，我想让切面**不改变**谁被冻住、关掉时还原给谁，以便详情覆盖层那条记账一个字不动。
56. 作为用户，我想让覆盖层的**尺寸一行都不动**，以便这次加分面不改变它今天的样子。

### D. 检索：搜索

57. 作为用户，我想让 `/` 在轨迹页上进入搜索，以便不打一串键就能找东西。
58. 作为用户，我想让查询串**打在输入区**（草稿原样存着、退出时原样还原），以便我不在状态行上做行内编辑。
59. 作为用户，我想让进搜索后 `Esc` 能还原草稿，以便我搜错了不会丢原来那半句。
60. 作为用户，我想让查询是空格分词、大小写不敏感、各词 AND，以便三个词能逐步收窄。
61. 作为用户，我想让索引**覆盖整场会话**而不是窗口内的那些块，以便早就滚出屏的记录照样搜得到。
62. 作为用户，我想让搜索是**块级**的（一块命中，它那几行一起算），以便我不逐行读结果。
63. 作为用户，我想让搜到的块在账本上**真过滤**（未命中不占行），以便结果就是结果。
64. 作为用户，我想让过滤期间**跟随暂停**、命中的新块照样进账，以便我不被新内容顶走。
65. 作为用户，我想让过滤期间组头**保留且不改写**，以便退出过滤时画面不跳变。
66. 作为用户，我想让 `n` / `N` 跳下一个 / 上一个命中并把选中移过去，以便我能沿命中走一遍。
67. 作为用户，我想让退出过滤回到原处，以便过滤没有破坏我的阅读位置。
68. 作为用户，我想让**还没定稿的增量块不进索引**，以便索引里没有一个还在变的记录。
69. 作为用户，我想让改一个字符就实时重算，以便我不需要按回车。

### E. 检索：折叠

70. 作为用户，我想让一个回合可以折成一行摘要，以便长回合不再占满屏幕。
71. 作为用户，我想让一次迭代可以折成一行，以便一段密集的思考收起来。
72. 作为用户，我想让**同一迭代下相邻的工具调用**折成 `M 个工具调用 · a, b` 一行，
    以便一个 557 次迭代的回合读得动。
73. 作为用户，我想让折行沿用组头的格式、虚线保留、`▸` 出现，以便「这里有折起来的东西」一眼可读。
74. 作为用户，我想让 `▸` **只在折叠态出现**（展开态不用它），以便那个字形有一个意思而不是两个。
75. 作为用户，我想让折行**就是那一行**（可选中、可开详情、`Space` 展开），以便折起来的东西不是死的。
76. 作为用户，我想让点组头字形也能折 / 展，以便不必记键位（不做双击）。
77. 作为用户，我想让 `{` / `}` 全折 / 全展，以便一秒清屏或一秒还原。
78. 作为用户，我想让全展**还原到进入全折之前的那份折叠态**，以便全折不会抹掉我自己折的东西。
79. 作为用户，我想让无主段落不折（开场 / 压缩 / 新会话段本来就一行），以便那里没有可折的子结构。

### F. 行选择与导航

80. 作为用户，我想让轨迹页成为**键盘的一层归属**（只在它持有键盘时认那些键），以便选中、折叠、

## 实现决定

### §0 落地顺序（依赖图，不是排期）

八条冻结项之一是「交付一张图一次拆完」，下面是这个顺序的理由：**每一层落地时屏幕上都有一个
可验收的新行为**，而没有任何一步需要等后面的层。

1. **事件面那一笔**（`first_token_ms`，ADR 0020）—— 不依赖这次 effort 的其他任何部分，先做。
2. **块身份 + 窗格的新入口**（ADR 0021）—— 账本结构、选中、折叠、搜索都站在它上面。
3. **账本结构**（两级分组、组头、耗时、失败、无主段落）—— 纯显示，落在第 2 步之上。
4. **键盘归属层 + 选中 + 层级跳转** —— 落在第 2、3 步之上。
5. **检视器的面** —— 与 2–4 无耦合，可以任意插在中间。
6. **搜索与折叠** —— 落在第 2、3 步之上。
7. **时间轴** —— 落在第 1、2 步之上。
8. **读法**（浮字位那一行、命中底色）—— 落在第 6、7 步之上。

### §1 数据面：一个可选字段 + 一个身份

- **`MessageCompleted` 加 `first_token_ms: Option<u64>`**：首个增量 token（`TextDelta` 与
  `ReasoningDelta` 先到者）距本次调用开始的毫秒数。三处产点在主循环与合成器；**用户消息那一条恒
  `None`**。`SCHEMA_VERSION` 跟着涨一档（它只是记号，代码里没有按版本分派的读取逻辑）。
  可选形状给出双向兼容：老流缺字段读成 `None`，老二进制读新流忽略未知字段。
  **不给这一批事件新增变体** —— 那是单向不兼容，老二进制的 `read_events` 会拒读整条流
  （`--continue` / `sessions show` / `sessions replay` 全挂）。
- **一个字段推出三个数**：TTFT = 它；生成时长 = 完成时刻 − (开始时刻 + 它)；吞吐 = 输出 token ÷ 生成时长。
  三处只用现成字段。
- **块身份从事件信封派生**：`Painted` 与 `Block` 带上 `seq`（今天 `apply` 只取 `at` 就把它丢了）
  加**块内序号** —— 一条事件可以产出零个到多个块，所以「一个 `seq` 对应一个块」今天不成立。
  块在流式期间（`Block::Delta`）就取一次号，定稿不换身份。
- **两块随块一起走的数据**：块的首行时刻（今天已有）与工具耗时 / 失败信息（今天已有）。

### §2 身份记账：「块 → 源行」

- 渲染层记一份**块身份 → 源行**的账，活过两件事：`CAP` 裁剪（窗格内一切下标统一左移）与
  宽度变化重放（整批源行重放）。**位置下标两条都活不过**。
- 覆盖层那三处入口（点行开详情、层级跳转、命中导航）统一走这份账；今天那条「屏幕行 → 源行下标 →
  链接表」的路径保留为它的实现。
- **不做**：反向的「源行 → 第几个显示行」通用入口。今天的窗格已经有一个按源行滚过去的入口，
  补上索引查找就够，不新增第二个。

### §3 窗格：只加一个入口

- 公开面加**「按行键替换任意一行」**（今天只有「改最后一条」，那个是思考行在用的）。
  唯一消费者是组头的增量增长（§5）。
- **折叠与过滤不走这里**：它们是**重放时推什么给窗格** —— 走一遍与宽度重放同路径的重放
  （取走整份 `painted` → 逐块重推），被折的块只推一行折行、未命中的块一条源行都不推。
  所以**窗格今天没有「删掉一段行」的入口，而这次也不需要**。
- 过滤与折叠因此合成**同一个机制**，顺序是**过滤先**（哪些块在）、**折叠后**（块画几行）。
- 过滤期间「命中块强制展开」是**重放层的临时覆盖**：折叠集合本身一个字节不动，所以不需要额外记一份
  「原折叠态」，退出过滤自然还原。
- 触发重放的时机：进搜索改串、出搜索、折叠、展开、全折、全展、清过滤。滚动意图由窗格
  `clear` 保留的视口锚点兜住。
- **`CAP = 20 000` 一个字不改**：块全在共享源里（窗格裁的是折好的显示行与两张平行表），
  整场会话从会话文件原样重放。要「画回来」只有重放式虚拟化一条路（那是以后的 effort）。
- **回合条不动**：它只与对话窗格平行；重放只清轨迹窗格与它的链接表。

### §4 键盘归属：新增一层

- 轨迹页成为键盘阶梯里的**一层**，判据两半：**主列当前显示页是轨迹** 且 **没有处于「已交还」状态**。
  位置在**详情覆盖层之下、记号菜单之上**（`/` 必须先到搜索）。
- 覆盖层立着时它持有键盘，**嵌套在轨迹页那一层之上**；关掉覆盖层**恢复轨迹页层的原状态**
  （交还过就还是交还着）—— 照「切面不改变谁被冻住」那条纪律。
- **焦点只有一个布尔状态**：默认持有（当前显示页持有），`Esc` 退完三层把它交还给输入区，
  **点账本任何位置**拿回，重新成为当前显示页时**自动回到持有**。
- 轨迹页这一层**不画「键盘所在」的反显**：全屏唯一的反显仍只给问卷与记号菜单（详情覆盖层今天也
  不画），账本里**选中行自己就是那个锚点**。这一层是仓库里**第四套**「键盘在谁那里」的机制
  （前三是左栏的布尔、两页各自的焦点索引、反显的隐式归属）—— 与左栏两页同形，将来要统一是以后的活。
- 收编的键与它们今天的归属：`↑` / `↓`（编辑器光标）、`Enter`（提交）、`Space`、
  `/`（记号菜单）、`Tab` / `Shift+Tab`（模式循环）。新绑的（全局原本无绑定）：`j` / `k`、`n` / `N`、
  `g` / `G`、`[` / `]`、`{` / `}`、`/`。**不征用** `Home` / `End`（编辑器的行首行尾）。

### §5 账本结构

- **两级分组，成员不缩进**：一级是**单位**（交互会话数回合：起始迭代为 1 的 `TurnStarted` 到
  `TurnEnded`；讨论会话数轮次：`RoundStarted` / `RoundEnded`），二级是**迭代**（`TurnStarted.iteration`）。
  可执行的边界判据就是那三个事件。讨论会话不额外给「发言」一级 —— 发言者身份沿用既有的 `[名字]` 前缀。
- **成员一律从第 9 列起排**：层级由头行承载，工具行保住它的内容宽度（两级缩进会把它压到 36 列）。
- **组头并进单位之间那条虚线**（框架字形、跨度与今天的分隔线一致，**含时间戳那 9 列**），
  占一行、零额外行数。字段顺序：**起时刻 · 序号 · 墙钟跨度 · 工具直方图**，
  一级头像 `回合 1`、讨论里 `轮次 2`；二级头是弱色单行、不带虚线，`第 N 次迭代 · 18 s`，
  行首那格放它自己的起时刻。
- 起时刻 = 该单位第一条边界事件的 `at`；跨度 = 起时刻到收尾事件的 `at`；直方图按工具名计数、
  同类归并成 `bash×6`；**拿不到的字段整个不画**。
- 超宽**从右往左丢**：先丢直方图尾部，再丢整段直方图，序号与跨度最后丢。
- **摘要在单位开头就画、随单位推进而增长**，收尾那刻定稿 —— 靠 §3 的「按行键替换任意一行」。
- **正在跑的那个一级组**：组头照常画（它照实反映到此刻为止的直方图与跨度），**不另造一个「进行中」样式** ——
  着色留给语义色板那一档既有语义，不新发明。
- **行首 9 列一个字不动**：只放 `HH:MM:SS` 加一个空格，行上不给序号。
- **工具行耗时**：行尾、用量之前，`· 1.5 s`；秒为单位、一位小数、≥ 10 s 不带小数
  （`0.2 s` / `1.5 s` / `49 s`）；这次调用**还没有结果**的、宽度放不下的都**空着**。
  口径 = 工具完成的 `duration_ms`（调用墙钟，含钩子、权限与排队）。取消与策略拒绝合成的那一条
  结果也带一笔墙钟，而那是排队加取消那一刻、不是工具花的时间 —— 流上它与真跑过的调用同形，
  所以行上照画；要它留空得给 `ToolCallCompleted` 一个「跑过没」的位（票 17 的落地注记）。
- **行尾溢出顺序**：先丢耗时、保用量。
- **迭代耗时**挂在二级头上。口径 = 该次 `TurnStarted(k).at` 到下一个**同 speaker** 的 `TurnStarted`
  或该回合收尾事件的 `.at`。
- **失败**：行尾红 `失败` 保留；**错误正文首行多画一行**（从第 9 列起、弱色）；`ok = false` 而没有
  错误正文时第二行不画；**错误 code 不做**（流上只有一段文字，要 code 得动流）。
- **结果摘要只在异常时给一句**：常规成功行一个字不加；空输出 → `· 无输出`；被截断 →
  `· 已截断 18842 字符`；失败按上一条走。那一句报的是**流上真有的那个数**：工具结果自己头尾
  预览里嵌着的那句 `[已截断：N 字符，约 M token；全文在 …]` 只有字符数与 token 数，**行数不在
  其中**（要它得动流，2026-10-10 维护者裁决不做）。上下文组装期那一处标记不进工具结果，
  **行上读的是工具输出自己的头尾那一路**，两处不混成一个数。
- **三类无主段落各一行小标题**（形状与组头同族：不缩进、弱色、不带虚线、**不是把手**）：
  `▸ 开场 · N 条注入`、`▸ 压缩 · 上下文过半，前面 N 轮压成摘要`、`▸ 新会话段（上一段留在磁盘上）`。

### §6 检视器：面

- 详情从「一份正文」变成「一组面 + 当前面」：面 = `{ 名称, 行, 滚动位置 }`，**每面各记自己的 `top`**。
- **一张按记录种类穷举的表**（不是「面自己声明适用性」——那会让同一个知识散在几处，编译器不提醒）：
  `Message` = 正文 · 用量 · 概述；`Thinking` = 思考 · 用量 · 概述；`Context` = 注入 · 概述；
  `Tool` = 参数 · 输出 · Schema · 计时 · 来源 · 概述；`File` / `Diff` / `Todo` = 单面、**不画标签条**。
  **默认面永远是今天打开就看到的那一面**（工具默认落在**参数**：「概述」排在末尾）。
- 标签条借走主体**一行**、复用既有的标签条画法，每个标签记一个命中矩形供点击；切面键 `Tab` / `Shift+Tab`
  （覆盖层立着时它们是空键，不撞输入框换行与模式循环）。
- **覆盖层尺寸一行都不许动**：尺寸算术仍然只有那两处（文字区宽与内边距）；100×30 实测是
  **96×26**（宽度 = 100 − `MODAL_MARGIN`(4)、高 = 30 − 框与内边距那几行；原文那个「92×26」
  是票 13 落地时更正的旧数字，见它的 `## 落地记录`）。
- 小节标题的判据（**这一面 ≥ 2 节**）在生成面那一步就决定。
- **用量面**：五个桶（输入 / 缓存读 / 未命中 / 输出 / 推理），算法与左栏用量面板**同一套**；
  两节「本次」与「这一趟会话（到这条记录为止）」，末尾一句口径
  **`输入 = 缓存读 + 未命中；推理已含在输出里，这两条不能再相加`**。推理为 `None` 时写
  `—（供应商未报）` 且**不画条**。「本次」跨多次调用时就是那几次之和，与行尾那个 `合计` 同一个数。
- **用量面挂在消息与思考详情上，不挂工具详情**：工具调用**没有用量**（用量事件带发言者不带工具调用 id，
  行尾那条用量尾巴也只挂在消息与思考上）。
- **计时面**：每节末尾一行**计时来源**，写清是哪两个时刻相减。首 token / 生成 / 吞吐三项在老流上
  **不存在**：写 `不可用`，并把原因写进同一行的「计时来源」，不另起一句、不填 0。
  **降级**：拿不到「这次模型调用」的归属时（工具行属哪次模型调用今天没有记账），这一面**只出现
  「这次工具调用」一节** —— 面上只画它自己能证明的那一段。
  工具的**两个口径**（总跨度与等审批切分）并排出现，要写清「两个口径，不是两个可相加的数」。
- **参数面 / 输出面**：参数今天已经是 `pretty` JSON 按宽度折行，零改动；输出读落盘全文、**原文加缩进**；
  **不做 JSON 树**（树要键入交互才划算）。错误与「没有结果」照今天的样子。
- **来源面**：只读的**祖先链三环**（本行 → 它上面那条迭代的回复 → 那一回合 → 上面那条用户消息），
  链深不封顶所以**固定截到三环**并写清。它**不押在稳定行键上**：拿不到行身份时它退成只读链仍然有用。
- **原文面不做**：消息 / 思考 / 注入的正文本来就是流上的原文字符串（渲染层里没有 markdown 渲染
  函数），工具输出也有落盘全文 —— 那几类**今天已经是原文面**；缺的只有事件信封的 JSON。
- **覆盖层记账不升级**：切面不改变谁被冻住、关掉时还原给谁。

### §7 搜索

- **入口键 `/`** 归 §4 那一层。**同一个物理键两层换含义**（打字时 `/` 弹记号菜单、轨迹页持有键盘时
  `/` 进搜索）—— 这是浮层那条纪律的应有之义，不是破例，写进逐面文档。
- **查询串打在输入区**：进搜索时输入区切到搜索模式，**草稿原样存着、退出时原样还原**（复用既有编辑器的
  缓冲、光标、行内编辑与拖选）。搜索模式里：普通键改串、`Backspace` 删字、`Enter` 接受并离开搜索模式
  （**不提交草稿**）、`Esc` 取消并还原草稿。改一个字符就实时重算（不设节流）。
- **不给状态行做行内编辑**（全仓没有那个先例）。
- **索引**：**每块一条记录，字段 = 块自己那段文字的全文**（工具摘要、消息正文、思考、注入正文、
  工具参数与输出）；不另立字段、不做分词预处理。
- **建索引的时机 = 块定稿进共享源那一刻**，增量建、只建一次；**重放不重建**（重放换的是窗格的行，不是块）。
  **未定稿的增量块不进索引** —— 它还在变；它定稿那一刻建索引并触发一次重放，于是它若命中就出现在
  过滤视图里。
- **索引覆盖整场会话**，不受 `CAP` 裁剪（`CAP` 只裁窗格不裁块）。所以文档里要说成「搜的是整场会话」
  而不是「搜窗口内」——**这是与 DSH 不同的一档**。
- **不做截断**：截断就是拿一个静默的洞换内存，搜不到的东西没人知道。
- **查询语义**照 DSH：空格分词、大小写不敏感、各词 AND。没有引号短语、没有正则、没有模糊匹配。
- 索引记的是**事件里那份文本**，它可能已被截断；而输出面读的是落盘全文 —— **两处口径不同，
  界面上不许混着说**。
- **搜索串只活在进程内**，切会话 / 恢复会话不持久（照轨迹页既有纪律，也照 DSH：视图本地状态）。

### §8 折叠与过滤

- **过滤**：账本上**只剩命中块**。**组头保留且不因过滤改写**（它是该单位全体成员的直方图，不是命中成员的；
  命中数由那一行给）。跟随暂停。退出过滤回到原处。
- **折叠三档**（与两级分组对齐）：**单位** / **迭代** / **连续工具调用**（同一迭代下相邻的几次调用折成
  `M 个工具调用 · a, b`，这是 557 次迭代的回合唯一读得动的手段）。
- **折行沿用组头的格式**：一级折行 = 组头那行的字形换成 `回合 3 · 12 个步骤 · 9 个工具调用 · 2.1 s`
  （虚线保留、`▸` 出现）；二级折行 = `第 7 次迭代 · 4 个工具调用 · 18 s`。
- **折行就是那一行**：它是一个源行、可选中、`Enter` 开详情、`Space` 展开，链接照挂。
- **点组头字形 / 点折行 = 折 / 展**。**不做双击**（今天根本没有双击识别，`DRAG_THRESHOLD` 只分
  「点击 vs 拖选」；两次相邻单击就是两次点击）。**悬停同理**，在范围之外。
- **全折 / 全展**（`{` / `}`）：全折把整本账折到只剩各级组头与折行（正在跑的那个回合也折）；
  **全展还原到进入全折之前的那份折叠态**，不是「清空折叠态」。
- **无主段落不折**：它们本来就一行，没有可折的子结构；开场那串注入若太长，折成**一行**
  `▸ 开场 · N 条注入 · …`，不是可展开的一组。
- **过滤集只有一个，来源只有搜索命中**：行选中不产生过滤（选中只有一行），时间轴也不产生过滤
  （轴的输入是选中与命中，它自己是消费方）。**时间轴区间聚焦整体不做。**

### §9 选中

- **粒度 = 块**：一个块的第一条源行是落点，附属行（错误正文那行、还在长的增量行）跟着所属块一起高亮、
  **不能单独选中**（选到那里 `Enter` 无事可做）。折行也占一个源行，它就是那个块的落点。
- **画法**：整行 `ACCENT + BOLD`（照左栏文件页 / 改动页 / 页签条的先例，**不新开通道**）。
  不用底色（底色在界面上是内容语义）、不用反显（全屏只许一个，且会把选中洗白）。
- **与用量的关系**：选中行必然在过滤集里（过滤期间账本上只有命中块），所以它与命中底色不同时出现。
- **点击**：点一行 = 开详情（**今天这条语义明确保护**）；点空白 = 拿回键盘 + 清选中（清一个空选中
  是无操作，所以两个动作叠在一个手势上不打架）。
- **粘性**：宽度变化重放之后**认块不认位置**、留在原处；切主页签不动；滚动与翻页**不推动**选中；
  滚出视口**不拉回来**（视口照跟随走）；选中的块不在新过滤集里时**留着、只是不画**。
- **层级跳转**：`[` 到所属组头（回合 / 迭代）、`]` 到该组第一条成员行；**从组头再按 `]` 就是进它的
  第一条成员**，于是两级分组兑现成可导航的结构。方向键里没有第三个方向可用（`←` / `→` 在左栏两页
  已被占用），所以用两个成对的括号键。
- **`G`** = 跳到最新**并恢复跟随**；过滤期间它**只恢复跟随、不动过滤**（退出过滤归 `Esc` 的层序）。
- **`Esc` 层序**：搜索模式 → 有过滤则清过滤 → 有选中则清选中 → **交还键盘**。

### §10 时间轴

- **一条固定在内容区顶部的三行横带**：刻度 + 模型泳道 + 工具泳道，**不随账本滚动**。
- **几何必须两处一起改**：顶部固定区从 2 行撑到 5 行（矩形高度 + 画家那处硬编码的 `+1`），
  同时把外壳高度从 6 改成 9。只改前者会把状态行与底部块顶出屏幕，只改后者固定区没有位置。
  代价：120×24 下轨迹页可视从 15 行变成 **12 行**。
- **宽度口径（更正原型帧）**：主列 79 列 → 扣滚动条与回合条那 2 列 → 扣行首 9 列 → **正文 68 列** →
  泳道标签 5 列 → **横轴 63 列**（原型帧里的 74 / 70 是它自己把 79 当正文宽的假设）。
  一格 ≈ 0.76 s 那次实测是 48 秒的会话，**不是常数**。
- **模型泳道**的一条 span = 该次 `TurnStarted(iteration = k).at` → 下一个**同 speaker** 的 `TurnStarted`
  或该回合收尾事件的 `.at`；按首 token 时刻切成**「等首 token」与「吐字」两段**，**不足一格不画**。
- **工具泳道**的一条 span = `ToolCallStarted.at` → `ToolCallCompleted.at`；**并发调用会重叠**，泳道要能叠。
- **回合边界**在模型泳道里画一道竖线；**迭代边界不标**（太密）。**空档保持留白**，不写解释文本。
- **轴域 = 整趟会话**（不滑动、不缩放）；**视口**用刻度行的区间底色标出，不额外占行。
- **整趟跨度增量累积**：在数据到达时维护一份 span 表，轴每帧只读它 —— **不每帧重扫整份块**
  （块数随会话线性长，今天也没有别处每帧遍历全部块）。
- **流式中**：进行中的段画到当前时刻、右端不收边、**不给时长数字**。
- **降级阶梯**：宽度不足 → 稀疏刻度 → 一行的三态版 → 整条不画；高度不足 → **账本优先**，整条让位。
- **不可聚焦**：不进键盘阶梯、不响应鼠标、不产生过滤。
- **明确放弃**：拖选、缩放、平移、悬停；行内迷你条；贴状态行或并进状态行；4 行版与独立的空档泳道；
  「输入」泳道；轴上标迭代边界；把等审批的切分画到轴上。

### §11 读法：过滤态在界面上哪里

- **状态行一个字都不动**：它两个视图共用（每帧画一次），而过滤只属于轨迹页。
- **命中数写在内容区右下角那个浮字位**（与「新内容指示器」同一位、同一色、同一贴边算术，
  每视图各一个）：`n 个命中`；自进入过滤以来有新命中块到达时加 `· 新增 M`
  （**M 是新到达的命中块数，不是新到达的行数**）；**无匹配就写 `0 个命中`**（同一句话）。
  滚到底恢复跟随后「新增」清零。
- **过滤期间那个位置整句让给命中读法**，因此那一刻它**不再是可点的手势位**；回到最新由 `G` 承担。
  非过滤期间它的行为逐字不变（`N 条新行` / `回到最新`，可点）。
- **轴上的命中**：连续命中**合成一段底色**铺在**模型泳道与工具泳道那两行**；
  两个命中块之间**间隔小于一格**算同一段，大于等于一格才断开（阈值跟分辨率走，不写死秒数）。
  **刻度行的底色只给视口区间**，两个底色是两个具名常量、两个语义。
  **未命中的段不调弱**（只是不加底色）：省一档色阶，而底色已经是零先例的第四个通道。
- **落轴的判据**：**属不属于一次模型调用或一次工具调用**。工具类落工具泳道、模型类落模型泳道；
  **注入、问卷作答、命令、开场段落不落轴**。于是「搜到的命中不一定都在轴上出现」
  （搜的是整场会话，轴是两种时间的摘要）—— 这条限制写进逐面文档，不是缺陷。
- **轴上的选中标记**是一根**前景记号**（与回合边界同一个字形族），语义是「位置精确、长度有下限」，
  画在**选中块的首行**那一刻。底色是背景、记号是前景，**两者正交、同格共存**，所以不需要定谁压过谁。
- **不做**：时间轴区间聚焦（拖选一段把账本聚过去）、把命中的判据做成「跨度相交 / 开始时刻落在区间里」
  （区间这个输入已被取消）。

### §12 色板与通道

- **新增两档底色**（界面域，语义名）：**视口区间底色**与**命中底色**。两者语义不同、
  分属不同的行，因此不必互相区分到不可分辨，但**必须能被分辨开**。
- 底色通道今天**零先例**（全仓五处底色全是内容语义），这是界面上**第四个通道**。走既有那族色板纪律
  （语义色板是取色的唯一出处、绘制代码只引语义名）。
- **不新增字形**：分隔线用框架那套虚线、回合边界与选中标记用同一族竖线、折叠才用 `▸`。
- **反显通道继续封着**：全屏唯一的反显是「键盘所在」，消费者只有问卷与记号菜单。

### §13 文档

- `CONTEXT.md`：**账本**、**选中**、**行身份**、**新内容指示器**、**详情覆盖层**、**面**、**时间轴**、
  **首 token 时刻**、**命中**、**过滤**、**折叠**、**单位**几条词条（本 effort 期间已随票落下）；
  **轨迹视图**词条里「滚轮与三键都归当前显示的那一页」那句要改成新的两层归属。
- `docs/render.md`：**两个视图**一节（两级分组、组头并进虚线、耗时与失败）、新增**时间轴**一节、
  **键盘**一节（新增那一层归属、`Esc` 层序、键位表）、**时间戳**一节（组头与二级头也带时刻）。
- `docs/tui-manual-checklist.md`：轨迹那一条从「主列的第二页、时间戳与轮次分隔线」扩成走查项 ——
  两级分组、组头字段、每行耗时、时间轴三行、选中与折叠、搜索过滤的键盘流。
- **三处文档纪律要跟着**：`/` 在轨迹页与记号菜单两义、`Enter` 在搜索模式里不提交草稿、
  搜到的命中不一定都在轴上。
- 新增的 `docs/**` 一律过文档密度护栏的压表达规则。
- 启动检查脚本**不受影响**：它只要求身份在场与虚线的数量，从不要求某一页上写着什么；
  横带若选了框架那套虚线，它的计数自然上升，而那是「至少三格」的降级护栏、不红。

### §14 不改

事件 schema 除 `first_token_ms` 之外的任何形状；`seq` 与信封；对话视图与它的 pane；
plain / headless 渲染器；`Block` 层的产生规则；回合条与它的 `Viewport` 判定；状态行与它的宽度阶梯；
提示行与输入区（搜索模式是它的**一种模式**，不是新件）；记号菜单；问卷与它的键位；
左栏两页与它们的焦点行；详情覆盖层的尺寸算术与 `detail_opener` 记账；
`wording::status_row`；`CAP = 20 000`；历史重播与 `sessions` 三条动词；模型可见文本与投影。

## 测试决定

- **一个主 seam：`draw_frame`** —— 一个 `TuiState` 进去、一块定尺的 `Buffer` 出来
  （既有层，`tests/render_layout.rs` / `tests/render_tui.rs` / `tests/history_replay.rs` / `tests/ask_user_question_tui.rs`
  都在它上面）。**不新增 seam。**
- **三个既有低层 seam**，各管一件 `draw_frame` 够不着的事：
  - **纯函数层**：搜索索引的建立与查询语义、耗时与跨度的格式化、轴的 span 表与一格换算、
    分派表（`DetailKind → 面集合`）。先例：`tests/wording.rs`、`tests/render_editor.rs`。
  - **窗格自身的单测**：那个「按行键替换任意一行」的入口（替换不存在的行、空窗格、替换后视口锚点不动）。
    先例：窗格里那两条 `CAP` 单测。
  - **事件流与历史重放**：新增那个可选字段的兼容（旧流读成 `None`、新流被老形状忽略、
    重放路径与实时路径同值）。先例：`tests/event_log.rs`、`tests/history_replay.rs`、`tests/replay.rs`。
- **帧层只进高风险处**（维护者的口径），其余交给纯函数：
  - **几何与降级**：横带三行的位置与高度、外壳高度从 6 到 9、轨迹页可视 15 → 12、
    横轴宽度 63、正文 68、窄屏下横带的三级降级、窄到只剩 12 行时账本仍在。
  - **键位分层**：轨迹页持有键盘时那一串键各自的动作；`Esc` 的四层顺序；
    交还之后 `↑` / `↓` 回到输入区、点账本能拿回；覆盖层立着时轨迹页那层不生效。
  - **过滤 / 折叠 / 选中三者的组合**：搜完过滤视图里只有命中块、组头没被改写、
    过滤期间新块进账而视口不动、退出过滤回到原处；折叠三档各折成什么样、全展还原到全折前那份折叠态；
    选中的块被过滤掉时高亮消失但退出过滤后还在。
  - **重放与身份**：改宽度之后选中的那一行还在原处、组头那一行被就地改写而不是多出一行。
  - **检视器**：标签条出现与消失（三种单面详情不画它）、切面、各面各记自己的滚动位置、
    页脚那对数只报当前面、覆盖层尺寸不变。
  - **读法**：过滤期间右下角那一行的三种文案；刻度行的底色与泳道行的命中底色落在不同的行。
- **不测实现细节**：不断言窗格内部字段、不为「两层键盘归属」写白盒断言（它的可观察后果全在屏幕上）、
  不用断言内部集合的名字去代替「屏上出现了什么」。
- **既有断言按新归属改写**：轨迹页那几组的屏上预期（行数、分隔线、时刻列）、
  回合条与轨迹页互不影响的断言、窗口高度相关的几何断言。
- **文档与护栏**：`cargo test` 全绿、`cargo clippy` 干净、`cargo fmt --check` 只留既有漂移、
  文档密度护栏与语言护栏通过、启动检查照旧。
- **真机走查**（`cargo test` 看不见的那一半，进手工清单）：横带在真实字体与真实终端宽度下的读法、
  两档底色在不同主题上的可分辨性、79 列正文里组头与行尾并排时的密度、
  长会话里折叠与过滤的实际手感。

## 明确不做

- **虚拟化引擎**：衡有自己的窗格窗口与 `CAP`；「只挂载可见行」在字符格里不是问题。
- **分页 / 「加载更早的历史」/ 滚到顶部自动加载 / 行键在 prepend 时的稳定性**：要救的东西**没丢**
  （块全在共享源里、整场会话从会话文件原样重放）。以后要做，正解是重放式虚拟化，不是读盘。
- **聚合条数**（写成「共 N 行 / 已加载 M 行」）：字符格里没有屏幕阅读器这个消费者；
  且「不加载更早」之后那一半恒等于总数。
- **`aria-*` / `role` / `tablist` 那一整套 Web 无障碍树**、**悬停 tooltip**、**像素手势**
  （滚轮缩放 / 右键平移 / 边缘自动平移 / 拖选调宽 / 双击）：字符格里没有这些词。
  真正对应的是「键位不落空 + 每一层都有 `Esc` 出口 + 键盘拿得到也还得了」三条。
- **`Enter` / `Space` 选中行**（DSH 用它们选中）：衡把 `Enter` 留给「开详情」、`Space` 留给「折 / 展」。
- **深链接与选择持久化**：DSH 自己也没有（记录选择与时间轴区间都是视图本地状态）。
- **时间轴区间聚焦**：轴不产生过滤，视图里唯一的过滤集来自搜索命中。
- **图片与附件面**（缩略图、灯箱）：衡还没有图像输入。
- **`run_code` / PTC 那一族的代码检视与子调用缩进**：衡没有工具内派发这种工具。
- **原文面 / prompt 差异面 / system prompt 面 / 工具目录面**：见 §6 的理由。
- **事件的原始 JSON**：见 §6 的理由。
- **模型面**：一块都不动 —— 轨迹是视图，模型可见文本与投影零变化。

## 补记

- **两条 ADR 的分工**：0020 动事件 schema（唯一一处，可选字段，双向兼容）；
  0021 只动渲染层内部（事件流一个字节不改）。实现时**先落 0020 那一笔** —— 它不依赖这次 effort 的
  其他任何部分。
- **三个被事实推翻的票面前提**（都在票的 `## 作答` §0 里，别照票面那句话去做）：
  「命中高亮用底色」在界面上**零先例**（那是新开的第四个通道）；
  `apply` 今天把 `seq` 丢了（块身份要接上）；
  「更早的历史还在磁盘上、要不要开个口子」——**要救的东西根本没丢**。
- **一处宽度口径的更正**：原型帧里把 79 当正文宽，算出 70 列内容与 74 列横轴；
  实现里 79 是**主列宽**，正文 68、横轴 63。帧的**代价结论方向不变**，数值偏乐观。
- **词汇**：`unit` 那一级的中文名是**单位**（交互会话数回合、讨论会话数轮次）；它是视图层的统称，
  流上的事件仍叫 `TurnStarted` / `RoundStarted`。不另造「发言」这一级。
- **产物**：四张形态票的帧在 [`prototype/`](prototype/)（脚本 + txt，脚本带每行显示列自检），
  三张事实票的底账在 [`research/`](research/)。实现时如果帧与这一份 spec 冲突，**以 spec 为准** ——
  帧是提高讨论保真度的一次性产物。
- **折 spec 时的纪律**：每条决定只存在一处——细节在票的 `## 作答`、索引在 [`map.md`](map.md) 的
  「已定的决定」、逐条对齐与「不做」在 [`parity.md`](parity.md)。本 spec 是构建计划，不复述理由。
