# 对齐矩阵：DSH 的轨迹 × 衡的轨迹页

这张表回答「对比 DSH 的『轨迹』，衡缺什么」。它是 [`.scratch/trace-ledger/map.md`](map.md)
的路标与索引，**不是决策** —— 判定的依据在票里，落地的形状在折出来的 spec 里。

## 读法

- **DSH 侧的事实**来自本机安装的发布产物（不是源码仓库）：
  `/usr/lib/node_modules/@deepseek-ai/dsh/node_modules/@deepseek-ai/dsh-client-ui-trajectory`
  的 `README.md` / `README.zh.md` / `lib/types/client/*.d.ts` / `lib/client.js`（2026-10-09 读）。
  它是 dsh web 客户端的一个 view（`conversation.view` 环里的 `trajectory` 页），只读投影，
  不注册服务、不碰模型面。
- **衡侧的事实**来自本仓库今天的代码与文档：`src/render/`（`tui.rs` / `pane.rs` /
  `transcript.rs` / `layout.rs` / `wording.rs` / `links.rs` / `palette.rs`）、`docs/render.md`、
  `CONTEXT.md`，以及 `trace-tab` / `trace-in-main` / `trace-thought-stamp` / `trace-usage-tail`
  四条已落地的 spec。
- **判定**只有四种，每种都必须给结论，哪怕结论是「不做」：
  - **已对齐** —— 衡今天的做法与 DSH 那条在语义上等价（形状当然不同）。
  - **补齐** —— DSH 有、衡没有，这次要做。
  - **变形做** —— DSH 那条在 TUI 里不能照搬，但它的**用途**能用一个字符格里的做法兑现；
    具体形状归票。
  - **不做** —— 明确排除，理由写在这张表里，同时出现在 map 的「范围之外」。
- **平台不对称是前提**：DSH 是 React + DOM 的 pixel UI（虚拟化、像素测量、滚轮缩放、右键
  平移、500 ms hover、lightbox、CSS 主题变量、`ResizeObserver`），衡是 ratatui 的字符格。
  「不做」的绝大多数属于这一类，不是能力差距。

## C. 检视器（详情覆盖层）

判定已由 [检视器的面与内容](issues/08-grilling-inspector.md) 收口（2026-10-09，`resolved`；形状的候选与账由 [检视器分面的形态](issues/07-prototype-inspector.md) 给）。

**分派表**（按 `DetailKind` 穷举七行，实现落成一处可测的常量）：`Message` = 正文 · 用量 ·
概述；`Thinking` = 思考 · 用量 · 概述；`Context` = 注入 · 概述；`Tool` = 参数 · 输出 ·
Schema · 计时 · 来源 · 概述；`File` / `Diff` / `Todo` = 今天那一面，**面数 ≤ 1 所以不画标签条**。
默认面永远是今天那一面，工具默认落在参数。

| DSH 的轨迹 | 衡今天 | 判定 | 落哪 |
| --- | --- | --- | --- |
| 分面切换（概述 / 预览 / 原始 / 来源 / 参数 / 结果 / Schema / 计时 / 用量 / 差异） | **一个面**（正文），`DetailKind` 七种各是一个整面 | 补齐 | **已定**：顶部一条标签条（`draw_label_bar`，借走主体一行），`Tab` / `Shift+Tab` 翻（覆盖层立着时独占键盘、`Tab` 空着）、点标签也切；**各面各记自己的滚动位置**；面里的小节标题**只在 ≥ 2 节时画**；页脚只给当前面的 `↕ pos/total`，不加面号 |
| 用量面：本次 + 会话累计，分桶（输入 / 缓存读 / 缓存写 / 其他 / 输出 / 推理 / 内容） | 行尾 `in=… out=…`，一次发言跨 ≥2 次调用时收尾那条多一个 `合计`（ADR 0016），挂**消息与思考行** | 变形做（**两处都要**：行尾保留现状，检视器另加一个分拆面） | **已定**：**挂在消息与思考详情**（`UsageRecorded` 带 `speaker` 不带 `tool_call_id`，工具调用没有用量 —— 07 帧 5a 的工具框前提是错的）；两节「本次」/「这一趟会话（到这条记录为止）」各五行，条形沿用面板那套；末尾写清 `输入 = 缓存读 + 未命中；推理已含在输出里`；跨多次调用时「本次」与行尾的 `合计` 是同一个数；推理未报时写 `—` 且不画条 |

| Raw / Summary 二分（原文按内容块逐块输出 vs Markdown 渲染） | 只有渲染那一档 | **已对齐** | 渲染层里没有 markdown 渲染函数，正文走 `folded_text` 原样折行 —— **今天那份就是原文面**。事件的原始 JSON 拿不到（块 → 源事件没有记账 + 要读盘），**不做** |

| 初始停在尾部、向上滚暂停跟随、流式帧按结构签名更新 | 已有（`Follow` / `fresh` / 「N 条新行」） | 已对齐 | — |
| **行选择**：每行可聚焦、Enter / Space 选中、`aria-selected` | **没有**：只有滚轮、`PgUp` / `PgDn` / `Ctrl-G` 与点击开详情。而且行身份是**位置型下标**（CAP 裁剪会全体左移、宽度变化整批重放），要做选择 / 折叠 / 命中得先补一层稳定行键（[绘制面](research/02-draw-and-input-surface.md) 第 2 节） | 补齐 | 粒度是**块**不是行；整行 `ACCENT + BOLD`；新增一层键盘归属（判据 = 主列当前显示轨迹页且未交还），`Esc` 退完三层即**交还键盘**、点账本任何位置**拿回**；块身份从 `Event.seq` 派生、`Pane` 开「按行键替换任意一行」—— [长历史与行选择](issues/10-grilling-history-and-selection.md) §1–§8（事实：[行身份与从磁盘加载](research/03-line-identity-and-loading.md)） |
| 键盘可达（`tablist` / `role="separator"` 方向键 / `Escape` / `role="status"`） | 部分（`Esc` 关覆盖层、三键翻页、`Ctrl-D` 关覆盖层） | 变形做 | 「键位不落空 + 每一层都有 `Esc` 出口 + 键盘拿得到也还得了」三条；`aria-*` / `role` 那一套在字符格里**没有消费者**，明写不需要 —— 同上 §13 |
| 深链接 / 选择持久化 | 无 | 不做（DSH 自己也没有：记录选择与时间轴区间都是视图本地状态） | 范围之外 |
| 时间轴区间聚焦 → 未命中行淡出 | 无 | 变形做（**由搜索命中承担**） | 已定：区间聚焦整体不做，淡出由搜索命中在轴上兑现 —— [搜索与折叠的形态](issues/09-grilling-search-and-folding.md)；轴上那个选中位置标记画在**选中块的首行**那一刻 —— [长历史与行选择](issues/10-grilling-history-and-selection.md) §9 |

## F. 平台不对称，整块不做

这些不是「衡缺」，是衡**不该有** —— 写下来是为了让「逐条对齐」有个诚实的底：

- **虚拟化引擎**（`@tanstack/react-virtual`、`scrollMargin`、`anchorTo`、`followOnAppend`）：
  TUI 的重绘模型里没有「只挂载可见节点」这回事。
- **像素手势**：时间轴的滚轮缩放 / 右键清除与平移 / 边缘自动平移 / 500 ms hover tooltip；
  检视器的拖拽调宽。字符格里没有这些词，取舍见[时间轴与计时](issues/06-grilling-timeline.md)。
- **剪贴板按钮与灯箱**：衡已有拖选 + OSC 52 复制（`tui-feedback`），不新增按钮。
- **CSS 主题变量 / 容器查询 / `ResizeObserver`**：衡有语义色板与字形语法
  （[ADR 0015](../../docs/adr/0015-mark-light-sweep.md) 那一族决定，逐面文档 `docs/render.md`）。
- **`run_code` / PTC 的代码检视**：衡没有工具内派发这种工具。
- **模型面**：一块都不动 —— 轨迹是视图，模型可见文本与投影零变化。

## 一句话结论

衡的轨迹页**不缺「一份记录」**（它是全量块，DSH 也是），缺的是**可寻址**：DSH 的每一行都是
一个能选中、能折叠、能被搜索与时间轴区间命中的对象，而衡今天是一串只能点开的行；再往上缺的
是**结构**（回合 / 迭代的分组与组头摘要）、**数字**（每行耗时、检视器里的用量与计时拆分）与
**另一种读法**（时间轴总览、搜索过滤）。十张票就是这四件事的展开。
