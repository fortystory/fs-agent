**What to build:** 点这一页里除页签条的任何一格（含条目行），弹出一个详情覆盖层，里面是**打开那一刻**
的整份列表；进度行右端有一个写着 `详情` 的按钮。今天想看全只能去读转录里那几次调用的参数，那是一段
JSON 形状的原始参数，不是给人读的东西。

## 验收

- [ ] 新增一种详情（与思考 / 上下文注入 / 消息全文 / 文件内容 / 一份 diff / 一次工具调用并列），
      正文是这一份待办列表；照既有模板补齐那五处（枚举、正文分派的那唯一一个匹配、打开入口、
      打开方分派、标题与颜色）
- [ ] 打开方分派的那一支照文件页 / 改动页（**什么都不冻、什么都不还**）；注意「关闭时按打开方分派」
      那个匹配是**穷尽**的
- [ ] 进度行右端有写着 `详情` 的按钮（四列），窄档 28 列排得下（文案 15 + 间隙 9 + 4 = 28）
- [ ] 点页区里任何一格都开它；点**页签条**仍然是切页签
- [ ] 弹窗正文：进度行 → 空行 → 未完成项（正在做置顶）→ 空行 → 已完成项（**静音档降暗**、不划掉），
      **不加**「已完成」小标题
- [ ] 弹窗正文用满「详情正文宽」（不是框宽），可滚，滚到底不另写「还有 N 项」
- [ ] **快照**：开着时模型再提交一份新列表，只改面板；关掉重开后看到的是新的那份
- [ ] 这一页改走「自己画并返回」那条分支、画的时候记下它的矩形，**并在切走时把另两页的矩形清掉**
- [ ] 弹窗关掉后左栏仍停在这一页、位置不动
- [ ] 屏幕文本层把折行的**续行标出来**：拖选复制一条折行项得到的是**一条**（不多换行），选区不跨区域，
      相邻两项不会被粘进来
- [ ] **拖过是选中、不是点开**：拖选复制一条待办文字不会弹窗（照文件页那件既有的两路机制）
- [ ] **既有那条「点 `todo` 行什么都不动」的测试改写**成「点开的是详情覆盖层」，并保住它原来守的那件
      事：同一横排上**别处**的转录行不被这一页的点开动作带出来
- [ ] 帧测试：点一下 → 取帧 → 断言正文里进行中 / 待做 / 做完的都在，做完的那两行取样出来的**前景色与
      别的行不是同一档**（不钉具体颜色值）
- [ ] 已有别的弹窗开着时，第一次点击是**关掉它**（既有行为，spec 照写）；`Esc` 与 `Ctrl-D` 都能关
