## 问题

这张票是 **2026-10-09 那轮 charting 的归档**：维护者在场，两轮 grilling 共 15 问当场拍板，
所以答案是已经发生的事，不是走票走出来的结果。偏离与理由写在
[`map.md` 的「Tracker 事实与降级」](../map.md#tracker-事实与降级本图适用) 一节里，与
[`diff-page` 那张图](../diff-page/map.md) 同一处偏离。

要谈清的是**这一整个空间的形状**（不是某一个分叉）：

1. **终点与范围**：「todo 优化」说的是哪一层（页的呈现 / 工具本身 / 待办与目标清单 / 整条规划链路）？
   现在被什么硌着？走完这张图手里该有个什么（一份 spec / 一个决定 / 一次改动）？图要不要包含实现？
2. **这一页的职责**：摘要页 + 详情弹窗，还是一页可读的完整计划，还是搬进主列占一整页？
3. **长文本**：折行、截断 + 只在弹窗里看全、还是只给在做的那条折行？
4. **条目比页高多**：折叠已完成项、滚动、自动跟随进行中那项，还是保持 `＋N 项`？
5. **看全**：要不要详情弹窗，怎么打开（鼠标 / 键盘 / 都不要）？
6. **进度行**：写在哪（页顶 / 页底），写成什么样，要不要占比条？
7. **页上画什么**：进度行 + 全部未完成项，还是只留一行在做与一行下一个？进行中的项要不要特别标出？
8. **已完成项**：默认折掉但能一键展开，还是折掉不给展开，还是不折只降暗？
9. **弹窗里的列表**：打开那一刻的快照，还是一直跟着最新的，还是忙碌时拒绝打开？
10. **样式**：换不换掉 `▸`（与转录可折叠块同形）、完成项降暗还是划掉、还是样式一个不动？
11. **文档落点**：回改 `todo-and-modes/spec.md` §4、只在本目录留补记、还是补记 + 旧 spec 加指针？

## 作答

1. **终点是一份能拆票的 spec**；**执行在范围内** —— spec 折出来之后，实现票由 `/to-tickets`
   拆出、住在本目录（`Type: implement`，由 `/implement` 认领，不进 frontier）。这是 wayfinder
   默认 plan-don't-do 之外的一次显式覆盖。
   **层次**：只勾了**左栏 `todo` 页的呈现**。工具本身、待办与目标清单、整条规划链路三处**不在**
   本图范围（进「明确不做」或「尚未明确」）。**被硌着的**：长文本被藏 + 页签信息量不够。
2. **摘要页 + 详情弹窗**。页上是「进度 + 在做 + 接下来」，看全靠弹窗 —— 28/40 列的左栏放不下
   一份可读的完整计划。**被否决**：可读的完整计划（页内折行 + 滚动，长条目吃掉高度）；
   **被否决**：搬进主列占一整页（`todo` 页签是这只闩的由来，搬走就与 `todo-and-modes` §4 整套冲突）。
3. **折行**：一条内容可以占 2–3 行，续行缩进到字形列，**不再截断**。**被否决**：截断 + 只在弹窗里
   看全（页上仍读不到在做什么）；**被否决**：只给在做的那条折行（待办项的长度恰恰最不可预测，
   两套排版换来的是折行预算没法定）。
4. **折叠已完成项**：已完成的不画，计数行告诉有几条做过；进行中与待做因此自然露出来。
   **被否决**：滚动（今天左栏页区没有滚动机制，滚轮与 `↑`/`↓` 归文件页与焦点行，那是新机制）；
   **被否决**：自动跟随；**被否决**：保持 `＋N 项` 现状（那是今天长列表读不下去的直接原因）。
5. **要弹窗，鼠标开**：新增一种 `DetailKind::Todo`；进度行右端一个可点按钮，页内点空白处也能开。
   **被否决**：只给键盘键 —— 那一档的收益要靠 06 票问；**被否决**：键盘与鼠标两样都要（多一套键位）。
   **不给这一页一个键盘遍历机制**（焦点行 / `Enter` / 滚轮）。
6. **进度行挪到页顶**，文案跟上：`3/11 · 1 个在做`，全部做完写 `11/11 完成`。**被否决**：留在
   页底（每帧能多画一行条目，但摘要压在最下面等于没有摘要）；**被否决**：页顶 + 占比条
   （`调用量` 页那套 `▓`/`░` 是先例，本图不选）。
7. **进度行 + 全部未完成项**，`in_progress` 置顶、其余保持提交时的原顺序；放不下报 `＋N 项`。
   **被否决**：只留一行在做 + 一行下一个（太安静，「接下来还有什么」被藏）；进行中的项**不**
   特别标出（折行 + 置顶已经够，再加一层视觉分层是第三套规矩）。
8. **默认折掉，不给展开**：想看全部去弹窗。**被否决**：一键展开（页会重新被做完的历史占满，而那
   正是它今天读不下去的原因）。
9. **快照**：打开那一刻拍一张；开着时模型又提交了新列表，关掉就看到新的。**被否决**：跟随更新
   （弹窗会一边被人读一边变形）；**被否决**：忙碌时拒绝打开（用户想看的是「模型此刻在做什么」，
   那正是忙碌时最想看的）。
10. **换掉 `▸`**（它与转录里可折叠块的标记同形，`wording.rs:1907` 记着那条「靠区域区分」）+
    **已完成项在弹窗里降暗**。**不划掉**（降暗已经退后，划线再加一道噪）。页上的字形具体换成
    哪一个，以及降暗落在哪个语义色名上，交给 04 票与 spec。
11. **回改 [`todo-and-modes/spec.md` §4](../todo-and-modes/spec.md)**：新 spec 是它的继任者，
    那一节整节重写并在旧处留一行指向本目录。**被否决**：只在本目录留补记（旧 spec 会继续说
    「计数行留到最后一行」这种今天就错的话）。
