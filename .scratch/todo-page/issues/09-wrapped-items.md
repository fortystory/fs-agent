**What to build:** 一条待办不再被截断。今天左栏 28/40 列，一句话超出的那一截直接消失 —— 用户看到的
是半句话而不是「这条有点长」。这一票让一条内容可以折成 2–3 行，续行缩进到内容列；放不下时末行报
`＋N 项`，那个数字是**一条都没露出来的未完成项数**。

## 验收

- [ ] 一条内容折成 2–3 行，**续行缩进到内容列**（不是顶格）；折行按既有折行件那套（数显示列、
      按字符硬切、**不保词**）
- [ ] 所有条目的内容**严格同列**：带的与不带的起于同一列（前缀 = 状态字形两格 + 目标条目 id 位三格，
      没有 id 的那一格留空）
- [ ] 放不下时末行写 `＋N 项`，N 是**一条都没露出来的未完成项数**（不是清单总数）
- [ ] 一条折行后比剩下的页区还高：画它的前几行、末行末尾加 `…`，而它**不**计入 N（它至少露了一行）
- [ ] 帧测试：窄档与宽档两档下，一条长内容跨多行且续行缩进；带 id 与不带 id 的两行内容起于同一列
- [ ] 窄口测试：三行页区里溢出行报的数字正确（一条都画不出时报的是「没露出来的未完成项数」）；
      一条要三行而只剩两行时，它露两行 + `…` 且不计入
- [ ] 这一票**仍然不接命中区域**，也**不动屏幕文本层的续行标记** —— 那是 10 一起改的（改了之后折行项
      复制出来才是一条而不是几行）

## 评论

落地（2026-10-09）：一个条目从「一行、按页宽截断」变成 `item_rows`（另有一个 `item_lines`
是它上面那层「要不要降暗」的包装，弹窗用）—— **前缀补满五列**
（字形一列 + 空格 + id 两列 + 空格，没有 id 就两个空格占位），于是带 id 与不带 id 的两行内容
严格同列，与文件页「字形列每行都占满两格」同族。折行走既有的 `pane::wrap_text`（数显示列、
按字符硬切、不保词），**续行缩进到内容列** —— 那条纪律写在折行件自己的文档注释里，本票按
[04 票](04-prototype-page-and-detail.md) D 组那个变体选了缩进，理由（这一页不是日志，缩进主张的
是「这一片属于哪一项」）也写在那里。

排版从「计数行留最后」换成「进度行留最上」，于是 09 的溢出行回来了，口径按 [05 票](05-grilling-cramped-and-empty.md)
改成「**一条都没露过面**的未完成项数」：被 `…` 截断的那一条至少露过一行，不计入。

**一处与 04 票那帧的出入，写在这里免得日后有人当 bug**：04 的帧草图里 40×3 那一档画的是
「一条都不画 + `＋9 项`」—— 那是 05 票裁定「截断 + `…`」之前的中间稿。按 05 与 spec，现在
那一档是「进度行 + 首条的前几行（末行带 `…`）+ `＋8 项`」。帧草图没有跟着改（它验完即弃）。

新窄口测试两条（折行 + 截断 + 溢出口径、两行页区只剩进度与溢出），帧测试两条（长句跨行且续行
缩进到内容列、放得下就不截断），既有断言四处跟着改形状。`--test render_layout` 274 passed /
`--test todo` 16 passed。
