## 它要什么

1. **进度行**：一行完成进度，形如 `3/11 1个正在进行`（还有一项在做）、`11/11 完成`（全做完了）。
2. **样式美化**：这一页今天读起来是什么样。
3. **完整列表弹窗**：在进度那一行上放一个**按钮**，点开用**详情弹窗**显示整份列表 —— 弹窗里
   长过一行的文本**折行**，不隐藏。

三条都只动**呈现**：列表的来源、工具的形状都不动。

## 现状（2026-10-06 核实）

- **计数行已经在**，只是形状不如上面第一条：它写 `已完成 3/11`（`wording::todo_count`，
  [`src/render/wording.rs:1771`](../../src/render/wording.rs)），坐在左栏那一页的**最后一行**，
  而且只数完成数（`crate::tools::todo::completed`）—— 既没有「正在进行」那一项，也没有
  「全部完成」那一档。
- **条目行今天会截断**：[`src/render/todo.rs`](../../src/render/todo.rs) 的 `item_line` 画
  `字形 + id + 内容`，用 `truncate_columns` 裁到页宽 —— 左栏只有 28（窄档）/ 40（宽档）列，
  长条目**文本是被藏起来的**。塞不下的条目另有 `＋N 项` 一行（`wording::todo_overflow`）；
  **这一页没有滚动**。
- **这一页没有命中区域**：`Tab::Todo` 走 `state.todo.lines(page)` 加一次 `Paragraph`
  （[`src/render/tui.rs:4514`](../../src/render/tui.rs)），是纯读数；同一条分派里文件页自己画、
  记 rect 与焦点行。所以「按钮」是新的一件 —— 左栏今天只有页签条可点。
- **弹窗那一半有现成件**：详情覆盖层已有五种 `DetailKind`（Thinking / Context / Message /
  File / Tool，[`src/render/tui.rs:6653`](../../src/render/tui.rs)），宽度上限 135 列，而它的
  **正文不折行**（由调用方按 `Regions::detail_text_width()` 排好）—— 「折行显示」正落在调用方
  那一侧（`pane::wrap_text` 就在手边）。
- **数据来源一个字不变**：列表来自最近一次主会话 `todo` 调用（`TodoPanel::observe`），
  `--continue` 靠重放重建同一份；弹窗显示的也就是它。
- 状态字形今天是 `☐`（待办）/ `▸`（进行中 —— 与转录里的可折叠标记**同形双义**，靠区域区分）/
  `✓`（完成）。

## 待谈的分叉

1. **「正在进行」怎么算**：数 `Status::InProgress` 的项（工具并不禁止同时进行多项）；没有进行项
   时整段省掉，还是照写 `0 个正在进行`。
2. **「完成」那一档的形状**：`11/11 完成` 是把数字换成一句文案，还是照旧数字 + 一个 `✓`。
3. **进度行的位置**：它今天在页的**最底**，而按钮要跟它同一行。要不要把它挪到**最上**（摘要在
   前）—— 那会让每一帧的条目少拿一行。
4. **「美化」动到哪一步**：状态字形换一套、完成项降暗或划掉、还是给完成度加一条占比条（左栏
   `调用量` 页有 `▓`/`░` 的先例，见 [`.scratch/usage-stats-format/spec.md`](../usage-stats-format/spec.md)）。
5. **弹窗接哪儿**：新增一种 `DetailKind::Todo`，还是复用 `Context` 那一种；打开方
   （`DetailOpener`）今天记的是转录 / 详情自己的滚动位置，从**左栏**点开的这一个要记什么、
   关掉之后怎么还。
6. **弹窗里怎么排**：宽度用满（≤135）还是留白；`✓ 03 补测试` 这种带 id 的条目，折行的续行对齐
   到哪一列；条目多到一屏之外时它自己要能滚（详情覆盖层本来就支持滚动）。
7. **按钮本身**：长什么样、窄档（左栏 28 列）下进度加按钮还放不放得下、要不要进提示行。
8. **与 [`todo-and-modes/spec.md`](../todo-and-modes/spec.md) §4 的关系**：那一节定了「页签是
   闩、列表从流推、计数行先留出来」—— 这一轮只改呈现，是回改它的正文，还是只在本目录留补记。

## 默认不做（除非访谈时正面推翻）

- 不动 `todo` 工具本身（形状、参数、回执、`Effect::ReadOnly` 都不动）。
- 不给执行者的列表在左栏开位置（它今天只住在转录里，见 `src/render/todo.rs` 开头的注释）。
- 不做「点条目改状态」：列表归模型所有，这一页是**读**的那一面；让前端改模型的状态是另一条路。
