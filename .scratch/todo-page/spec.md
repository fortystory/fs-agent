## 问题陈述

左栏三页各回答一个问题：`调用量` 回答「花了多少」，`todo` 回答「干到哪了」，`文件` 回答「工作区
长什么样」。**`todo` 这一页今天答得很勉强。**

它画出来的是：每项一个状态字形（有 `id` 的再带两位数字）、按页宽**截断**的文本、以及最后一行
`已完成 3/11`。代价落在三处。

**长条目的大半被藏起来。** 左栏窄档 28 列、宽档 40 列，而一条待办是一句话（「摸清仓库现状：
tracker 约定、现有 todo 设计与 spec」）。今天没有折行，超出页宽的那一截直接消失 —— 用户看到的是
半句话，而不是「这条有点长」。**塞不下的项**另用一行 `＋3 项` 报出来，可那一行说的是「总共几项」，
不区分「还没做完的」与「做完的」。

**「还有什么没做」要自己数。** 已完成的项与未完成的项混排在一起，都占行，于是「剩下的事」在
页面上**不是**任何一块连续的东西。进度压在**最底下一行**，页的最上面放的是第一条历史。

**看全没有入口。** 想知道这份清单里到底有什么，只能去读转录里那几次 `todo` 调用的参数 —— 那是一段
JSON 形状的原始参数，不是给人读的东西。

而这一页是模型开工前立下的那份计划。用户在长任务里反复靠它判断「现在轮到哪一步」，所以它答不
上来，代价不是「少一个功能」，是**每次都要把模型重说的话再自己解码一遍**。

## 方案

把左栏 `todo` 页改成「**摘要 + 详情弹窗**」，范围只在呈现：

1. **页顶一条进度行**：`2/11 · 1 个在做`，全部做完写 `11/11 完成`。摘要压在最上面。
   进度行右端有一个写着 **`详情`** 的按钮。
2. **页上只列未完成的项**，`in_progress` 的那条排在最上，其余保持模型提交的顺序；**已完成的折
   掉，页上不给展开它们的地方**（要看全部去弹窗）。
3. **长文本折行**：一条内容可以占 2–3 行，续行缩进到内容列，**不再截断**。放不下时末行报
   `＋N 项`，那个 N 是**一条都没露出来的未完成项数**。
4. **看全走新增的一种详情覆盖层**：页区里除页签条**任何一格**点一下都开它（拖选照旧 —— 拖过是
   选中，不是点开）。弹窗里是**打开那一刻的整份列表**（进行中、待做、做完的都在，做完的用静音档
   降暗），标题写 `── 待办 · <提交者> ──`。
5. **四种空态各有定话**：列表空写 `还没有待办`、全部做完就只剩一行进度、极小页区只剩进度行加
   `＋N 项`、空列表时**不给按钮**（开不了弹窗）。

**不动的东西**：`todo` 工具的形状与 schema、回执、`Effect::ReadOnly`、模型开工前立待办的引导、
权限模式三档、事件流、模型可见文本。页签仍是**一只闩** —— 见过一次非空列表，此后整个会话都在，
清空列表也不摘。

## 用户故事

### A. 进度一眼看得见

1. 作为用户，我想在页的最上面就看到「做完几条、共几条」，以便不用数行就知道这份计划走了多远。
2. 作为用户，我想在有正在做的那条时看到「N 个在做」，以便知道现在动的是哪一段。
3. 作为用户，我想在全部做完时看到一句「N/N 完成」，以便知道收工了。
4. 作为用户，我想让进度行**占页区第一行**，以便摘要压在最上面而不是最底下一行。
5. 作为用户，我想让进度文案跟着宽度走（分窄档与宽档都读得下），以便不为了放一句话而换一整套排版。
6. 作为用户，我想**不要**一条占比条，以便左栏不留第四种读数格式。
7. 作为用户，我想在列表被清空时看到一句「还没有待办」，以便分不清「没有」与「坏了」。
8. 作为用户，我想让页签**出现过就一直在**，以便它不在会话中途跳走 —— 即使模型清空了列表。
9. 作为用户，我想让这些文案归到那一个措辞层里，以便将来换词只有一个地方要改。

### B. 一屏里只有「还有什么没做」

10. 作为用户，我想让页上列的全是**未完成**的项，以便「剩下的事」在页面上是连续的一块。
11. 作为用户，我想让**正在做**的那条排在最上面，以便一眼找到当前那一步。
12. 作为用户，我想让其余项保持模型提交的顺序，以便页面的顺序与模型想表达的顺序一致。
13. 作为用户，我想让**已完成的项不在页上**，以便它们不占掉本来属于未完成项的行。
14. 作为用户，我想让页上**没有**展开已完成项的地方，以便这一页永远只回答「还有什么没做」。
15. 作为用户，我想在放不下时看到一行「还有 N 项」，以便知道这一屏不是全部。
16. 作为用户，我想那个 N 数的是**一条都没露出来的未完成项**，以便它直接回答「我还欠多少」。
17. 作为用户，我想让被折行截断（只露了前几行）的那一条**不算进** N 里，以便正在进行的那一条不被藏起来。

### C. 一句话读得全

18. 作为用户，我想让一条待办折成 2–3 行而不是被截断，以便我读到完整的那句话。
19. 作为用户，我想让折出来的续行缩进到内容那一列，以便一眼看出这几行属于同一项。
20. 作为用户，我想让所有条目的内容**严格同列**，以便扫读时眼睛不必每一行各自往前挪。
21. 作为用户，我想让带 `id` 的项仍能看出它对**目标清单**的哪一条，以便「哪条做完了」是确定的而不是靠文本对得上。
22. 作为用户，我想让状态字形是三个互不相同的记号，以便待办 / 正在做 / 做完三档一眼分得开。
23. 作为用户，我想让「正在做」的记号不再与转录里可折叠块的记号**同形**，以便两个区域不必靠记忆区分。

### D. 看全那份清单

24. 作为用户，我想在进度行右端看到一个写着 `详情` 的按钮，以便知道这一页能点开。
25. 作为用户，我想**点页里任何一格**都能打开它，以便不用瞄准那一小块按钮。
26. 作为用户，我想拖选仍然照旧（拖过是选中、不是点开），以便选中一句话复制时不误开弹窗。
27. 作为用户，我想在弹窗里看到**整份**列表（正在做、待做、做完的都在），以便它回答「这份计划到底是什么」。
28. 作为用户，我想让做完的项在弹窗里**降暗**（而不是划掉），以便它们退后但仍可读。
29. 作为用户，我想让做完的项跟在后面、不另起一段小标题，以便「已完成」这个事实页顶那一行已经说过一次，不必再说。
30. 作为用户，我想让弹窗标题写明这份列表**是谁提交的**，以便讨论会话里我读的不是别人那一份而不自知。
31. 作为用户，我想弹窗是**打开那一刻**的快照，以便我读一半时它不会在眼前变形。
32. 作为用户，我想开着弹窗时模型又提交了新列表，关掉之后看到的是**新的**那份，以便它不落后于模型。
33. 作为用户，我想弹窗正文用满可用宽度并可滚，以便长项目的全文读得到。
34. 作为用户，我想关掉弹窗后左栏仍停在这一页、位置不动，以便它没有跳走。
35. 作为用户，我想关弹窗认 `Esc` 与 `Ctrl-D`，以便与既有的详情覆盖层一致。
36. 作为用户，我想在已经有别的弹窗开着时，第一次点击是**关掉它**而不是叠开第二个，以便不出现两层框。
37. 作为用户，我想在列表为空时**没有**那个按钮、点不开弹窗，以便没有可看的东西时不弹一个空框。

### E. 问卷、窄屏与那一族的邻居

38. 作为用户，我想问卷立着时这一页照常可点，以便问我的同时还能看一眼进度。
39. 作为用户，我想滚轮落在这一页上不做任何事，以便它不抢文件页的滚动。
40. 作为用户，我想终端窄到左栏整栏隐藏时这一页就是看不见、**没有**别处替代，以便我不会在自己收起左栏之后还在别处读到它。
41. 作为用户，我想执行者（子 agent）提交的那份仍然**不进**左栏，以便左栏只回答我这一份的进度；它仍在转录里读得到。

### F. 同一份列表在别处也是同一份

42. 作为用户，我想 `--continue` 接着上次会话时左栏重建出**同一页**，以便继续干活时进度没丢。
43. 作为用户，我想 `sessions replay` 重算出**同一页**，以便审计看到的东西与我看到的一致。
44. 作为用户，我想这一页与它的弹窗都**不进事件流、不进模型上下文**，以便它只是给人看的读数。

### G. 多 agent 会话

45. 作为用户，我想讨论会话里页上显示的是**最后一次由讨论者提交**的那份，以便它跟着「谁刚在动手」走。
46. 作为用户，我想讨论者轮流发言时页跟着换人不算问题，以便我随时知道这一轮是谁在动。

### H. 边界

47. 作为用户，我想 `todo` 工具的形状、参数与回执一个字都不变，以便模型那边没有任何意外。
48. 作为用户，我想权限模式仍是三档，以便「能不能写」与「计划怎么记」仍然是两件事。

50. 作为用户，我想完成项的降暗落在语义色板的**静音档**上，以便不新起一个颜色。
51. 作为用户，我想这一页上的文字仍能被拖选复制，且一条折行项复制出来是**一条**，以便复制到手的是原话而不是几行碎片。

## 实现决定

### §1 这一页画的是哪一份

1. **列表来源一个字不变**：仍是最近一次已落地、且**说话者不是执行者**的 `todo` 调用所带的
   整份列表（今天就是这样）。工具是「一次提交整份」，所以「最后落地的那份整份胜出」这条规则
   照旧。
2. **面板多记一个说话者**：现在面板只有「见过非空列表」与「当前列表」两个值，要留住「这份是谁
   提交的」就得再加一个说话者值 —— `DetailKind` 的标题在**打开那一刻**取它。
3. **执行者那份仍然不进左栏**，与 `todo-and-modes` §2 一致：那是子 agent 自己的工作记录，只在
   转录里读得到。
4. **不做投影改动**：「页上那一份是谁的」经判断是**呈现的一个属性**，不是投影规则问题 —— 变的
   只是现在把「是谁」说出来了。

### §2 页的排版

5. **从上到下**：进度行一行 → 未完成项（`in_progress` 置顶，其余保持提交顺序）→ 放不下时末行
   `＋N 项`。
6. **完成项折掉**：页上不画，也不留展开它们的地方（配置里也不留开关）。
7. **溢出行的口径**：那个数字是「**一条都没露出来的未完成项**」。被折行截断（只露了前几行 + `…`）
   的那一条**不算**进去 —— 它至少露了一行，而正在进行的那一条最不该被藏起来。
8. **一条放不下时**（折行后比剩下的页区还高）：画它的前几行，末行末尾加 `…`。**不**整条跳过。

### §3 条目行的形状

9. **前缀严格同列**：状态字形占两格，目标条目 `id` 位占三格（没有 `id` 的项那一格留空），内容
   统一从第五列起。照抄文件页「字形列每行都占满两格，于是同层的名字落在同一列上」那条规矩。
10. **代价明说**：窄档 28 列里内容只剩 **23 列** —— 一条 25 字的内容折 3 行，42 字折 4 行。
11. **折行**：按既有折行件那套（数的是显示列、**按字符硬切、不保词**），续行**缩进到内容列**。
12. **这是对一条既有纪律的有意例外**：那件折行函数的文档写着「续行从第零列起 —— 窗格是一份
    日志，缩进会主张一种折行后的文字并没有的结构」。这一页不是日志，缩进主张的是「这片属于
    哪一项」，那是真结构。spec 与实现注释都要写明这是例外及其理由。
13. **状态字形**：`☐` 待办 / **`●`** 正在做 / `✓` 做完 —— 三个记号都退出与别的区域同形的那个
    `▸`。**要在真机上核一遍**：`☐` `✓` `●` 都是 Ambiguous 宽度，本 spec 按一列算（与今天
    `☐` 的实际排布一致）；若某两个字体下变成两列，前缀就宽一列、内容少一列。
14. **一个不做**：不为这一页另写「保词折行」。折行件是公共件（工具输出、diff、问答题都在用），
    为一页去动它是更大的一个决定。

### §4 进度行与按钮

15. **文案**：`做完/共做 · N 个在做`（有正在做的）与 `做完/共做 · 完成`（全做完）；其余情况
    只写 `做完/共做`。
16. **位置**：页区**第一行**。这一行换不来条目 —— 它换来的是「摘要压在最上面」这件事。
17. **按钮**：进度行**右端**写 `详情`（两个字 = 四列）。窄档 28 列排得下（文案 15 列 + 间隙
    9 列 + 4 列 = 28）。这一页今天没有任何几何冲突，四个退路（更短文案 / 单字形 / 不给按钮 /
    整页可点）全都放得下 —— 可发现性靠**整页可点**与这个 `详情`，不靠瞄准。
18. **按钮照常登记进屏幕文本层**：复制这一页的文字时 `详情` 跟着走；把它挖掉会让复制出来的
    进度行缺一块。
19. **列表为空时不画那一块、也不可点**。列表重新落地（哪怕只有一项）它自己回来。

### §5 命中区域

20. **页区里除页签条，任何一格都点得开弹窗**（含条目行）。这是对 charting 那句「按钮 + 点空白
    处」的**读法澄清**，不是重开。
21. **拖选不抢**：按下起拖选、松开时按「是不是拖过」决定是复制还是点击 —— 既有的两路机制，
    文件页那条「点开新增动作不该吃掉拖选」就是这个形状。
22. **沿用既有指针分派**：问卷立着时这一页照常可点；已经有详情覆盖层时，第一次点击是「框外点击
    关掉它」（既有行为，spec 照写，别当 bug）。
23. **接上接线那四件**：一个页面状态值挂上渲染状态、「自己画并返回」的分支、画的时候记下这块
    矩形并在切走时清掉另外两页的、屏幕坐标落在矩形内即命中。
24. **不做行级映射**：文件页与改动页靠「屏幕行 → 行下标」换算，那成立是因为**每个逻辑项恰好
    占一行**；这一页折行之后不再是双射。而整页可点**根本不需要**行下标 —— 只要「落在这块矩形
    里」这一句。
25. **不接滚轮**：这一页没有可滚的东西。不接滚轮的补偿是「整页可点」加上「弹窗里能滚」。
26. **关掉之后什么都不还**：新增的那支详情打开方照文件页 / 改动页那一支（什么都不冻、什么都不
    还）。实现时要记得那个「关闭时按打开方分派」的匹配是**穷尽**的。

### §6 详情覆盖层

27. **新增一种详情**：与思考 / 上下文注入 / 消息全文 / 文件内容 / 一份 diff / 一次工具调用并列
    的那一种，内容是这一份待办列表。要动的地方是照既有模板的那五处（枚举、正文分派的那唯一
    一个匹配、一个打开入口、打开方分派、标题与颜色）。
28. **标题**：`── 待办 · <提交者> ──`，左右各一段横线、右侧照既有覆盖层那样挂着「esc 关闭」。
    名字取措辞层里那个说话者标签的既有形式。
29. **正文**：进度行 → 空行 → 未完成项（`in_progress` 置顶）→ 空行 → 已完成项（**静音档降暗**）。
    **不加**「已完成」小标题 —— 页顶那一行已经说过一次。
30. **宽度**：用既有那个「详情正文宽」的口径（它等于框宽减边框与两侧内边距），**不是**框宽。
31. **快照**：内容在打开那一刻算完并存在详情里；此后模型再提交新列表只改面板，不动开着的弹窗。
    既有的「正文的形状只在打开时定」这条路已经够用，不需要新机制。
32. **滚动**：交给覆盖层既有的滚动；**不**另写一句「还有 N 项」—— 滚到底就是底，页脚已经写着
    位置。

### §7 四种空态与小页区

33. **列表为空**：页里一句 `还没有待办`（措辞层里归 `todo` 一族的新小节）。
34. **全部做完**：就一行 `11/11 完成`，条目区留白。页签不动（它是闩）。
35. **极小页区**：进度行 + 溢出那行，中间是**能画几行画几行**（§2 第 8 条：截断的那一条加 `…`）。
    窄档最矮是 28 列 × 5 行那一档（能画出一条折行项再报溢出）；3 行地板只在宽档出现
    （120 列 × 12 行那一帧是「进度行 + 首条的首行带 `…` + `＋8 项」）。
36. **左栏被收起 / 终端窄到整栏隐藏**：**不做替代路径**。可见性是用户自己的意图乘上终端宽度，
    而转录里那次调用本来就在屏幕上。

### §8 文本层与复制

37. **折行之后要给屏幕文本层标出「这是续行」**：那一层登记的是**画出来的行**，不标就会被当成
    几条独立行，复制出来多几个换行。标了之后一条折行项复制出来仍是一条 —— 选区不跨区域，所以
    相邻两项不会被粘进来。

### §9 要一起改的既有东西

38. **一条既有测试与本 feature 正面冲突**：左栏 `todo` 页那条「点一行什么都不动」的测试断言的
    正是「本页没有命中区域」这件事。实现时必须一起改写成「点开的是详情覆盖层」，并保住它原来
    守的那件事（同一横排上的**别处**的转录行不该被这一页的点开动作带出来）。
39. **回改** `todo-and-modes/spec.md` §4，并在旧处留一行指向本目录。
40. **文档**：渲染那篇加一节这一页；手工清单加一节真机观感项（见「补记」里的清单）。
41. **不改** `CONTEXT.md`：「待办列表」与「待办工具」两条词条今天仍然准确（列表仍是调用参数、
    仍是模型自己的、左侧栏仍是非执行者那一份）。

## 测试决定

### 什么是好测试

只钉**外部行为**：屏幕上该有的字、该没有的字、点一下该开什么、复制出来该是什么。不断言页面
矩形记在哪里、不断言内部字段、不断言每一句中文文案逐字不变（文案归措辞层，测试断言「有这一句
意思」而不是把字符串焊死）。

### 两个 seam

1. **渲染状态（主 seam）**：喂一串事件、取一帧、读**左栏那几列**；点一下再取一帧看弹窗；按住
   拖过再松开看剪贴板。今天左栏页的测试已经是这一条（假会话 + 取帧 + 按显示列定位），详情覆盖层
   的断言也在这一条上（有一整套「按真实几何算出正文区」的取景助手可照抄）。
2. **面板的排版窄口**：直接调面板那个「给一块页区矩形、排出几行行」的方法并逐行比对。这一层只
   用来钉**纯排版规则**（高度阶梯、溢出、截断），不必为它搭整帧 —— 面板级单测在本仓库已有先例。

**没有第三个 seam**：工具层今天不动，它自己的契约测试照旧。

### 要钉住的行为

- **页**：进度行的三种文案与它在第一行；`in_progress` 置顶而其余保持提交顺序；完成项不在页上；
  长内容折行且续行缩进到内容列；前缀同列（带 `id` 与不带 `id` 的两行内容起于同一列）；
  放不下时末行 `＋N 项` 且数字是「没露出来的未完成项数」；被 `…` 截断的那条不计入。
- **四种空态**：列表空写 `还没有待办`；全做完只剩一行；极小页区只剩进度行 + 溢出；空列表时
  那一块不可点。
- **弹窗**：点页里任何一格都开；标题带提交者名字；正文里做完的项也在（能看出它们被降暗到另一
  档 —— 用**前景色取样**判断而不是钉具体颜色值）；开着时模型再提交一份新列表，关掉重开后看到的是
  新的那份；关掉后左栏仍停在这一页。
- **复制**：拖选一段跨折行的条目文字，剪贴板里是**一条**（续行拼回，不多换行）。
- **多 speaker**：讨论者提交的那份出现在页上、弹窗标题是那位；执行者提交的那份**不**出现在页上。
- **重放**：同一串事件重放两次，两帧相同。

### 先例

左栏页现有的渲染测试（假会话入口、取帧、只读左栏那几列、按显示列定位）；详情覆盖层现有的
「点开 → 断言 `esc 关闭` 与正文 → `Esc` 关掉 → 断言关上」；面板级排版单测；改动页那套弹窗取景
助手；以及「点开新增动作不该吃掉拖选」那条（复制与点击两路）。

## 明确不做

- **不动 `todo` 工具**：形状、schema、回执、权限分类、派发性、规则段（模型开工前立待办的那句
  引导）一个字都不改。写得太潦草是另一个话题。
- **不让前端改状态**：不做「点一项把它标成完成」。列表归模型所有，这一页是读的那一面。
- **不给执行者的列表在左栏开位置**。
- **不把这一页搬进主列**；不加键盘遍历（焦点行、方向键、`Enter` 开弹窗）；不接滚轮；不给这一页
  一个专门的键位（`Ctrl+T` 那一族是别家的做法，见「补记」）。
- **不接滚动**：页上放不下就报溢出，不给这一页加滚动位置。
- **不给已完成项一个展开开关**（哪怕记在配置里）。
- **不做占比条**。
- **不做搜索与过滤**：页与弹窗都不给。
- **不把它塞进模型上下文**：与文件页 / 改动页的弹窗同一立场。
- **不改事件 schema、不加事件、不加字段到已有的事件上**。
- **不顺手分开剩下的 `▸`**：转录里可折叠块的记号与选择器里的「当前项」记号仍同形，各自在自己的
    区域里；那是一次要动两处的改动，超出本次 destination。
- **本 feature 不改权限模式**，也不改左栏的可见性判据（意愿乘以终端宽度）。
