# 侧栏 `todo` 标签：会话出现过列表就常驻

Type: implement
Status: done
Blocked by: 02

> 规格：`.scratch/todo-and-modes/spec.md` §4、`Testing Decisions`。

## 目标

左侧栏出现一个 `todo` 标签，显示**主会话**的待办列表与完成计数；它**一旦出现过就不再消失**（用户选的那一档）。

## 落点

`src/render/tui.rs`（`Tab` 枚举、`draw_tab_bar` 的条件标签表、`draw_sidebar_page` 的 Todo 页、命中矩形）、`src/render/wording.rs`（`TAB_TODO`、状态字形、计数与溢出文案）、`src/render/layout.rs`（若截图/阶梯需要）、`docs/tui-manual-checklist.md`、`tests/render_layout.rs`。

## 具体行为

1. **`Tab` 加 `Todo`**：标签文案 `todo`（4 格），插在 `调用量` 右边。
2. **出现条件**：本会话见过**非 `Executor`** 说话人的 `todo` 调用，且 args 里的 `items` 非空 ⇒ 标签出现，**此后不再消失**（全完成、被清空都留着）。置位是**渲染器状态**、不进流；`--continue` 时由重放自然重建。
3. **页内容**：
   - 一行一项：状态字形（`☐` 待办 / `▸` 进行中 / `✓` 已完成，措辞层常量）+ `content`；
   - 一行计数：`已完成 2/5`（放最后一行的位置由实现选，但要与溢出行**不冲突**）；
   - **不做滚动**：行数由高度阶梯给，溢出时最后一行画 `＋3 项`；一行也放不下时退化到只有计数行。
4. **阶梯与宽度**：与 `调用量` 共用同一套高度阶梯（字段数那个 `loop` 不动），宽度两档（40 / 28）不变 —— 四个标签在 28 格下仍放得下（`调用量│todo│轨迹│文件` = 3+4+2+2 格 + 3 个分隔）。
5. **点击**：标签仍只给鼠标（`Tab` 归 `/` 菜单、`Shift+Tab` 归模式循环）；命中矩形照旧「这一帧真画了什么就记什么」。选中 `Todo` 时它**不会消失**（因为常驻），所以不需要落回逻辑 —— 这一点在测试里写明，免得将来有人加回一个「消失」以为安全。
6. **执行者的列表不上侧栏**：执行者调 `todo` 只在转录里留一行（详情覆盖层里能看到 args）。

## 测试

`tests/render_layout.rs`：

- 无 `todo` 调用时，标签条里**没有** `todo`（60×24、120×24 各一档）；
- 一条非空列表之后出现；全 `completed` 之后仍在；空数组清空之后仍在；
- **执行者**的 `todo` 调用**不**触发出现；
- 页内容：三档字形各一行、计数行、溢出时的 `＋N 项`；
- 28 档宽度下四个标签都在、且不与填充线重叠；
- 点标签切页只认标签本身的格子（沿用现有命中测试的写法）。
