# 短横的旋转改回 mark 自己的块字形

Type: implement
Status: done
Blocked by: 05

> 规格：`.scratch/tui-input-pulse/spec.md` §2（本次改写它）。
> 来源：用户看过真机之后的一句话 —— 「你不应该把 `▀▀▀▀` 换成 `────`」。

## 目标

mark 里那个短横的空闲样子**回到原来的 `▀▀▀▀`**；四个朝向全部用 mark 自己的块字形画，不再借线字形。

## 问题

票 05 为了让四个朝向共用一族字形，把 mark 的静止短横从半块 `▀▀▀▀` 换成了线 `────`。那是**改动了空闲 mark 的样子** —— 一个本该只在忙碌时才出现的动画，不该顺手改掉静止时的字形。

## 具体行为

1. **静止/平着 = `▀▀▀▀`**（mark 原来那一格，一字不改）。
2. **另外三个朝向用块字形**，都画在那格 4 列 × 5 行里：
   - `╲`：`▚` 沿对角错开（每格填左上 + 右下两个四分之一块），四格连成一阶梯；
   - `│`：`█` 立柱，五行；
   - `╱`：`▞` 反向阶梯。
3. **格子表改成三元组**：`DASH_CELLS: [&[(usize, usize, char)]; 4]` —— 每格自带字形。四个朝向的顺序**必须**与 `wording::DASH_TURN` 一致（平、`╲`、`│`、`╱`），两处注释互相点名。
4. **窄档那一行不变**：文字身份行 `fs-agent 0.1.0` 里那一格继续用 box-drawing 的 `─ ╲ │ ╱`（真对角、不抖，文字行里也没有块格子可用）。`wording::DASH_TURN` 照旧，只是 rustdoc 说明 mark 用的是同一批朝向的块字形版本。
5. **机制的其余部分一个字节不动**：250ms 一帧、守卫、归零、运行结束回静止。

## 测试

1. `the_dash_of_fs_agent_turns_while_a_run_is_in_flight`：四段字符画改成新的块字形（`▀▀▀▀` / `▚` 阶梯 / `█` 立柱 / `▞` 阶梯）；**新增一条**：空闲时 mark 的短横那一格与**票 04 之前的原始 `logo_lines()`** 逐字符相同（这条就是「不许再改静止字形」的回归断言）。
2. 窄档那条、颜色不变那条、无左栏那条、色环离屏那条照旧跑绿。
3. `cargo test` / `cargo clippy --all-targets` / `cargo fmt --check` 基线同前。
