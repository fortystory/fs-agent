# 14: 模态覆盖层：四种等待回答的问题

**What to build:** 把权限询问从「占掉输入行的黄色提示」改成**模态覆盖层**，并让四种 pending 问题共用同一套外观与回答机制：权限、计划冲突、超长粘贴确认、Esc 清空草稿确认。

Blocked by: 10, 12

Status: ready-for-agent

**参考:** spec §9（模态覆盖层）、§7（两种确认）、§10（措辞层）

- [ ] 覆盖层外观：画在中段（转录 + 右栏）**之上**、垂直居中；宽度 `min(中段宽 − 4, 72)`；`Block` 边框 + `Clear` 打底 + 居中 `Paragraph`；问题文本与可接受键走 `wording.rs`
- [ ] 四种 `Question` 共用：`Permission` / `PlanConflict` / 超长粘贴（12 新增）/ Esc 清空草稿（12 新增）
- [ ] 键位与默认答案**沿用既有 `answer_key` / `default_answer`**：权限默认 `Deny`、计划冲突默认 `Keep`、两个新确认默认**否**
- [ ] `Esc` 在模态上 = 默认答案；`Ctrl-C` 仍然有效
- [ ] 模态期间转录与输入**不接收字符键**（现状的 `pending.is_some()` 分支）；模态消失后焦点回输入区
- [ ] 覆盖层**不属于转录、不随滚动移动**；`Block::PermissionAsked` 仍留在流里可回看
- [ ] 措辞新增：`粘贴 {n} 字符？`、`清空输入？`，以及四种问题各自的可接受键提示
- [ ] 用例：四种问题各渲染一次（`TestBackend` 断言覆盖层出现且背景被遮住）；默认答案正确；模态期间字符键不改变输入缓冲
