# 11: 对话面板：滚动缓冲、换行缓存、吸底与鼠标滚动

**What to build:** 让对话面板真正成为**可回看的转录**：自己持有源行缓冲（上限 20 000 源行、超出丢最旧）、按宽度缓存换行结果与其索引、吸底但用户上滚后不抢、右缘恒留滚动条、脱离吸底时底部右缘显示可点击的「点此到底」。同时把**用户自己输入的消息**从「单行 + 截断 500 字符」改成多行原样渲染。

Blocked by: 10

Status: ready-for-agent

**参考:** spec §3（面板行缓冲与换行缓存）、§4（滚动、吸底与鼠标）、§6（键位表里转录那几行）

- [ ] 源行缓冲：`Block` 展开成未换行行；**20 000 上限按源行算**（宽度无关），超出丢最旧
- [ ] 换行缓存：全量换行后的行 + **源行 → 显示行起点**索引
- [ ] 换行口径：**逐字符、CJK 2 列，复用 `wrap_take`**；**不用** `Paragraph::line_count`、**也不开** `unstable-rendered-line-info`
- [ ] 失效：宽度变化 → 全量重算；流式增量 → 只重算尾部；新块 → 只增量换行尾部并追加索引
- [ ] 缓存**在 `draw` 闭包里按 `frame.area().width` 失效**（不写单独的 resize 分支）
- [ ] **非 assistant 消息改多行原样渲染**（保留换行、不做 Markdown），续行按 speaker 前缀显示宽度缩进；**assistant 的消息保持全文 Markdown 不动**；工具输出保持 4 000 字符 preview 与 `summarize_args`
- [ ] 描画：`Paragraph` + 自算 `scroll`，**滚动位置自己夹紧**在 `0..=max`（`Paragraph::scroll` 不夹紧）
- [ ] 吸底：默认吸底；**任何上滚立即脱离**；脱离后新内容不改变视口；**提交（Enter）无条件回到底部并恢复吸底**
- [ ] 键与手势：`PgUp`/`PgDn` = 整页**减 2 行重叠**；`Ctrl-G` = 一次到底；**滚轮每格 3 行**；左键点击「点此到底」= 到底
- [ ] **除「点此到底」外，所有鼠标点击一律忽略**（不抢焦点、不选择、不改视口）
- [ ] **滚动条**：右缘**恒预留 1 列**（不因出现而改变转录宽度），只在内容超出时画字符；`ScrollbarState` 三个量都按**显示行**填；脱离吸底时要有可区分的视觉差异
- [ ] 脱离吸底时在转录区**底部右缘**显示 `↓ {n} 行新内容 · 点此到底`（无新内容时 `点此到底`），整块是一个鼠标命中矩形，`n` 按显示行算
- [ ] resize 锚点：吸底态保持吸底；脱离态保持顶部可见的**源行**
- [ ] 措辞：`↓ {n} 行新内容 · 点此到底` 与 `点此到底` 进 `wording.rs`
- [ ] 用例：滚动/吸底/脱离/提交回底；20 000 源行上限丢最旧；resize 锚点（两种态）；滚轮 3 行；「点此到底」命中矩形；其它区域点击无效；非 assistant 消息多行渲染；assistant 仍走 Markdown
