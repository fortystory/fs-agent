## Question

定下**鼠标点击作答**的完整契约。对象是**两套不同的绘制**：中段覆盖层（权限 / 计划冲突 / 超长粘贴 / Esc 清空草稿）与接管底部输入区的 `ask_user_question` 问卷。要回答的是「点哪里、点了发生什么、什么时候不响应」。

## 冻结的输入（不得重开）

- 详情覆盖层**不可叠在待答问题之上**（票 02 的边界同样适用于这里）。
- 不改 `events` schema、只动 TUI；plain / headless 不动。
- 现有「模态拥有键盘与鼠标」的守卫（`pending.is_some()` 时滚轮不滚转录）**保留**，本票决定在它之内放开什么。

## 需要定

1. **命中矩形的来源与失效**：沿用 `indicator` 的「绘制时记录矩形」先例，还是每帧由 `layout` 纯算？覆盖层几何在 `layout::Regions::modal` 里已有——选项行是第几行、怎么从 `PgUp/PgDn`、滚动窗口、resize 后重算。**必须给出每种问题的命中表**（权限的 `y/a/n` 三键行、计划冲突、两个确认，以及问卷的每个选项行 / 自定义文本行 / 翻页行 / 跳过行 / 提交行）。
2. **单击的语义**：单选点击后是直接提交答案，还是先高亮再等第二次确认；问卷单选点击是否**自动前进**到下一题（DSH 先例是前进）；多选点击只切换勾选、不提交；提交按钮/键的位置。
3. **滚轮与长列表**：问卷选项已有窗口（`option_window_start`）。滚轮在问卷里应该滚选项、滚转录、还是不动？中段覆盖层里的滚轮呢？
4. **点击空白/边框/被遮住的区域**：一律不动作（确认），以及详情覆盖层打开时的点击归属。
5. **焦点与光标**：鼠标点击后键盘光标（`highlight` / `index`）怎么变；点击自定义文本行是否把焦点交给文本编辑；点击后是否要重新显示光标。
6. **命中区域的可发现性**：选项行是否整行可点（含前导 `>`/`●` 与缩进）；是否需要视觉提示（反白/hover）；终端不开 any-motion 时的替代反馈。
7. **边界**：`40×10` 下覆盖层只有一行正文、候选键可能被截——命中表在这种降级尺寸下的定义；模态不显示（`Regions::modal` 返回 `None`）时点击一律不响应。
8. **一次只问一个问题**：现有「循环一次只问一个、迟到的丢失」守卫与鼠标命中的关系；run 结束时撤回在飞问题（票 31）后命中也随之失效。

## Answer

**契约定稿（2026-09-23，两轮 grilling、9 条决定）。** 下面是命中机制、`mouse()` 分派、两张命中表、焦点规则与不响应条件。

### §1 命中矩形的机制

- **绘制时记录，当帧重建**：`draw_frame` 画每个可点区时把它记进 `TuiState` 的**命中表**（条目 = 矩形 + 动作），`mouse()` 读**上一帧**的表。与现有 `indicator`（`Option<Rect>` + 绘制时赋值 + `mouse()` 包含判断）同一套机制；实现时可把 `indicator` 一并折进这张表。
- 命中判定沿用 `indicator_hit` 的半开区间：`x ≤ column < x+w && y ≤ row < y+h`。
- 表在每帧绘制前清空；**只有当帧真的画出、且没有被裁掉**的区域才有条目。

### §2 `mouse()` 的分派优先级

1. **详情覆盖层打开** → 鼠标只给详情（滚轮滚详情、点击命中滚动/关闭）。此时 `pending` 必为空（map 冻结项 6：详情不可叠在待答问题之上）。
2. **否则有 `pending` 问题** → 鼠标只给该问题（§3 覆盖层 / §4 问卷）。
3. **否则** → 现有转录路径：折叠提示行的点击（票 02/03）+ `indicator` + 转录滚轮。

**任何时候都不滚背后的转录**（保留现有「问题拥有指针」的守卫，只是把它从「整体早退」改成上面三段分派）。

### §3 中段覆盖层命中表（权限 / 计划冲突 / 超长粘贴 / Esc 清草稿）

四种问题都画成「标题 + 正文 + 候选键行」，**候选键行恒为最后一行**（票 01 事实 43）。

- 候选键行里**每个 `[key] label` 区间**是一个命中区（列范围按该选择项的 span 宽度现算，不是整行一个区）。
- 命中任一区间 → 走等价动作 `answer_key(question, 该键)`，与按下该键完全相同；`Esc` = 默认答案的路径不变。
- 点击标题 / 正文 / 边框 / 覆盖层内空白 → **不动作**。
- 候选键行被裁掉时（`40×10` 的长问题），**被裁部分没有命中**，未裁部分仍可点。
- `Regions::modal(rows)` 返回 `None`（放不下）→ 整块无命中；安全出口仍只有 `Esc` / `Ctrl-C`。
- `Esc` / `Ctrl-C` 的优先级**不受鼠标影响**（现有 `key` 路由不变）。

### §4 底部问卷命中表

- **可见选项行**（按当帧 `option_window_start` 算出的窗口）：**整行可点**（含前导 `> `、`●`/`[x]` 标记与缩进）。命中 → 先把 `highlight` 移到该选项，再执行 `confirm_highlight()`：
  - **单选**：选中该 label、清空 `custom`，然后 `advance()`（有下一题时）；**最后一题只确认、不前进、不自动提交**。
  - **多选**：切换该 label 的勾选，**不前进**（前进用底部 `下一题 →`）。
- **自定义文本行**（`questionnaire_parts` 的 `custom` 行）：点击 → 把焦点交给文本编辑并显示光标（§5）。这一行**不**执行确认动作。
- **底部可点条**（现在显示 `questionnaire_status` 的那一行）：`{n}/{N}` 保留，后面**只画可用的项**——
  - 非首页画 `← 上一题`，点击 = `back()`；
  - 非末页画 `下一题 →`，点击 = `advance()`；
  - `all_handled()` 画 `提交`，点击 = 提交（等价 `press(Enter)` 的提交分支）。
  - 不可用项不画 → 不存在命中区。
- **滚轮**：选项超出一屏时滚**选项窗口**——窗口由 `highlight` 推导，所以滚轮 = `move_highlight(∓1)`（一格一项）；中段覆盖层里滚轮**不动作**。
- 点击选项列表之外的空白 / 边框 / 被遮住区域 → **不动作**。

### §5 焦点与光标

- 点击选项**先移动 `highlight` 再确认**，所以点击之后键盘光标与鼠标一致（随后的 `↑/↓`、`Enter` 从被点那一项继续）。
- 点击自定义文本行 → 该题进入**自定义聚焦**态：之后 `draw_bottom` 在那一行显示光标（现状是问卷期间一律不显示光标，这一条是行为变更）。
- 进入聚焦态的入口只有两个：**点击自定义行**，或**键盘输入过可打印字符**。
- `advance()` / `back()` 切题时聚焦态**复位**（不跨题保留）。

### §6 不响应与降级

- 以下情况对应命中区**不存在**，点击一律不响应：`Regions::modal` 返回 `None`；候选键行被裁；选项不在当帧可见窗口；`pending` 被 `RunState { running: false }` 撤回（票 31 的 run 结束撤回）；终端低于最小尺寸（`40×10` 以下）。
- `40×10`：中段覆盖层只有一行正文，长问题的候选键可能被裁 → **只有可见部分可点**；问卷的 `panes.input` 只有 1 行 → 只命中当帧画出的那一行。
- **一次只问一个**：命中表只服务当前 `pending`；循环「迟到的丢失」与 run 结束的撤回会让旧矩形在下一帧自然消失（不再记录），不需要额外的失效广播。

### §7 实现落点提示（不写代码）

- `TuiState` 新增当帧重建的命中表（`draw_frame` 写、`mouse()` 读）；现有 `indicator: Option<Rect>` 可折进去。
- `mouse()` 目前是 `if self.pending.is_some() { return }` 的整体早退，要改成 §2 的三段分派。
- 中段覆盖层的候选键列区间从 `choices_row` 的 span 复算；问卷选项的可见行号 = `prefix.len() + (i − option_window_start)`。
- **底部可点条不要靠拼接后的字符串反推列区间**（脆弱）：让 `wording` 产出「项 → 文本」的列表，绘制与命中共用同一份。
- 聚焦态落点：`QuestionDraft` 加 `focused: bool`（或 `Questionnaire` 持一个「当前题的自定义行是否聚焦」标志）。
- 问卷底部新增 `← 上一题` / `下一题 →` / `提交` 三条措辞，落 `src/render/wording.rs`；这会改掉现在 `questionnaire_status` 的形态，`grilling：Ctrl-D 退出的确认与提示行` 与 `grilling：测试与验证迁移` 要对齐。
- 不改 `events` schema、不动 plain / headless。

### §8 给验证票（`grilling：测试与验证迁移`）的断言点

- 中段覆盖层：四种问题各点一次候选键区间 → 与按对应键结果一致；点正文/空白无动作；被裁的键不可点。
- 问卷：单选单击前进；最后一题单击**不提交**；多选单击只切换、不前进；底部 `← 上一题`/`下一题 →`/`提交` 的可用性与动作；滚轮移动高亮；点击自定义行后光标出现、切题后复位。
- 失效：`modal()` 返回 `None`、窗口滚动后、resize 后、`RunState{running:false}` 撤回后 —— 旧命中的坐标不再生效。
- 分派：详情覆盖层打开时点击不影响其后的转录；有待答问题时折叠提示行不可点（票 02/03 的边界）。
