## Answer

**形态定稿（2026-09-23，第一轮原型评审）。** 选定组合：**`▸ ` 行首标记 + `── 标题 ──` 分节横线 + 覆盖层宽 90 列 + `…`/`✓` 思考字形**。

- **可点击提示**：折叠提示行（`思考完成` 与工具行）行首加 `▸ `；流式期的「正在思考」**不加、也不可点**。
- **思考行**：`[kimi] … 正在思考` → 正文 delta 到达时**原地定格**为 `[kimi] ✓ 思考完成`（`DarkGray`）。两种标记同时在场时顺序是 `▸ [kimi] ✓ 思考完成`。
- **工具行**：`▸ [kimi] 调用 bash command=…`（`BOLD`）；失败行 `▸ [kimi] 调用 read_file path=… 失败`（`Red`，`失败` 在**行尾**、不另起一行）。
- **详情覆盖层**：分节用 `── 思考 ──` / `── 参数 ──` / `── 输出 ──` 横线（`DarkGray`）；标题 = 被点那一行的原文（`BOLD`）；**宽度上限 90 列**（仍居中于中段，更宽的终端不再加宽）；底部 `↕ n/m · esc 关闭`。

**产物**：`.scratch/tui-ux/prototype/` —— 13 张 `variant-*.txt`（被否决的备选）与 6 张 `chosen-*.txt`（选定组合）：`chosen-40x10` / `chosen-80x24` / `chosen-120x10` / `chosen-120x24` 覆盖尺寸矩阵，`chosen-detail-120x24` / `chosen-detail-80x24` 是同一组合 + 详情打开。每个变体解决什么见该目录 `README.md`。

**实测口径**：全部快照是 ratatui `TestBackend` 真渲染（`Terminal::new(TestBackend::new(w,h))` + `draw`，无 pty）；**颜色与 `UNDERLINED`/`BOLD` 在每张快照末尾的 `styles` 一节里逐行列出**，因为文本 dump 只有字形。四分区几何是近似（精确几何归 `prototype：删 airy 后的几何、降级阶梯与 Mark 间距`）；CJK 列宽按 East-Asian Wide/Fullwidth 近似。

**给实现票的接口约束**：

- `▸` 只加在**被点的那一行**，是可点击性的视觉提示，不进入 `wording` 的语句本身。
- `…` / `✓` 是**思考行文案的一部分**，要落 `src/render/wording.rs`。
- 覆盖层宽度 90 是本票的形态结论（票 02 把几何留给本票）。
