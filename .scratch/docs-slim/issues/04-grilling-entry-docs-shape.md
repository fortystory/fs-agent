# grilling：入口三份的重写形状与净行数目标

Type: grilling
Status: resolved
Part of: ../map.md
Blocked by: 03

## Question

冻结项 7 把「净行数指标」只给入口三份（[`README.md`](../../../README.md) / [`.scratch/README.md`](../../README.md) / [`AGENTS.md`](../../../AGENTS.md)），因为只有它们有明确可删的复述。**但「删成什么样」还没定** —— 这是三条独立的形状决定：

1. **`.scratch/README.md` 第 11 行那 7,429 字符的段落**：它是逐日流水账（「2026-10-01 落地了 X、10-02 落地了 Y……」），同一份经过在各 feature 的 `spec.md` 抬头与票里已经有一份，冻结项 4 允许删。**删完剩什么形状**？候选：
   - (a) 一句话「本索引表是权威；各 feature 的经过在它自己的 `spec.md` / `map.md` 抬头」+ 那张表原样；
   - (b) 除了那句话，再留一段「`.scratch/` 的读法」（约定、状态词表、数法）；
   - (c) 连表也重排（表本身 42 行，单元格里有极长的一句话）。
   还要定：**这张表将来怎么维护**（它 churn 全仓最高，26 次）—— 与本文 `Not yet specified` 第一条雾有关，但本票只定「这一份长什么样」。
2. **`README.md` 的「状态」段（第 26 行，2,664 字符）**：它逐条记 2026-10-02 / 10-03 每次落地。**删完剩什么**？「v1 的 34 张票全部 done」「当前规模数字」「怎么复核」这三件事要不要全留 —— 后两类其实都能从命令派生。
3. **`AGENTS.md` 的 `### Docs` 节**（冻结项 8）：留哪些指针、删哪些复述。它每轮全文注入，所以要**按「每轮都成立」的标准逐句过**（[`docs/skills.md`](../../../docs/skills.md) 的判据：超过 80% 的回合都成立吗）。那五个英文小标题是技能工具链的锚点，**不能动**。
   **已实测**（charting 阶段）：`AGENTS.md` 共 1,317 字符，其中 `### Docs` **601 字符（46%，全文件最大的一节）**；同文件 `## 语言` 387、`### Issue tracker` 113、`### Domain docs` 74、`### Triage labels` 63。那 601 字符里，约 380 是**复述 [`README.md`](../../../README.md)「约定」小节（1,827 字符）的语言线**，约 100 是指针（`.scratch/README.md` 是 feature 索引 + 「新增文档前先读这两处、照邻居写」），约 200 是讲**本文件自身**小标题语言的引用块（讲的是这份文件的 schema，不重复，应保留）。所以可删的复述约 380 字符 —— **这一节能压到约 250 以内**，整份 AGENTS.md 从 1,317 降到约 950。注意 AGENTS.md 的 `DOCS_MIN_RATIO` 下限是 23%、实测 29.9%（余量 6.9，scope 内最宽的之一），**这里删中文比别处安全**，但删完要重跑 `check-language.py`。

还要定**净行数目标**：三份各自降多少（或合计降多少）。目标要能被 [票 05](05-grilling-guardrail-contract.md) 的脚本复核 —— 一个「净行数 ≤ N」的硬数字，不是比例印象。

**依赖**：本票要读 [票 03](03-research-long-paragraph-triage.md) 的逐段分类 —— 那 8 段 ≥1500 的重写形状是它的产物，其中包括 `.scratch/README.md` 与 `README.md` 各 1–2 段。

## 需要人拍板的点

- 三条形状各自的选项（1 的 a/b/c，2 与 3 同理）。
- 三份各自的净行数目标值。
- `.scratch/README.md` 的表格要不要一起重排（那一列「一句话」里最长的单元格有多长，见票 03 的产物）。

## Answer

**结论：三份各有明确的形状 + 一组可复核的数值目标；指标口径修正为「非空白字符数 ≤ 上限 + 行数 ≤ 上限」。**（本轮七问全在 live exchange 里由维护者拍板。）

### 1. `.scratch/README.md` —— 极简 + 读法一段（Q1 = a）

删掉 L5-9 整块（六条约定；权威在 [`docs/agents/issue-tracker.md`](../../../docs/agents/issue-tracker.md)）与第 11 行那段 **7,429 字符**的逐日流水账（约六成是复述，删）；保留一小段「`.scratch/` 怎么读」；**表格结构不动**（只精简 3 个写满逐日经过的单元格：L43 729、L53 564、L47 562 字符）。L59-74 拆 3、L76 拆 2。

「读法一段」的边界（Q7 = a）：
- **留 ①**：三种形态（`spec` / `map` / `seed`）+ `Status:` 词表 + 数法命令；
- **留 ②**：需求池的账（「16 条意向、现值 10 条」+ 移交 / 折成 spec 的说明）—— **压成一行**。它是唯一一份，各 `seed.md` 只自述「这不是 spec」；
- **删 ③**：四张 wayfinder 图的状态小结 —— **已过期**（现在是 7 张 map），且各图抬头自己写着；
- **删 ④**：两条如实记录（`call-rationale` 空目录已不在；`map` 与 `spec` 并存是 tracker 常识）。

### 2. `README.md` 的「状态」段 —— 结论 + 复核方式（Q2 = a）

2,664 字符压到 **250–390**，只留两样：**① v1 的 34 张票全部 `done` 这个结论** + **③ 怎么复核**（`cargo test` / `wc -l` 那两句）。规模数字（行数 / 测试数）**只留一处**并在旁边写明数法 —— 这是 [`docs-tidy`](../docs-tidy/spec.md) 那次立的规矩（「数字旁边写上它是怎么数出来的」）。逐日经过全删（各 feature 的 `spec.md` 抬头已有一份）。

### 3. `AGENTS.md` 的 `### Docs` 节 —— 留指针、删复述（Q3 = a）

601 字符压到 **≤250**：保留两个指针（`.scratch/README.md` 是 feature 索引；「新增文档前先读这两处、照邻居写」）与那段讲**本文件自身**小标题语言的引用块（这份文件的 schema，约 200 字符）；**约 380 字符的语言线复述删掉**，换成一句「语言约定见 `README.md` 的『文档』一节」。五个英文小标题不动。

**它是唯一只受体量指标约束的落点** —— 票 03 实测 `AGENTS.md` **没有任何 ≥500 的单元**，段落护栏看不见这一节。

### 4. 指标口径的修正（Q4 → Q5）

Q4 选了「字符数必须降 + 行数不得增」，但**「行数不得增」不成立**：拆段落要加空行（`.scratch/README.md` 第 11 行一段拆 8 段就 **+14 行**）。修正为（Q5 = a）：

- **硬线 = 非空白字符数 ≤ 上限**（唯一的内容体量判据）；
- **行数也各给一个上限**（= 拆完的预计行数 + 小余量）：既允许拆，又拦住以后往入口文档追加流水账。

### 5. 数值目标（Q6 = a：按票 03 的删法推算 + 留余量）

| 文档 | 非空白字符：现在 → 上限 | 行数：现在 → 上限 |
| --- | --- | --- |
| `.scratch/README.md` | 18,100 → **≤13,500**（推算 12,760） | 82 → **≤100**（拆完约 97） |
| `README.md` | 19,954 → **≤18,500**（推算 17,684） | 286 → **≤300**（拆完约 290–294） |
| `AGENTS.md` | 1,225 → **≤950**（推算 845） | 26 → **≤30**（拆完约 27–29） |
| **合计** | 39,279 → **≤32,950** | — |

上限是「**不得超过**」而不是「必须压到」：推算偏差不会造成失败；改完若更低，棘轮可以跟着收紧 —— 收紧的机制归 [票 05](05-grilling-guardrail-contract.md) 的「棘轮 vs 快照」那一条。

### 6. 交给 `/to-spec` 的执行要点

- 三份都在冻结项 2 的 scope 内；**只删「别处已有一份的复述」**，其余只拆（冻结项 4）。
- 删完重跑 `python3 scripts/check-language.py`：`AGENTS.md` 余量 6.9（安全）；**`.scratch/README.md` 与 `README.md` 都不在 `DOCS_MIN_RATIO` 清单里**，不受中文占比下限约束。
- 字符数 / 行数上限写进 [票 05](05-grilling-guardrail-contract.md) 的 `scripts/check-doc-size.py`。
- **不碰**：`.scratch/README.md` 表格的 42 行结构、`README.md` 的其它章节、`AGENTS.md` 的五个英文小标题。
