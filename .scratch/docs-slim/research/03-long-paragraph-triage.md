# research：超长文本块的豁免分类

票 [03](../issues/03-research-long-paragraph-triage.md) 的产物。日期 2026-10-04。
scope = 36 份活文档：`README.md`、`CONTEXT.md`、`AGENTS.md`、`.scratch/README.md`、`docs/*.md`（顶层）、`docs/adr/*.md`、`docs/agents/*.md`。**排除** `docs/research/`、`.scratch/*/issues/`、`.scratch/*/spec.md`、`.scratch/*/research/`。

一句话结论：**冻结项 5 的「空行分隔整块」把连续的 bullet 清单算成了一段 —— 79 个「超长段落」里 60 个是清单块。换成「散文段 + 顶层清单项」的单元口径，真正 ≥500 的只有 22 个单元（19 个散文段 + 3 个清单项）。逐块分类是 可拆 68 / 是复述 11 / 需豁免 0；逐一豁免判据实测，今天唯一需要豁免的是 `README.md`「文档」表里两个纯指针单元格，整段一个都不需要。**

## 1. 口径与基线（先修一个数）

同一份 scope，四种口径下的段数（`≥500 / ≥800 / ≥1500`）：

| 口径 | ≥500 | ≥800 | ≥1500 | 最长 |
| --- | ---: | ---: | ---: | ---: |
| **A 整块**：空行分隔的整块，排除表格 / 围栏代码 / `#` 标题（冻结项 5 原样） | **79** | **31** | **8** | 7,429 |
| B 整块，再剥掉 markdown 标记字符（反引号、星号、下划线、井号、方括号、圆括号、波浪号等）后计长 | 63 | 29 | 5 | — |
| C 整块，去掉所有空白后计长 | 66 | 26 | 7 | — |
| D 在每个清单项行处断开得到的块（续行会被切成独立块，仅作对照） | 18 | 3 | 2 | — |
| **E 单元**：散文段 + 顶层清单项（含续行与嵌套子项） | **22** | **4** | **2** | 7,429 |

读法与结论：

- map 的「≥800 约 30、≥1500 8」与口径 A 精确吻合，说明当时那份基线用的是**整块口径**；但「≥500 约 60」在任何口径下都复现不出来（A=79、B=63、C=66、D=18）。最接近 60 的是 B（剥标记后 63），大概是那次的口径或笔误。**给票 05 的告警：不要把「约 60」当验收基线，它不是可复现的数。**
- 79 个整块里 **60 个是清单块**（首行是 `-` / `*` / `+` / `1.`），它们一共含 **335 个顶层清单项**；整块口径把 335 个单元压成了 60 个数。真正 ≥500 的清单项只有 **3 个**（`docs/render.md` 的「标记」569、`docs/adr/0008` 的「`markdown.rs` 被重写」551、`README.md` L251 的「散文一律中文」512）。
- 19 个散文段里，8 个是复述（`README.md` 3 个 + `CONTEXT.md` 5 个），11 个可拆。
- 所以「60 段要拆」是口径制造的。**段落单元应定义为：散文段，或一个顶层清单项连同它的续行与嵌套子项。**

量测口径：块 = 连续非空行的最大串（遇到空行、表格行、围栏代码块、`#` 标题即断）；字符数 = Python `len(text)`（含行内代码与标点，含换行）；顶层清单项 = 以 `^\s*([-*+]|\d+[.)])\s` 起、缩进不深于该块首个清单项的行及其后续行。

## 4. 可执行的豁免判据

### 4.1 先定义「单元」（护栏脚本的第一步）

1. 切块：空行分隔的连续非空行；遇到表格行（`^\s*\|`）、围栏代码块（``` / ~~~）、`#` 标题即断（与冻结项 5 同）。
2. 块若是清单块（首行匹配 `^\s*([-*+]|\d+[.)])\s`）：**每个顶层清单项连同它的续行与嵌套子项算一个单元**；块首到第一个清单项之间的散文另算一个单元。
3. 否则整块算一个单元。
4. 表格单元格单独算单元（按 §5 的口径量）。

单元长度 ≥500 才进入豁免判定；不命中就报红（票 05 的护栏）。

### 4.2 自动豁免（两条，可直接放行）

- **R1 引文**：单元里以 `>` 开头的行占单元字符数 ≥50%。
  ```python
  q = sum(len(l) for l in unit.split("\n") if l.lstrip().startswith(">"))
  exempt = q / len(unit) >= 0.5
  ```
  理由：外部引文失真即失去核对价值（与 `docs/research/` 的纪律同一条）。本语料 0 命中（scope 内没有 ≥500 的引用块，冻结项 5 那句「引用块待定」今天可以先定成「豁免」）。
- **R2 纯指针枚举**（表格单元格或清单项）：链接跨度占单元 ≥50%，且 `·` / `、` 分隔符 ≥4 个。
  ```python
  link = re.compile(r"\[[^\]]*\]\([^)]*\)")
  span = sum(m.end() - m.start() for m in link.finditer(unit))
  exempt = span / len(unit) >= 0.5 and (unit.count("·") + unit.count("、")) >= 4
  ```
  理由：索引本身就是内容，拆开只会把指针拆散。**本语料命中 2 个**：`README.md` 文档表的 L242（571，`docs/` 逐面链接枚举）与 L244（1,241，11 个 ADR 链接 + 一句摘要）。这是今天唯一进豁免名单的东西。

### 4.3 复核候选（脚本打印、不自动放行）

这三条形态对，但自动判据只能当筛子，命中后交人定（票 05 可以让脚本打一行 `review:` 而不非零退出）：

- **R3 单一长句**：散文单元，按 `。！？` 切分后最长切片 ≥0.8×len，**且**再按 `；、` 切分后最长切片仍 >500（次级停顿也切不出合格段）。
  ```python
  ss = [x for x in re.split(r"[。！？]", unit) if x.strip()]
  sub = [x for x in re.split(r"[；、]", unit) if x.strip()]
  review = kind == "prose" and max(map(len, ss)) / len(unit) >= 0.8 and max(map(len, sub)) > 500
  ```
  校准样本：`README.md` L141（530）在第一半命中、第二半被否（有 2 个 `；`，切成 234/205/91 都合格）—— 这半条是实测捕到的唯一一次假阳性，也证明它必要。**今天 R3 命中 0。**
- **R4 不可断因果链**：散文单元，句子 ≥3 且 ≥60% 的句子以指代 / 连接词开头（这 / 那 / 它 / 该 / 此 / 因此 / 所以 / 于是 / 结果 / 前者 / 后者 / 代价是 / 好处是）。
  ```python
  ss = [x.strip() for x in re.split(r"[。！？]", unit) if x.strip()]
  lead = re.compile(r"^(这|那|它|该|此|因此|所以|于是|结果|前者|后者|代价是|好处是)")
  review = kind == "prose" and len(ss) >= 3 and sum(1 for x in ss if lead.match(x)) / len(ss) >= 0.6
  ```
  **今天命中 0**：本语料没有「删一句就留下悬空指代」的长段。票 03 起初以为 `docs/lifecycle.md` L241-249 是这种，读原文后更正 —— 它是 3 条独立编号注记。
- **R5 次序操作序列**：单元是单条编号项，含 ≥3 个次序词（先 / 再 / 然后 / 接着 / 之后 / 最后 / 直到），且不含 `；`。
  ```python
  review = kind == "item" and re.match(r"^\s*\d+[.)]\s", unit) and \
           sum(unit.count(w) for w in ("先","再","然后","接着","之后","最后","直到")) >= 3 and "；" not in unit
  ```
  **今天命中 0**：走查清单的每一步都短（全语料最长的清单项是 `docs/render.md` 的「标记」569，可切两刀）。

### 4.4 阈值是起点，不是终点

`0.5 / 0.8 / 0.6 / ≥4 / >500` 都是本轮定的起点；票 05 要调它们时，回归样本就是本文件 §2 的 79 行表 + §4.3 的 `README.md` L141 假阳性。名单（哪几段豁免）会过期，规则不会。

### 4.5 今天豁免名单的实际内容

- **自动豁免 2 项**，都是 `README.md` 文档表的单元格：L242、L244。
- **整段 0 项**。79 个整块里没有一个需要豁免：60 个是清单块（按项拆开全部合格），19 个散文段里 8 个复述、11 个可拆。
