6. **边界**：历史里同一次工具调用出现多次（同一 `tool_call_id` 不会有）；历史里 `tool_call` 没有结果（悬空，票 02 会查明其日志形状）时点击显示什么。

## Answer

**契约（2026-09-23，4 条决定）。**

### §1 与 tui-ux 契约的关系

- **不新增形态**：历史详情**就是** tui-ux 票 02/03 的那套覆盖层（`── 标题 ──` 分节、90 列上限、内部滚动、`Esc` / 再点关闭）。本票只规定「历史块也要产出同样的可点行」与「历史场景下的取数」。
- 命中沿用 tui-ux 票 04 的**绘制时当帧记录**机制——它天然吸收 `Pane::evict` 在重播中的显示行整体平移（票 02 事实 28），**不需要历史专用的例外**。（**2026-09-23 落地后的具体符号**：`TuiState::apply` 维护的 `links`，与 pane 平行、同受 20 000 淘汰；**历史行必须经 `apply`**，直接 `Pane::push` 不会带 `▸` 命中。见 `map.md` 的「已落地的 tui-ux 接缝」。）

### §2 可点范围

- 历史里的 **`✓ 思考完成` 行与工具行**带 `▸`、可点；**历史分隔行**（`── 以上为历史 ──`，`Block::Notice`）**不可点**。
- **重播期间（`replay.is_some()`）鼠标一律不响应**——滚轮也不滚，与票 01 §5 的键盘边界一致（重播是一过性状态）。重播完成后恢复。
- 命中实现与 live 同一条：每个可点行在**绘制那一帧**把矩形记进命中表。

### §3 工具详情：取数与降级表

判据 = 事件文本里是否含溢出注记 **`full output at <path>`**（`src/context.rs:462-464`）：

| 事件文本 | `<会话目录>/outputs/<id>.txt` | 详情显示 |
| --- | --- | --- |
| 含 `full output at …` | 存在且非空 | 文件全文（仍受 tui-ux 的 200 000 字符上限约束 → 超出 `已截断`） |
| 含注记 | 不存在（`prune` / 手删） | 事件里的 head/tail 预览 + `全文不可用` |
| 含注记 | 存在但为空 | 预览 + `全文不可用` |
| **不含注记** | （从不尝试读） | 事件文本**本身就是全文**，直接显示、不报「不可用」 |

- 路径规则与 live 相同：`SessionFacts.cwd` 是**会话目录**，取 `<cwd>/outputs/<tool_call_id>.txt`；`prune` 会整个删掉会话目录（票 02 事实 40）。
- 悬空调用的**合成结果**（`ok: false` + `INTERRUPTED`，票 02 事实 31-32）**不含注记** → 按最后一行显示那段文本，不会误报「不可用」。

### §4 思考详情

- 只来自 `MessageCompleted.reasoning`，与 live 相同（超限同样 `已截断`）。
- 合成器等 `reasoning: None` 的历史**没有**「思考完成」行（票 03 §1），所以**没有可点的思考详情**——**不伪造、不弹空框**。理由：推理增量不落日志，无法从历史判断「当时是否在思考」；要做到就得改 schema（`## Out of scope` 已排除）。

### §5 覆盖层行为

- 与 live 完全一致：`Esc` / 再点同一行关闭；`↑/↓`、`PgUp/PgDn`、滚轮滚详情；打开时**视口冻结（吸底暂停）**，期间到达的 live 事件照常 append 但视口不跟随；关闭后**恢复吸底**。
- 它不是 `pending`（tui-ux 票 02），所以不拦既有的键盘 / 鼠标分派；「有待答问题时详情不可开」的既有规则不变。

### §6 边界

- 历史里同一个 `tool_call_id` 只出现一次（日志按调用追加）。
- 悬空 `tool_call`：恢复已把合成结果**写进日志**（票 02 事实 31），所以详情显示 `INTERRUPTED` 文本。本图的接缝在恢复**之后**，不会看到「没有结果的调用」这种状态。
- 历史分隔行 / 轮次分节线 / 无 `▸` 的行：一律不可点。

### §7 给下游

- 票 05 要断言：历史 `▸` 行可点；§3 的四种文件状态各自的详情文案；重播期间点击不响应。
- **不新增 `wording` 条目**——复用 tui-ux 的 `全文不可用` / `已截断` / `↕ n/m · esc 关闭`。
