**What to build:** 点一行或按 `Enter`，在**详情覆盖层**里开那份 diff。正文在打开那一刻按需取：
已跟踪文件跑 `git diff HEAD -- <path>`，**未跟踪文件直接读盘给全文**。弹窗里每行带行号、头行四行
不画、太长的有界截断、二进制只报一句。

## 验收

- [x] 点一行打开详情覆盖层；键盘在改动页时 `Enter` 做同一件事
- [x] 弹窗标题是路径（超宽尾部 `…`）；未跟踪文件写 `新文件`
- [x] 正文是那一份 diff：`@@` 那行留着（它带函数上下文），`diff --git` / `index` / `---` / `+++`
      四行**不画**
- [x] 每行带行号：新增与上下文取**新文件**的号、删除取**旧文件**的号；hunk 头与头行留空
- [x] 行号列 = 最长行号位数 + 1，右对齐 + 一格空格，**续行顶格**
- [x] 正文按**文本区宽**（框宽 − 4）排版，不是按框宽
- [x] 太长的 diff **有界截断**并写 `只显示前 N 行，还有 M 行`；二进制写 `二进制文件，不显示内容`
- [x] 未跟踪文件的正文是全文（它的 diff 是空的，这一点由取数那一层挡住）
- [x] 弹窗可滚、`Esc` 关掉；关掉之后这一页停在原处
- [x] 这个弹窗**不进事件流、不进 `messages`、不打码**；正文进屏幕文本层、可拖选复制
- [x] 详情覆盖层加变体只动既有的三处（enum 一项、唯一那个 switch 一支、一个打开入口），
      打开方的记账照既有的 `DetailOpener` 形状（不冻任何页）
- [x] `docs/render.md` 的详情覆盖层一节写上这个变体

## 评论

落地：`DetailKind::Diff` + `DetailOpener::Changes`（不冻任何页）。正文在打开那一刻取：未跟踪的直接
读盘，已跟踪的跑一次 `git diff HEAD -- <path>` —— 那是子进程，所以弹窗先立起来、正文后到（`Body::Pending`
那一句占位），结果回来时对**序号**，迟到的那一份直接丢掉。行号、头行四行不画、三档截断、二进制一句
与 `新文件` 标题都有帧层断言；真终端里 `Enter` 打开过一份真 diff（`@@` 行、行号、`↕ 14/26 · esc 关闭`）。
