## 问题

[01 号票](01-charting-decisions.md) 把这一页的**形态**定死了（常驻第四签 `改动`、一行 = 文件名 +
状态字形、先按状态分组再字典序、点开是整份 diff 可滚、不可用态写一句），但**没有一张图**。
它在 40 列与 28 列两档、120×24 下那块页区里一屏到底装得下什么？路径怎么截？组标题长什么样？

这一票只画**长什么样**，不重新讨论形态本身。走 `/prototype`：**画出来**（帧草图、取舍掉的
几个备选、以及它们为什么被丢），把结果收进本票的 `## 作答`。

### A. 列表那一侧

1. **一屏几行**：宽档（40 列）与窄档（28 列）下页区各有多少行（宽档今天要不要先花掉标记与身份
   那几行？以 `layout.rs` 与 `tui.rs` 的实际几何为准 —— 文件页那边量过一次，照它的口径重算）。
2. **状态字形怎么画**：`M` / `A` / `D` 是 1 列、`??` 是 2 列 —— 放行首还是行尾、要不要**补齐列宽**
   （文件页因为「同层名字严格同列」给字形列定了「每行都占满两格」，这一页要不要同一条规矩）？
   `??` 要不要换成别的写法（真正两列的 `??`，还是自己的字形）？
3. **路径怎么截**：显示**全路径**（相对 cwd）还是基名？截断口径是什么（尾部 `…`？保基名？
   保末尾几级目录？）—— 28 列下 `src/render/tui.rs` 只剩 14 列给路径。
4. **分组怎么画**：组标题要不要占一整行（`已修改` / `未跟踪` / …）、用什么字形、给不给色；
   空组不画。分组头与第一行之间要不要空行（`文件页` 是紧凑的，没有空行）。
5. **状态字形与分组的对应**：porcelain 的 `XY` 两列怎么折成一个字形（`MM` 画 `M`？），
   这一条与图里「尚未明确」那两条相邻，取定一个最小可用的口径写进作答。

### B. 弹窗那一侧

6. **标题放什么**：路径（可能很长，135 列封顶的框怎么截）、状态字形要不要进标题。
7. **正文的列宽口径**：`files-page` 记过一处既有落差 —— 详情正文的排版宽度用的是**框宽**，
   而实际文本区比它窄 4 列；`file_body_lines` 是照**修正后**的口径写的还是照旧的？这一页照它
   （给结论与依据）。
8. **行号与 diff 标记**：diff 正文的行号从哪来（hunk 头 `@@ -a,b +c,d @@` 里的两个区间，
   新增 / 删除 / 上下文各取哪一列），行号列占几列、`+`/`-` 标记占几列、折行时续行怎么排
   （`file_body_lines` 的模板能不能直接借）。
9. **头行留不留**：`diff --git` / `index` / `---` / `+++` 四行在弹窗里留不留（`diff_tag` 今天把
   它们归进 `Hunk`）。
10. **三句文案**：二进制文件、截断（读了多少行 / 省掉多少）、未跟踪文件（没有 diff，给全文 —— 
    标题与开头要不要说清「这是一份新文件」）。

### C. 页面那三句

11. **空态与不可用态**：工作区干净、不是 git 仓库、`git` 不在 `PATH`、正在取数 —— 各写一句
    （28 列下也要读得下去），与 `wording.rs` 的既有命名习惯对齐（`tab_placeholder` 那一族）。

### 产物

## 作答

**产物**：[`prototype/frame.py`](../prototype/frame.py) —— 一份可执行的帧草图（`python3
.scratch/diff-page/prototype/frame.py` 一条命令重画两档的页区与弹窗）。它按仓库的真实几何算，
数字与出处写在脚本头部的注释里，不是估的。

### A. 列表那一侧

1. **一屏几行**（按 `layout.rs` 的算式重算）：**宽档 120×24 ⇒ 页区 40 列 × 15 行**（块字收起来
   那一版占 `LOGO_COMPACT_ROWS=5` 行 + 页签区 `TAB_ROWS=3` 行，`layout.rs:94,533`）；
   **窄档 80×24 ⇒ 页区 28 列 × 19 行**（文字身份占 `IDENTITY_ROWS=1` 行 + 页签 3 行，
   `layout.rs:105`）。窄档反而多四行 —— 它在顶上花的身份行少。
2. **状态字形占满两格**：`M ` / `A ` / `D ` / `??`，于是名字严格落在同一列上。与文件页那条
   真机反馈后的规矩同源（`.scratch/files-page/spec.md` 补记：那一列每行都占满两格）。
   **被否决**：只占一格 —— `??` 会把那一行的名字推右一格（脚本里留了这张对照帧）。
3. **全路径（相对 cwd）**，超宽**尾部 `…`** 收尾（与文件页「名字超宽用 `…` 收尾」同一条口径）。
   窄档下名字拿 **25 列**（28 − 字形 2 − 空格 1），实测这一组路径一条都没被截 —— 票里原先
   那句「只剩 14 列」是没算对的假设，以脚本为准。**被否决**：只画基名（`.scratch/diff-page/map.md`
   与别处的 `map.md` 会分不出来，而这一页没有悬停提示）。
4. **分组标题占一整行、不带计数**：`已修改` / `新增` / `已删除` / `未跟踪`，空组不画，标题与
   第一行之间**不空行**（紧凑，与文件页一致），标题**不给色**（与「过程退后、内容保持、信号
   着色」那条纪律一致）。**被否决**：带计数（`已修改 3`）—— 标题行多占两列，而件数不是这一页
   要回答的问题。
5. **`XY` 折成一个字形的最小口径**：优先取**工作区**那一位（`Y`），它为空时取 index 那一位
   （`X`）；`??` 是整列的单字符。于是 `MM` / ` M` / `M ` 都画 `M`，`A ` 画 `A`。已暂存与
   未暂存**不在这一页上分家**（图的「尚未明确」那条照旧留给 spec，本票不再往下切）。
6. **放不下时**：画满页区，末行写一句「**还有 M 处改动**」。**被否决**：给这一页加滚动 ——
   左栏页区今天没有滚动机制（滚轮给文件页、`↑`/`↓` 归焦点行），那是新机制、够自己一张票；
   **也否决**了「什么也不说」（读者不知道下面还有东西）。滚动的诉求若真机提出来，另起一张票。

### B. 弹窗那一侧

7. **标题 = 路径**（超宽尾部 `…`），**不放状态字形**（弹窗已经指明了是哪个文件）；未跟踪文件的
   标题明说「**新文件**」（它没有 diff，正文是全文）。
8. **正文列宽 = `Regions::detail_text_width()`（框宽 − 4）**，**不是框宽**。依据：`file_body_lines`
   收到的就是它（`src/render/tui.rs:3217`、`3417`），而 `layout.rs:240-248` 的注释写明这就是
   files-page 票 05 对齐过的那处 —— **那处落差已经修掉了，这一页照抄即可**，不要再按框宽排。
9. **行号列 = `digits + 1`**（`digits` = 该份 diff 里最长行号的位数），右对齐 + 一格空格，
   与 `file_body_lines`（`tui.rs:8104,8111`）同形；折行在插前缀**之后**按剩余预算算，续行顶格。
   行号取值：**新增行与上下文行取新文件的号，删除行取旧文件的号**；hunk 头与头行**不给行号**
   （留空）。120 列屏 ⇒ 正文 112 列；80 列屏 ⇒ 正文 72 列。
10. **头行不留**：`diff --git` / `index` / `---` / `+++` 四行不画（弹窗标题已经说明是哪个文件，
    而人是来看代码怎么变的）。`@@` 那行**留**（它带着函数上下文，也是读者定位的锚）。
    **被否决**：留着原样 —— 每份 diff 开头白占四行。
11. **三句文案**：二进制 → `二进制文件，不显示内容`；截断 → `只显示前 N 行，还有 M 行`；
    未跟踪 → 标题 `新文件`（正文即全文）。三句都照 `wording.rs` 的既有命名习惯落常量。

### C. 页面那四句

12. 空态与不可用态（都用 `wording` 常量，28 列下也读得下）：
    - 工作区干净 → `没有改动`
    - 不是 git 仓库 → `这里不是 git 仓库`
    - `git` 不在 `PATH` → `找不到 git`
    - 正在取数 → `正在读取改动…`（对齐文件页那两句 `正在读取工作区…` / `工作区里没有文件`）

### D. 真机观感项（折 spec 时写进 `docs/tui-manual-checklist.md`）

- 两档下这一页读不读得下去 —— 尤其 28 列下长路径被 `…` 收尾之后还认不认得出是哪个文件。
- diff 的颜色（`diff_tag` 给的**背景**色 + 语法高亮的前景叠加）在真配色下够不够分。
- 组标题与内容都不给色时，读者分不分得开哪一行是标题。

### E. 这票与图的关系

- 「大与多的边界」那片雾里**两半已经答了**（几千个改动文件怎么办 = 画满 + 一句；二进制那句
  文案 = 上面第 11 条），只剩「一份 diff 读到第几行截断」那一个数没定 —— 它随 spec 定。
- 「弹窗里留不留头行」那片雾**整条答完**（不留）。
