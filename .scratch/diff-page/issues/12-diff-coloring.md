# 12 — 那份 diff 上色

Type: implement
Status: done
Part of: ../map.md
Blocked by: 11

> 规格：[`../spec.md`](../spec.md) 的实现决定 §6 的后半与用户故事 B 里那两条（上色、语法高亮）。
> 前置是 [11 — 点开一份 diff](11-open-the-diff.md)。

**What to build:** 弹窗里的 diff 有颜色 —— 新增、删除、hunk 头各一档，代码部分按扩展名认语言做
语法高亮。仓库里那一层 diff 标记与它的颜色**早就写好了、一直没有调用方**，这一票是它的第一个
真调用方；顺手修掉它写死按 Rust 高亮那处。

## 验收

- [x] 新增 / 删除 / hunk 头按现成的 diff 标记层上色 —— 注意它给的是**背景**色，正好与语法前景叠加
- [x] 代码部分按**扩展名**认语言做高亮（与文件内容弹窗同一层），并修掉「不管什么文件都按 Rust
      高亮」那处
- [x] 用到的颜色走**语义色板**（一个语义一个具名常量），绘制处不写颜色值
- [x] 拖选复制出来的**仍是文本**：不带样式、不带转义序列、行号与截断提示按既有的取舍处理
- [x] 折行与截断不受上色影响（长行照旧按文本区宽折）
- [x] 高亮那一层的既有断言不回退（它今天只有测试在调用那条 diff 路径）

## 评论

落地：`DiffTag::style` 的三档颜色收进色板的**内容域**（`DIFF_ADDED` / `DIFF_REMOVED` / `DIFF_HUNK`）；
`highlight_diff` 那处「写死按 Rust 高亮」由 `highlight_diff_with(language, …)` 接上按扩展名认语言，
改动页的弹窗是 diff 层第一个真调用方。两层合成（背景 + 前景）在 `tests/render_changes.rs` 里按格子断言。
