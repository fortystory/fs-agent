# 13 — 刷新与手动重取

Type: implement
Status: done
Part of: ../map.md
Blocked by: 09

> 规格：[`../spec.md`](../spec.md) 的实现决定 §4 与用户故事 D。前置是
> [09 — 改动页画出一列改动的文件](09-diff-page-list.md)（取数件在那一票里立起来）。

**What to build:** 那一列数据跟着工作区走 —— 模型改过工作区、提交之后、`/undo` 之后各重取一次，
连着几次改动合并成一次；键盘在改动页时按 **`r`** 手动重取，并给一句提示行回执 —— 因为在**外部
shell 里做的 `git add` 不会触发任何信号**。失败时保留上一次读数。

## 验收

- [x] `WorkspaceChanged`（任何非只读工具调用收尾）、提交之后、`/undo` 之后各重取一次
- [x] 执行者与讨论者改过的工作区也算（它们落在同一条父流、同一个渲染器上）
- [x] 连着几次触发**合并成一次**取数：在飞时不并发，且**不丢更新**（最多延后一轮）——
      用**自己的**一个位，**不共用**文件索引那个位
- [x] 页面**不在前台**（左栏收起、或停在别的页）时也照旧取数
- [x] 键盘在改动页时按 **`r`** 重取，提示行给回执；`r` 在别的视图与输入区里一个字不变
- [x] 取数失败**保留上一次的读数**，提示行给一句失败回执，页里内容不动
- [x] 页里**不画**「上次取数时刻」，也不做阈值提示
- [x] 断言在帧测试层用状态机口子做（拉位、回传结果），不起真任务

## 评论

落地：触发点（进 TUI、`WorkspaceChanged`、提交之后；`/undo` 与执行者 / 讨论者都走同一条静默信号）、
**自己的一个位**（不共用 `file_scan_wanted`）、在飞时不并发但不丢更新、失败保留上一次读数 + 提示行回执、
页面不在前台也取数、`r` 手动重取 —— 取数件在票 09 里落地，本票把它们逐条钉成了断言。
