# 10 — 键盘交给这一页（焦点行）

Type: implement
Status: done
Part of: ../map.md
Blocked by: 09

> 规格：[`../spec.md`](../spec.md) 的实现决定 §7 与用户故事 C。前置是
> [09 — 改动页画出一列改动的文件](09-diff-page-list.md)。

**What to build:** 点左栏任意处把键盘交给改动页 —— 焦点行落在点的那一行并高亮，`↑` / `↓` 移它，
`Esc` 只把键盘还回去（不取消正在跑的回合）。与文件页**共用同一套归属位**，不另起一套。

## 验收

- [x] 点左栏任意处（页签条与页区都算）把键盘交给这一页，焦点行 = 点的那一行
- [x] `↑` / `↓` 移焦点行，移到两端时停住
- [x] 焦点行画得出来（与文件页那一档同一个样式）
- [x] `Esc` **只**把键盘还回去，**不**取消正在跑的回合（一次手势一层）
- [x] 点在输入区上把键盘还回去（与文件页同一条归还路径）
- [x] 键盘不在这一页时，`↑` / `↓` / `Esc` 的既有归属一个字不变（文件页那套照旧）
- [x] 页签切换仍然只靠点、不给键位（`Tab` 与 `Shift+Tab` 的归属不动）
- [x] 帧测试钉住：点左栏之后的焦点行、`↑` / `↓` 之后的帧、`Esc` 之后的键盘归属

## 评论

落地：焦点行与键盘归属复用文件页那一套 —— `sidebar_key` 按页分派（`files_key` / `changes_key`），
`take_sidebar_keyboard` 认「能走键盘的那两页」，滚轮按 `sidebar_page_rect` 分派。点一行同时给键盘与
开那份 diff（与文件页同一条），`Esc` 关掉弹窗之后这一页停在原处 —— 这几条都在 `tests/render_changes.rs`
里钉住。
