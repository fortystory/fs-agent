# 轨迹页里「… 正在思考」那一行的时间戳

Status: 1/1 done（2026-10-06 维护者的一条需求 + 一轮三问的 grilling；一张实现票
[`issues/01`](issues/01-thinking-stamp.md)）

轨迹页每一行都以 `HH:MM:SS ` 开头，只有一行例外：`[deepseek] … 正在思考`。模型正在想的
那几秒到几十秒里，屏幕上唯一在变的那一行恰恰是**唯一没有时刻**的行 —— 时间轴在它这里断了。

这是有意的（[`trace-in-main`](../trace-in-main/spec.md) 用户故事 21：「还开着的那一行不带，
以便屏幕上不出现一个编出来的时刻」）。这份 spec 推翻那半句：开着的行按上**思考开始那一刻**，
定稿时照旧整行重写成完成时刻。

## 问题陈述

1. **轨迹页的时间轴有一行是断的。** `paint_thinking_line` 直接 `push_line`，不过
   [`stamped_line`](../../src/render/tui.rs)；`Painted::Thinking` 也不带 `at`，所以宽度一变
   重放出来的那一行同样没有时刻。
2. **它偏偏是最该有时刻的行。** 实时看着模型思考时，别的行都静止，只有这一行在走；用户
   想知道的正是「它从什么时候开始想的」。
3. **旧理由只对一半。** 「不出现一个编出来的时刻」这条顾虑对**定稿行**成立（那时
   `MessageCompleted.at` 是真的），对开着的行不成立：那一刻根本还没有信封可依 —— 轨迹页其余
   行的时刻也都来自各自那条事件，而推理增量本就没有事件。

## 方案

- 开着的思考行在画出来时按上**思考开始那一刻**：第一条推理增量到达时的 `at`
  （`RenderEvent::Delta` 没有信封，所以那就是收到它的时候）。
- 定稿时**照旧**就地整行重写成完成那一刻（`trace-in-main` §5 的后半句不推翻）。
- `Painted::Thinking` 带上 `at`，于是宽度变化重放出来的行带着同一个戳。

## 实现决定

### §1 时刻从哪来

`open_thinking(speaker, at)`、`paint_thinking_line(speaker, at, targets)` 收下 `at`，画行时
过 [`stamped_line`](../../src/render/tui.rs)。两个调用点都在 `TuiState::apply` 里，`at` 是那
个函数早就算好的 `event_at(&event)`：推理增量那条路径上是 `now`（增量绕过事件流，本就没有
信封 —— `event_at` 的既有注释写着这件事），`Block::Message` 那条路径上（provider 一个增量都
没发时）是 `MessageCompleted.at`，真的。

**不用 `MessageStarted.at`**：那会把时刻挪到「这条消息开始」而不是「这段思考开始」。模型先
答两句正文、再开始想时，那个时刻会明显偏早，屏幕上就会出现一个与事实不符的早戳。

### §2 定稿时跳，一行的时间戳会变

定稿那条路径一字不改：`settle_thinking` 用 `replace_last` 就地重写整行，于是时间戳从「开始
那一刻」换成「完成那一刻」（live 上是正文第一个增量到达的时候，重放上是
`MessageCompleted.at`）。同一行的时间戳因此会跳 —— 这是本次接受的取舍，理由有两条：

- 它说的是实话：这行定稿了，定稿那一刻就是它的时刻。
- **不跳在重放里是错的**：`--continue` 重放时开着的行也是推理增量开的（没有信封），它的
  「开始时刻」只能是重放当时；若定稿不把它换掉，历史的时间轴就会显示「现在」。

### §3 重放清单跟着带 `at`

`Painted::Thinking { speaker, at }`。宽度变化那条路（`rerender_if_width_changed` →
`emit_painted`）重建出来的开着的行于是带着与实时那一刻相同的戳，而不是重建时的 `now`。

### §4 排版不动

轨迹内容的排版宽度已经是「主列内容宽 − `STAMP_COLUMNS`」（`trace-in-main` §5），那一列早
就为时间戳留着了，所以这里不新增任何扣减。思考行是短行，窄终端下由窗格照既有规矩折行。

### §5 明确不做

- **对话视图 / plain / headless 不加时刻**：立场不变，时刻只长在轨迹页上。
- **`live` 尾巴行不加**：它是还没定稿的那一段（`trace-in-main` 的「明确不做」）。
- **事件 schema、模型可见文本、`Block` 层一字不动**：这次只改渲染层的一条行怎么挂上时刻。

## 决定速查

| 问 | 落点 |
| --- | --- |
| 开着的行用哪个时刻 | 思考开始那一刻（第一条推理增量到达时，§1） |
| 定稿时跳不跳 | 跳，重写成完成那一刻（§2） |
| 宽度变化重放 | `Painted::Thinking` 带 `at`，重建出行同一个戳（§3） |
| 排版宽度 | 不动，`STAMP_COLUMNS` 早已扣过（§4） |
| 对话视图 / `live` 尾巴 | 不加（§5） |
