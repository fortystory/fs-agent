# 表格：从「join 竖线」到真网格

Type: implement
Status: done

> 规格：`.scratch/markdown-render/spec.md` §2。
> Blocked by: 01（它已经把整表缓冲那一支搭好了，本票替换它的产出）。

## 目标

一张 Markdown 表格在转录里读起来像表格：表头认得出、列对得齐、超宽不丢信息。

## 落点

`src/render/markdown.rs` 里票 01 留下的**表格缓冲**那一支（`Start(Tag::Table)` 收齐 → 产出的那一段）；测试在 `tests/render_markdown.rs`。

## 具体行为

1. **表头**：整行 `Modifier::BOLD`；表头行下面一条分隔线 `─┼─`（把 `|---|---|` 请回来当信号）。
2. **列宽**：每列取该列所有单元格的**最大显示宽度**（用 `src/render/width.rs` 的算术，CJK 按 2 列）。
3. **对齐**：`Tag::Table(Vec<Alignment>)` 给出每列的对齐方向（`:--` 左、`--:` 右、`:-:` 居中）；没有冒号的按左对齐。按对齐方向填每格的 padding。
4. **余量**：总宽小于 `width` 时，**余量全部给最后一列**——表格因此撑满可用宽度。
5. **超宽**：总宽大于 `width` 时，削减**最宽的那一列**，把省下的额度让给它折行；削到该列自然宽度仍不够就按同一规则继续往下削。**不截断。**
6. **单元格内折行 + 整行等高**：一个格折成三行，同行其余各格一起撑到三行高（用空格补齐），网格竖线在每条续行上都连续。
7. **顶格**：表格不加缩进，从第 0 列起。
8. **单元格里的行内 Markdown 要渲染**（代码、粗体、链接），所以单元格要保留 `Vec<Span>` 而不是 `String`。
9. 对齐行的信息由解析器给出，**不要**再自己扫 `|---|---|`。

## 测试

- `quotes_rules_and_tables_render_as_structure` 里那条「分隔那一行被丢掉」的断言**反过来写**：现在分隔线是表头信号，必须存在。
- **新增**：
  - 表头行的每个 span 都带 `BOLD`；
  - 分隔行的字符集是 `─ ┼`；
  - 同一列在各数据行里的**起点列号一致**（这就是「对齐」的可断言形式）；
  - 表格第一行的第一个字符从第 0 列开始（顶格）；
  - 一张超宽表：最宽的列被折成多行，且同行其余格同高（断言行数与每行的字符数）；
  - 右对齐列（`--:`）的 padding 加在**左边**。
- 用一张三列表做正反例：一张装得下（余量给最后一列）、一张装不下（折行）。
