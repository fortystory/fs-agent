沙箱是什么？

给完全不懂的人看的图解 · 全是大白话

沙箱 = 给程序划一个圈

圈里随便玩，圈外碰不到。

「沙箱」这词就是从这来的 —— 给小孩玩沙子的那个围栏。

程序其实碰不到任何东西

它只能说：老师，帮我拿一下。

老师就是内核。老师摇头，它真的什么也拿不到。

沙箱 = 老师多看一眼

在哪个环节看，就叫哪种沙箱。

看得见什么，就管得住什么 —— 这一句后面还会用到。

流行的大概五种

按「在哪拦」分成五种

🚪

门口搜身

只看你「要做什么动作」，看不到你指着什么东西。

seccomp · Linux
👓

换一副眼镜

给你换掉整个房间的样子。你的房间变小了，别的地方根本不在视野里。

bubblewrap、Docker/Podman 容器 · Linux
📒

查本子

房间不变，但老师手里多一张清单。每次动手前翻一下，不在单子上就摇头。

Landlock · Linux、Seatbelt · macOS、AppArmor / SELinux
🧑‍🔧

换个人去干

不让你自己去，派一个被管住的人替你去。上网就是这么管的。

网络代理 · 各家沙箱、受限令牌 · Windows
🏠

另开一栋房子

干脆搬出去住，自己一栋房子、自己一个管家。最安全，也最重。

Firecracker、Kata、gVisor、云 sandbox、WebAssembly
🧩

换个身体

让它只在一种「安全身体」里跑，身体本来就做不了危险动作。

WebAssembly（WASI）

那它们各自靠什么实现？

🚪 门口搜身
系统调用的入口装一个过滤器
👓 换眼镜
「命名空间」：每个程序可以有一份自己的房间清单
📒 查本子
内核里的安全检查钩子（LSM）
🧑‍🔧 换个人
换掉真正干活的程序，或中间加一道
🏠 另开一栋
硬件虚拟化 / 独立内核 / 语言运行时

共同点：它们都活在「老师」这一侧，程序自己拆不掉。

为什么沙箱也会漏？

老师只在他看得见的地方管。

网络、别的程序、你手里已经攥着的东西 —— 看不见，就管不了。

沙箱 = 让老师在替程序做事之前，多问一句「行不行」。

问在哪一步，边界就在哪一步。
