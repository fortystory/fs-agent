# 种子材料：注入的上下文可查看详情

> **这不是 spec，也不是票。** 它是 2026-10-01 在一轮 `/ask-matt` 里记下的意向：技能、
> `AGENTS.md` 这些被注入对话的东西，也要能看到详情。
> 还没被访谈、也没有票；想推进时走 `/grill-with-docs` 把它折成 `spec.md`，再 `/to-tickets` 拆票。
> **写就于 2026-10-01**；下面《现状》一节核实于同一天。

## 它要什么

模型看到的那份注入内容（技能正文、`AGENTS.md`、仓库地图……），人在 TUI 里也能展开看，
而不是只知道「注入了」。

## 现状

注入在 `src/context.rs` 与 `src/context/`（`skills.rs`、`repo_map.rs`）。覆盖层当前只有五种
（`Pending::Loop` / `Paste` / `ClearDraft` / `Exit` / `Questionnaire`），**没有**「查看注入」
这一类；可参照的先例是历史详情覆盖层（`tui-history-replay` 那一轮）。

## 待谈的分叉

1. 入口是什么：快捷键、`/` 命令，还是点状态行的某一段？
2. 展示的是「本轮实际注进去的原文」，还是「按当前配置会注进去的预测」—— 两者在技能按预算
   截断时并不相同。
3. 大块内容怎么截断：复用 `src/context.rs` 的 `preview` 与指针约定，还是给一个可滚动的原文视图。
