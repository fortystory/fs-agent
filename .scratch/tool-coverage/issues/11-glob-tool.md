## 目标

模型按一个 glob 模式列出工作区里的文件：一行一条相对路径、按路径稳定排序、忽略规则与搜索工具
**同一套**，于是"这儿有哪些文件"不必再拼 `ls` / `find`。

**可 demo**：`pattern: "src/render/*.rs"` 拿回该目录下的文件清单。

## 现状（改前先复核）

- `ls` 各种形态合计 728 段、`find` 104 段，全部走 bash。
- 搜索工具已经有一套成型的范围与忽略规则（只扫会话 cwd、遵守 `.gitignore`、跳过隐藏文件、
  输出按路径稳定排序、上限 + 末尾收尾）—— 新工具照抄这一套，不发明第二套。

## 验收

- [x] 单字段 `pattern`（必填，相对会话 cwd 的 glob，支持 `**`，也覆盖 `src/*` 这类目录语义）；
      **不加** `path` 参数
- [x] 输出一行一条**相对路径**，**按路径排序**，不带大小与时间
- [x] 忽略规则与搜索工具同一套（遵守 `.gitignore`、跳过隐藏文件与隐藏目录）
- [x] 上限 `MAX_PATHS = 500`（与搜索工具的条数上限同值）+ 末尾一句可操作的收尾
- [x] `effect()` = `ReadOnly`；**不做** `tree` 那档层级缩进
- [x] 描述里写清三方分工：符号地图答"有哪些符号"、搜索答"某个名字在哪"、本工具答"有哪些文件"
- [x] 新增一份工具文档
- [x] 新增测试：忽略规则与搜索一致、排序稳定、上限与收尾、非法 glob 报错
