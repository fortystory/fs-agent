### 验收：跑了，**判不了** —— 样本为零

```bash
python3 .scratch/tool-coverage/research/01-shape-inventory.py --since 2026-10-11 --check
# 会话目录（有 log.jsonl）：0
# bash 调用数：0
```

今天是 **2026-10-10**，这一轮代码还没进任何用户的会话，所以「发布日之后的会话」一条也没有。规格
§7 的样本门槛是**累计 ≥20 个含 bash 的会话**，门槛没过，于是**不下结论**，记为**待观察**。
顺带一句：那 0 个会话上脚本自己崩在一个除零上（`N = 0` 时 `平均 X/调用` 那一行），判据链之外的
一个小的健壮性缺口，等真有窗口再跑时顺手补掉。

基线与现值并排（三个主判据）：

| 主判据 | 基线（2026-10-10 快照） | 现值 |
| --- | --- | --- |
| 每会话 bash 调用数**中位数** | 见脚本输出（274 会话 / 7703 调用） | **无样本** |
| 段数 / 调用（不切管道切法） | **3.54** | **无样本** |
| 命令与结果字符数**中位数** | `cmd中位` / `res中位` 逐形态 | **无样本** |
| 辅助：bash 占全部工具调用 | **61.4%**（7703 / 12555） | **无样本** |

作为**基线本身仍然可复跑**的证据，全量跑一遍（无 `--since`）的今天值是：275 会话 / 7816 次 bash
/ 段数不切管道 3.52 —— 与存档基线（274 / 7703 / 3.54）只差今天新跑的那几场会话，属于正常增长。
