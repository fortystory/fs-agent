# 文件查看器：文件页那一档的内嵌 nvim

Status: done

- **来源**：维护者 2026-10-06 的要求「点击文件后的内容弹窗改成直接嵌 nvim」。先在
  `prototype/embed-nvim` 分支上验完三个未知（`vt100` 画得对不对、键鼠转发要写多少、浮层里
  能不能用），再折成这里的实现 —— 那份 README 记着每条决定的实测。
- **术语**：左栏 / 文件页 / 详情覆盖层 / 焦点行 / 语义色板 照 [`CONTEXT.md`](../../CONTEXT.md)；
  本 spec 新用**文件查看器**（`Viewer`：一屏外来的编辑器画面）与**外来屏幕**。

## 方案

1. **一个键挑一档**：`[ui] file_viewer = "builtin"`（缺省，一字不变）或 `"nvim"`；宽度
   `file_viewer_width`（缺省 135，下界 20）只对 nvim 那一档有效。不认识的词是启动错误。
2. **几何：去框留白**：浮层居中、宽 `min(屏宽 − 4, 上限)`、高 `屏高 − 4`，里面再让出**一格**
   留白 —— 没有框线，nvim 自己那块底色就是边界。100x30 的终端给 nvim `94x24`。
3. **只读、不折行、鼠标给 nvim**：`-M -R`（真锁，状态行亮 `[RO]`）、`-c set nowrap`
   （`--cmd` 会被用户配置里的 `wrap` 顶掉）、`set mouse=a`。三条都写死：这一档进来是**看**文件。
4. **键盘独占**：除 `Ctrl-C`（关掉浮层）与 `Ctrl-Z`（挂起，终端层手势）之外，每个键都翻成
   字节原样进 nvim —— 包括 `Esc`、`Ctrl-D` 与全部 `Ctrl` 组合。
5. **鼠标**：框外一次左键关掉它（且**不穿透**，与详情覆盖层同一条）；框内按 SGR 转发，修饰位
   一起带上（`nowrap` 之后靠 `shift + 滚轮`横着滚）；滚轮也归 nvim。
6. **关闭三条**：`Ctrl-C`、框外点击、nvim 自己的 `:q`。收掉时补一次重扫。
7. **不进事件流、不进模型上下文**：与内置预览同一条口径；它因此也**不过** fs-agent 的沙箱
   —— 做的是「人在自己的终端里点开自己的文件」。
8. **起不来就回退**：PATH 上没有 `nvim`、或 pty 开不出来时，走内置预览。

## 明确不做

- **可写**：这一档只读。要改文件用 `edit_file`（模型）或自己的编辑器（人）。
- **`nvim --embed`**：理由在 [ADR 0013](../../docs/adr/0013-nvim-file-viewer-is-an-alien-screen.md)。
- **给这一档单开一份 nvim 配置**：读的人的 `~/.config/nvim` 就是答案；想隔开自己设
  `NVIM_APPNAME=fs-agent` 即可。
