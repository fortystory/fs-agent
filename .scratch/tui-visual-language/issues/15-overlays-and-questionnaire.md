# 15 — 四个浮层表面与问卷

Type: implement
Status: done
Part of: ../map.md
Blocked by: 11

> 规格：[`../spec.md`](../spec.md) 实现决定 §25–§29。

## 目标

四个浮层表面**共用一套框架语法**（框色只剩一个）；模态不再整块一个颜色；菜单不再冒充警告；而问卷里「键盘在哪」**永远只有一个答案**。

## 现状（改前先复核）

- **模态**：边框、正文、按钮行、按钮键名**四个地方同一个 `Yellow`**（「整块黄」）。
- **`/` 与 `@` 菜单**：边框是框架色，但**未选中行也是 `Yellow`**，光标行是黑底黄字。
- **详情覆盖层**：整个框穿**发言者色**（2026-09-23 的记录，理由是不用读一个字就知道是谁的行）。
- **问卷**：表头 `Cyan`+`BOLD`、已选 `Yellow`+`BOLD`、当前项在选项区聚焦时 `REVERSED`、在输入区聚焦时 `DIM`，自定义行标签再在 `DarkGray` / `BOLD` 之间跳一次 —— **同一个问题有两个答案**。

## 落点

- `src/render/tui.rs`：模态的绘制与按钮行、菜单行、详情的边框与标题、问卷的选项与自定义行。
- `src/render/palette.rs`：取色。
- `src/render/wording.rs`：只有文案需要跟着动时才碰。

## 具体行为

1. **四个表面共用框架**：框架色虚线 + **四角为空**（`border::Set` 的角本来就能设成空格，**不需要自绘**）。框色**只剩框架色一个**；问卷没有框，不参与。
2. **模态拆成三件事**：边框（框架色 + 空角）、正文（正文档）、按钮行（焦点色，键名加 `BOLD`）。
3. **菜单去黄**：未选中行归正文档，光标行用 `REVERSED`。
4. **详情**：边框归框架色 + 空角，**发言者色退到标题行**（+`BOLD`）—— 那条记录的意图（不读一个字就知道是谁的行）没丢，标题本来就在框内第一行、紧挨边框。**要回改那条 2026-09-23 的记录。**
5. **问卷**：表头归正文档 + `BOLD`；**已选不用颜色**（只靠 `BOLD` 与已有的 `[x]` / `●` 标记）；**全屏唯一的 `REVERSED` 就是键盘所在** —— 选项区聚焦时在选项行、输入区聚焦时在自定义行；**`DIM` 退场**，不再有两处同时表达焦点；页脚归静音档。

## 验证

1. 逐格缓冲快照：四个表面各自的**框角**（四个角是空格）、颜色分档、焦点表达。
2. 问卷的三个组合：选项区聚焦 / 输入区聚焦 / 已选与当前项不一致（`[x]` 已选但光标在别处）—— 断言**每一帧只有一个 `REVERSED`**。
3. `tests/render_layout.rs` 的菜单反色与问卷高亮断言、`tests/ask_user_question_tui.rs`、详情边框色断言都要改写。
4. 真终端：手工清单 **② / ⑪ / ⑫ / ㉕**。**模态失去黄色之后是否仍「跳出来」**要在 ② 留实测记录；不够的话退路是给模态一个焦点色的边框，而**不是**把黄请回来。

## 不做什么

- 不改问卷的**键位与「选项区 / 输入区」语义**（那是既有 spec 与 ADR 的契约），只改视觉表达。
- 不改浮层的**几何基准**（模态主列居中 vs 详情屏幕居中）。
- 不改按钮之间的间距、菜单内边距（归[字形符号表与间距](17-glyph-table-and-spacing.md)）。
- 不动覆盖层立着时滚轮按指针位置分派那条交互。
