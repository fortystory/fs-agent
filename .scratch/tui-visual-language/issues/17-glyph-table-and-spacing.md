# 17 — 字形符号表与三个间距常量

Status: ready-for-walkthrough

> 规格：[`../spec.md`](../spec.md) 实现决定 §12–§15。

## 目标

散在四个文件里的字形收进**一张表**（一个语义一个具名常量），其中 `▸` 的判据被改正；间距从手写字面量收到**三个**具名常量 —— 就三个，不是一套体系。

## 现状（改前先复核）

- 字形散在四处：转录的可点标记、todo 页的三态、输入区的提示符、回合条的三个格、问卷的四个标记、还有状态行里的分隔符。
- **`▸` 承担两个语义**：在转录里是「这里有折起来的内容」，在 todo 页里是「进行中」。
- **注入行与轨迹视图的消息行是折叠的，却没有 `▸`**（它们点得开详情，里面才是全文）—— 这是决策图里一处被回头修正的判据。
- 间距全是手写字面量：按钮之间 3 个空格出现在 **4 处**；附属行的 2 格缩进散在多处；提示行用 ` · ` 分隔。
- **注意**：结构尺寸（行高、列宽、内边距）**早就有常量**了，缺的只是字符级那一层 —— 所以本票不要新起一套体系。

## 落点

- `src/render/wording.rs`（或一个新的字形模块，与 `wording.rs` 同侪）：符号表与三个间距常量。
- `src/render/tui.rs` / `todo.rs` / `editor.rs`：改成引用。
- `src/render/tui.rs`：注入行与轨迹页消息行的 `▸`。

## 具体行为

1. **一张符号表**：一个语义一个具名常量，覆盖 `▸`（**有折起来的内容**）、todo 三态、提示符、回合条三格、问卷四符、行内截断、状态行三段分隔。
2. **`▸` 的双义靠区域区分**（todo 页里全是 todo 行，不会与转录混），并**在表里明写这条双义** —— 别让它当暗知识。
3. **`▸` 的判据 = 谁把内容折起来谁就有**：思考行、工具行、**上下文注入行**、**轨迹视图的消息行**都有；**对话视图的消息行**已显全文，不给。
4. **三个字符级间距常量**：`INDENT`（2 格，附属行的缩进）、`GAP`（3 格，并列控件之间的距离）、`SEP`（`" · "`，一行里各条目的分隔）。三个都住 `wording.rs`。
5. 菜单的 1 格内边距与转录前缀后的 1 个空格**不立常量**（各只出现一次，立了是债）。
6. **两套居中机制都保留**，把理由从注释提升为函数旁的显式说明 —— 手算那套还担着「命中测试与绘制必须是同一份算术」，不是遗留。

## 验证

1. 逐格缓冲快照：`▸` 在四个位置的有无（思考行有 / 工具行有 / 注入行**有** / 轨迹页消息行**有** / 对话视图消息行**无**）；todo 三态字形；按钮间距与附属行缩进。
2. 符号表与间距常量落地后，`grep` 确认那几处手写字面量**零残留**。
3. **`scripts/tui-startup-check.py` 不许红** —— 它钉的三个字形锚点（标记、横虚线、竖虚线）本票不碰。
4. `tests/todo.rs` 与 `tests/render_layout.rs` 里钉 todo 字形与降级的断言按新常量改写。

## 不做什么

- 不改任何字形的**外观**（本票只把它们收进表里，`▸` 那处是**补上漏掉的**，不是换字形）。
- 不引入生僻符号；表里每一个字形都已在仓库里上过屏。
- 不动浮层的四个角（归[浮层与问卷](15-overlays-and-questionnaire.md)）。
- 不动结构尺寸的既有常量。
