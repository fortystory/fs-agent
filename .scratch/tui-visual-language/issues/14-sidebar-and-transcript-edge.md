# 14 — 左栏与转录右缘

Type: implement

> 规格：[`../spec.md`](../spec.md) 实现决定 §21–§24。

## 目标

左栏的占比条**真的看得出来**；转录右缘不再有两条并排的细竖线；轨迹视图也有位置指示；身份标记的坡道不再是孤儿色。

## 现状（改前先复核）

- 占比条是 `bg(DarkGray)` 涂出来的，而同一行的标签是 `fg(DarkGray)` —— **同一个值，一个当字一个当底**；条**不占列**（注释说这是刻意的：列宽与降级链完全不受它影响）。
- 转录右缘：滚动条（`track` 与 `thumb` 都是 `DarkGray`）+ 回合条，**两条一列宽的竖线挨着**；`TRAILING_COLUMNS = 2` 永远预留（理由：转录长高时文字不重新折行）。
- 轨迹页只有 pane 与右下指示器 —— 它有自己独立的滚动与贴底跟随，却**没有位置指示**。
- 身份标记的品红坡道（宽档 5 行）不在色板里，是全屏唯一没归属的色。
- 用量面板里还留着两条**已不可达**的宽度降级路径（注释自己承认「到不了」）。

## 落点

- `src/render/panel.rs`：`row` / `fit` 的列预算与降级链、那两条不可达路径。
- `src/render/tui.rs`：滚动条、回合条、轨迹页的绘制。
- `src/render/layout.rs`：轨迹页的列。
- `src/render/palette.rs`：身份坡道的两个条目。

## 具体行为

1. **占比条改用块字符**（`▓▓▓░░░░`，前景用静音档），不再用底色。注意它**占列** —— 列预算与降级链要重算，值列要给它让位置。
2. **滚动条只画滑块、不画轨道**。`TRAILING_COLUMNS = 2` 的预留**不动**（它的理由防的是重新折行，跟画不画无关）。
3. **轨迹页补滚动条、不补回合条**，画在**最右列**（那里没有回合条）；轨迹页正文因此 40/28 → **38/26** 列。
4. **身份坡道进色板**（两个具名条目：亮端 / 暗端）。
5. ~~**删掉两条不可达的宽度降级路径**~~（prefactor：它们的存在会让第 1 条的列预算重算多绕一圈）。
   **2026-10-06 实现时的收口**：**缓存行那条删了**（最宽的缓存拆分 17 列，短于真实的值列 21 列，从外壳那几档都到不了 —— 连同钉它的测试 `a_cache_split_too_wide_for_its_column_is_left_out`）；**上下文百分比那条留了** —— 实测它在窄档 28 列、占比到三位数（如 617%）时**是可达的**，删掉会把「丢掉百分比」变成 `…` 截断。理由与实测都记在 `../spec.md` §34 的注里。

## 验证

1. 逐格缓冲快照：占比条的字符与位置（含「一大于零就至少一格」「撞顶时不越界」两个边角）；右缘的格子（滑块在、轨道不在）；轨迹页的滚动条与 38/26 列。
2. `tests/render_layout.rs` 里占比条的两组断言（底色 → 字符条）与轨迹页宽度断言改写；`usage-stats-format/spec.md` 里「底色不占列，所以列宽计算与降级链一点都不用动」那句要回改。
3. 真终端：手工清单 **⑩ / ⑮ / ㉙**（占比条读数、右缘观感、轨迹页 26 列的密度）。

## 不做什么

- 不动左栏的宽度档、页签行为、`Ctrl-O` 意愿。
- 不动轨迹页的**隔行底色**（只可调色值，不撤）。
- 不动转录的取色与分段（[13](13-transcript-colours-and-turn-gap.md)）。
- 不动 `文件` 页的内容 —— 本票只碰它的占位行外观（如果它在色板上也要取色的话）。
