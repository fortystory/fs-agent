# 覆盖层与问卷（prototype）

对应 [覆盖层与问卷](../issues/08-prototype-overlays-and-questionnaire.md)。**一次性素材**；对着真终端看：`python3 .scratch/tui-visual-language/prototype/overlays-demo.py`。

## 四个表面的现状（读代码得到）

| 表面 | 边框 | 正文 | 焦点 / 强调 |
| --- | --- | --- | --- |
| **模态**（权限 / 问题） | `LIGHT_TRIPLE_DASHED`，`Yellow`（`tui.rs:4024`） | `Yellow` + 居中（`4038`） | 按钮行 `Yellow`；键名 `[y]` = `Yellow`+`BOLD`（`4112-4114`） |
| **`/` `@` 菜单** | `CHROME_LINE`（`4778`） | 未选中行 `Yellow`（`4815`） | 光标行 `Black on Yellow` + `BOLD`（`4809-4813`） |
| **详情覆盖层** | `LIGHT_TRIPLE_DASHED`，**发言者色**（`5940`，理由：不用读一个字就知道是谁的行） | 标题 `BOLD` 无色；正文无色 | 页脚 `DarkGray`（`5963`） |
| **问卷** | 无（接管底部输入区） | 表头 `Cyan`+`BOLD`（`3550`） | 已选 `Yellow`+`BOLD`；当前项 `REVERSED`（选项区）/ `DIM`（输入区）；自定义行标签在 `DarkGray` / `BOLD` 间跳 |

**模态是「整块黄」**：边框、正文、按钮、键名四个地方同一个 `Yellow`。菜单也一样，连未选中的行都是黄。

## 待拍板 1：模态的「整块黄」怎么拆

| 方案 | 做法 |
| --- | --- |
| **A 拆成三件事** | 边框 `CHROME` + **空角**（04 定的框架档）、正文 `PLAIN`、按钮行 `ACCENT`（键名 `BOLD`） |
| B 边框保留黄 | 把「需要你回答」编码进框色 |
| C 只把正文改 `PLAIN` | 边框与按钮仍黄 |

➡️ 推荐 **A**：`Clear` + 主列居中已经让模态「跳出来」了，框色不必再承担一次。**黄要留给诊断、hook 反馈与 `Severity::Warn`**（05 的决定）——一个阻塞式询问不是警告。

## 待拍板 2：菜单去不去黄

| 方案 | 做法 |
| --- | --- |
| **A 正文 `PLAIN`，光标行 `REVERSED`** | 菜单不再引任何颜色 |
| B 保持黄 | 菜单 = 「命令是黄的」这套既有语汇 |
| C 正文 `PLAIN`，光标行 `ACCENT`+`BOLD` | 与页签选中同族 |

➡️ 推荐 **A**。**光标行要的是「回车会选它」**，正是 05 给「临时光标」定的手段（`REVERSED`）；菜单是临时的选择器，给它一个专属颜色不划算。

## 待拍板 3：详情的发言者色框要不要保留

| 方案 | 做法 |
| --- | --- |
| **A 边框归 `CHROME` + 空角，发言者色退到标题行** | 四个表面框架语法统一；「这是谁的行」仍一眼可见 |
| B 保留发言者色框 | 现状；框架因此有两个色 |
| C 边框 `CHROME`，标题也不用发言者色 | 最统一，但丢掉那条 2026-09-23 写下来的信息 |

➡️ 推荐 **A**。这**推翻 2026-09-23 的一个决定**（「边框穿发言者的颜色……应该在你读它一个字之前就看得出来」），但那条的**意图**（不读一个字就知道是谁的行）没丢 —— 标题行本来就在框内的第一行、紧挨着边框。换来的是四个表面共用一套框架语法。

## 待拍板 4：问卷里「键盘在哪儿」

现状有两层表达：**当前项**用 `REVERSED`（选项区聚焦）或 `DIM`（输入区聚焦），**自定义行标签**再用 `DarkGray` / `BOLD` 跳一次。

| 方案 | 做法 |
| --- | --- |
| **A 全屏唯一的 `REVERSED` = 键盘所在** | 选项区聚焦 → 当前选项行反显；输入区聚焦 → 自定义行反显。不再有 `DIM`，也不再有两处同时表达 |
| B 保持现状 | `REVERSED` / `DIM` 两种 + 标签跳色 |
| C 都用 `ACCENT` | 与页签同色；但「键盘在哪儿」用反色更准 |

➡️ 推荐 **A**。05 已经定了「用 `REVERSED`、不用 `DIM`」（`DIM` 在主流终端有三套实现方向、浅色主题下可能无效）；而**同一个问题不该有两个答案** —— 现在屏幕上的「焦点」最多只出现一次，正是问卷代码注释里那句「屏幕上于是只有一个焦点」的本意。
