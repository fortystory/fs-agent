# 种子材料：右侧统计的单位与占比可视化

> **这不是 spec，也不是票。** 它是 2026-10-01 在一轮 `/ask-matt` 里记下的意向：右侧统计数字
> 用 `k`/`M`/`万`/`亿` 这类单位，并给用量加一个百分比或「数字背景是进度条」的占比显示。
> 还没被访谈、也没有票；想推进时走 `/grill-with-docs` 把它折成 `spec.md`，再 `/to-tickets` 拆票。
> **写就于 2026-10-01**；下面《现状》一节核实于同一天。

## 它要什么

- 一个配置项，决定统计数字用哪套单位（原话是「添加一个配置」）。
- 用量占比：百分比数字，或者「数字压在进度条上」（数字不变，背景是占比条）。

## 现状

右侧面板已经在算这些东西：`src/render/panel.rs` 折叠每一条 `UsageRecorded`，给出总量 / 预算、
缓存命中、输入 / 输出；数字走 `wording::thousands`（千分位），总量与预算由 `wording::token_pair`
配成一行（`src/render/panel.rs:82-102`）。

## 待谈的分叉

1. 单位制式：中文语境用「万 / 亿」，还是 SI 的 `k` / `M`？两者要不要都能配（而不只是开关）？
2. 占比的分母是谁 —— 会话 token 上限（`budget_limit`），还是模型的上下文窗口？
3. 「数字背景是进度条」在现在的渲染层怎么表达：同一行内叠色，现有样式够不够？
4. 窄档降级成什么（只留百分比数字，还是照旧）？
