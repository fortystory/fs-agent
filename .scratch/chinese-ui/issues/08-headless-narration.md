# 08: headless 的事件叙述

**What to build:** 机器模式（headless）走诊断出口的那一串进度叙述出中文，这样用管道或脚本时也读得懂。它**保留自己的事件式推导**，不并进共享的呈现类型。

Blocked by: 01

Status: ready-for-agent

**参考:** spec §Implementation Decisions（`.scratch/chinese-ui/spec.md`）、票 01（措辞模块）

- [ ] headless 的进度叙述（回合、轮次、工具、权限、收尾）是中文
- [ ] 它仍然从**事件**推导，不走共享的呈现类型；措辞只来自措辞模块
- [ ] **标准输出只放最终产物的契约不变**，既有的端到端权威回归仍然绿
- [ ] 被碰到的既有断言改成断语义

**顺序:** 与其余 02–08 没有依赖，但都会往票 01 建的同一个措辞模块追加函数；两票同时改它会冲突，按号做或分批做。

## Comments

- 需求侧对应 spec 的 30–31 号 user story。
- 为什么不让它并进共享呈现类型（访谈决定 S2a）：headless 的叙述本来就是**进度日志**而不是转录（没有说话人前缀、没有分节线），硬并进去等于换一种重复。它和 `sessions show` 属于同一类——共享短语，不共享结构。
