# 06: CLI：帮助与错误

**What to build:** 命令行这一侧给人看的字出中文：五份帮助（主命令、交互式、`probe`、`prune`、`sessions`）、参数解析错误、启动期的拒绝与失败、以及会话级错误的呈现。顺带把帮助文本从「直接打印」改成**返回字符串**，好让它能被断言、也被措辞层覆盖。

Blocked by: 01

Status: done

**参考:** spec §Implementation Decisions（`.scratch/chinese-ui/spec.md`）、ADR 0001（会话级错误的细节保持英文）

- [x] 主命令与交互式会话的帮助是中文
- [x] `probe`、`prune`、`sessions` 各自的帮助是中文
- [x] 帮助文本是**返回字符串的纯函数**，可被断言；打印归入口负责
- [x] 参数解析错误是中文（含「不认识这个参数」「这一项需要一个数字」这类）
- [x] 启动期的拒绝与失败是中文：以 root 运行、配置读不出、会话存储不可用、运行环境缺失
- [x] 会话级错误：**错误码带中文说明**，而**原始细节原样透传、仍是英文**（它是诊断线索，且日志只追加、永久回放）
- [x] 被碰到的既有断言改成断语义

**顺序:** 与其余 02–08 没有依赖，但都会往票 01 建的同一个措辞模块追加函数；两票同时改它会冲突，按号做或分批做。

## Comments

- 需求侧对应 spec 的 20–25 号 user story。
- 会话级错误那条是本票唯一需要「不翻」的例外，理由在 ADR 0001：写进事件流的文本按语言冻结，旧会话与新会话不该一半中一半英。错误码是契约，细节是诊断。

> **注（2026-09-30）**：上面那条 checklist（以及本节 `**参考**` 与这条 Comments 引 ADR 0001 的说法）已经从当年的结论翻过来：**`SessionError.detail` 现在写中文**（`src/agent.rs:1299` 的「这一轮没有讨论者作答」、`:1388` 的「合成器这次调用没有产出」），写进事件流的工具结果与错误文本同样 —— 这是 [ADR 0005](../../../docs/adr/0005-model-visible-text-in-chinese.md) 推翻 ADR 0001「模型可见文本冻结成英文」那半句的结果。**「错误码带中文说明、按 `code` 映射」这个形状没变**，`detail` 也仍然原样透传（只是透传的文本现在是中文）；ADR 0005 记的那笔代价照旧 —— 升级前写下的老流里这些 `detail` 还是英文的，`--continue` 重放出来会中英混排。
