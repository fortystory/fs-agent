# 07: `sessions` 的输出

**What to build:** 事后复盘这一侧给人看的字出中文：`ls` 的表头与「无会话」提示、`show` 的轮次分组标题与过滤词、`replay` 与 `stats` 的字段名与计价说明。**机器可读的部分不动**——JSON 的键与结构保持英文。

Blocked by: 01

Status: ready-for-agent

**参考:** spec §Implementation Decisions（`.scratch/chinese-ui/spec.md`）、票 01（措辞模块）

- [ ] `ls` 的表头与「无会话」提示是中文
- [ ] `show` 的轮次分组标题、过滤词、状态标签是中文
