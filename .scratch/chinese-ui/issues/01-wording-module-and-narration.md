# 01: 措辞模块与第一批：轮次 / 回合叙述

**What to build:** 一个**唯一处**，所有给人看的短语都从这里产出——然后让第一批真正上线：轮次分节线与回合起止叙述在 **TUI 与 plain 两个画家上同时**出中文。跑起来能看到 `── 第 2 轮（独立首轮）──` 和 `[kimi] 回合结束：完成`。这一票的产物除了这两句中文，还有**整个 feature 唯一的接缝**：一个纯函数模块（领域值 → 中文短语），无终端、无 sink，之后的每一票都往它里面加短语，不新开接缝。

Blocked by: None

Status: done

**参考:** spec §Implementation Decisions / §Testing Decisions（`.scratch/chinese-ui/spec.md`）、ADR 0001（冻结面）、票 23（中文宽度）

- [ ] 新增的措辞模块是**纯函数**（领域值 → 中文短语），调用方是画家；它**不管样式**（颜色/加粗仍归画家）、**不管结构**（plain 的逐行前缀、TUI 的缩进各留原样）
- [ ] 轮次分节线出中文，两种画家都覆盖
- [ ] 回合的开始与收尾叙述出中文，两种画家都覆盖；停止原因在文字上是中文
- [ ] 轮次模式与停止原因各有一个**显式中文映射**；讨论协议里已经存在的轮次中文标签并入措辞层；界面上不再出现调试格式的枚举
- [ ] 措辞层有它自己的测试，逐条断言**确切的中文**
- [ ] 被这一票碰到的既有画家断言改成断**语义**（画了没有、严重度颜色可区分、进的是滚动区还是实时区），不再断言文本内容
- [ ] **冻结面不被调用**：讨论者与合成器的 system prompt、投影拼出的轮次前缀、说话者自身的错误消息、fs-agent 自己生成的工具结果文本，措辞层都够不到
- [ ] 标准输出只放最终产物的既有权威回归仍然绿

**顺序:** 本票建立接缝，02–08 全部依赖它。

## Comments

- 需求侧的这一批对应 spec 的 1–4 号 user story。
- 为什么第一票就带枚举映射：轮次分节线与停止原因**就是**依赖这两个枚举的短语，所以它们是这条垂直切片的一部分，不是预先铺开的横切工作。
- 硬编码中文、不做运行期 locale（访谈决定）；换语言等于改这个模块。
